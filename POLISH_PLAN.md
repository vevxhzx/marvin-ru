# POLISH_PLAN — доводка до v0.13.0

Ветка: **`polish-v0.13`** (от `merge-marvin`; `main` не трогаем). База: `data/jarvis.db`.
Резервные копии: `backups/jarvis-*.db`, соседняя папка `..\marvin-backup-<дата>` (см. `backups/RESTORE.md`).

## Архитектура в 10 строк

1. Один Python-процесс (`run.py`): SQLite `data/jarvis.db`, FastAPI+SSE (порт 8765), Telegram-бот (aiogram), планировщик (APScheduler).
2. Всё личное — в одном локальном файле; режимы приватности `local`/`hybrid`/`cloud`; каждый ответ помечен источником (⚡ правило / 🧠 локально / ☁️ облако).
3. «Мозг»: ~40 офлайн-правил (`quick.py` + `rules()`), затем локальная Ollama с tool-calling, затем облако (Groq/…, через анонимайзер).
4. Инструменты LLM — `core/tools/registry.py`; это единственная граница «модель → данные».
5. Предметная логика — `core/services/*` (деньги, календарь/задачи, заказы, заметки, карточки, память, планировщик).
6. Telegram — `core/telegram/bot.py` (только `owner_id`), живёт в том же процессе.
7. Голос: `voice_client.py` (ПК) — wake-word Vosk, STT faster-whisper, TTS Silero/edge; общается с ядром по HTTP, шлёт пульс.
8. ПК-управление: ядро шлёт команды через SSE, `core/pc/actions.py` выполняет на Windows; файлы никогда не удаляются.
9. Сайт — React+Vite+Tailwind в `web/src`, собранный бандл `web/site` коммитится (чтобы работало без Node).
10. Бэкап — ночной `sqlite3.backup()` в `backups/` + зеркало `data/media`; prune по `keep_days`.

## Этапы (приоритет сверху вниз)

- **0. Подготовка** — git-ветка, бэкапы, `AGENTS.md`, `POLISH_PLAN.md`, `PROGRESS.md`. ✅
- **1. Баги** — P1 (персона/шутки), P2+P4 (статус ПК и экранное время), P5 (статусы Groq/qwen/голос), P3 (запуск/перезапуск `voice.bat` из настроек).
- **2. Голос** — P6 (модель STT, VAD, hotwords из данных, порог уверенности + «Верно/Повторить/Исправить»), P7 (режимы TTS, дефолт «на голосовые»), выбор голоса, кэш.
- **3. Карточки-картинки** — единый стиль, режимы «всегда / важные / никогда», кэш, отправка следом за текстом.
- **4. Telegram** — P8 (кнопки, «Сделано», единая ширина, антидубли), меню/подсказки, «печатает…», дайджесты с картинкой.
- **5. LLM и скорость** — таймауты/ретраи/fallback, кэш, логи времени ответа, документирование маршрутов.
- **6. Новые функции** — 5–6 безопасных (см. ниже), каждая за настройкой.
- **7. Веб** — bento-дизайн, вкладки, состояния загрузки/пусто/ошибка, настройки.
- **8. Надёжность** — P9 (Pillow в requirements), P10 (env/ffmpeg-проверка), тесты, README/CHANGELOG, аудит.

## Как проверять

- `python -m pytest tests -q` — зелёные после каждого этапа.
- `python run.py --no-tg` — поднять ядро, `/api/health`, `/api/status`, сайт.
- `npm run build` после правок `web/src`.
- Голос — `install_voice.bat`, `voice.bat`; Telegram — руками (не поднимать второй экземпляр на том же токене).
