# Маршрутизация запросов: что куда идёт

Короткая карта «какой запрос — каким путём», по реальному коду `core/brain/agent.py` / `llm.py`.
Порядок ветвления — `agent._handle()`; ключевые строки указаны, чтобы не искать заново.

## Порядок (сверху вниз, первое сработавшее выигрывает)

| Шаг | Когда срабатывает | Куда идёт | Логи |
|---|---|---|---|
| 1. Спецкоманды | «облако сброс/проверь», «проверь характер», «отчёт о себе», «смени голос» | без модели | `agent.py:1959+` |
| 2. Присутствие | «я ушёл», «я вернулся», статус дня | правила | `_presence_rules()` `1989` |
| 3. Правила (без LLM) | ~40 бытовых команд: траты, события, задачи, долги, заказы, заметки, «что сегодня», «сколько потратил» | **мгновенно, офлайн, без нейросети** | `rules()` `447-763`, `quick.run` `568` |
| 4. Судья спорной фразы | «сайт 15000», «отдал Ване 2000» — нет явного глагола | малая модель/облако по `brain.judge.where` | `_judge_disputed` `2132` |
| 5. Общий вопрос → облако | не личное (`is_personal` = ложь), режим hybrid/cloud, `brain.gemini.auto`, ключ есть | облако (через анонимайзер) | `2077-2083` |
| 6. Всё остальное → локально | личное: деньги, календарь, задачи, заметки, файлы | Ollama с инструментами | `2084-2089`, `via_ollama` `1432` |
| 7. Моделей нет → инструмент напрямую | Ollama недоступна, вопрос о своих данных | `registry.call` | `2090-2097` |
| 8. Запасной путь | Ollama лежит, вопрос не личный | облако | `2098-2107` |
| 9. Честный отказ | ничего не ответило | человеку понятный текст, **ничего не записано** | `2108-2117` |

Режим `cloud` (`_cloud_tools_mode`, `1385`): для всего, кроме явной болтовни, сразу облако с инструментами.

## Кто выбирает «облако» для служебных задач

| Задача | Настройка | По умолчанию |
|---|---|---|
| Судья спорных фраз | `brain.judge.where` | local |
| Разбор списка сообщений | `brain.sorter.where` | cloud |
| Память/факты | `brain.memory.where` | cloud |
| Связи в Мозге | `brain.relations.where` | cloud |
| Инициативные фразы, дайджесты | `persona.where` | cloud |
| Картинки/скриншот | `brain.vision.where` | auto |
| Голос → текст | `voice.stt.cloud` (в `local` — запрещено) | false в примере |

## Таймауты, ретраи, фолбэк

- **Облако** (`llm.cloud_chat`): маршруты по порядку — прокси облака → напрямую → прокси Telegram → системный прокси
  (`_cloud_routes` `559`), таймаут 45 с (`_cloud_post` `635`). Если модель отвергнута (400/404) — пробуется стандартная
  модель провайдера (`832-835`); если «auto»-бесплатная исчезла/перегружена (404/429) — переподбор (`823-829`).
  Голосовая модель без ответа → основная (`805-816`).
- **Локально** (`llm.ollama_chat`): таймаут 180 с; при нехватке `num_ctx` окно разово увеличивается (`324-329`).
- **Время ответа** пишется в лог на каждом маршруте: облако — `облако Groq: <модель> — N с (стрим/прямо, маршрут)`;
  локально — `_log_ollama_stats`; решения — `[tg] ПРАВИЛО → …`, `[tg] ОБЛАКО: …`, `[tg] ОБЛАКО: Groq ответил за N с`.
- **Журнал**: каждый ход — строка в `Run` (`core/services/trace.py`: путь, модель, инструменты, время), из него «отчёт о себе».

## Тон и fallback

Персона берётся из `persona.system_prompt()`/`character_block()` и **одинакова** для облака и локальной модели,
поэтому при падении облака и переходе на Ollama тон не пропадает. `persona.where` влияет только на инициативные фразы.
Если оба мозга недоступны — отвечает шаблон, но по-прежнему без канцелярита и без выдуманных цифр.
