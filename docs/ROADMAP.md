# Roadmap

Короткая карта: где я сейчас, что делаю руками прямо теперь и куда собираюсь. История изменений — в [CHANGELOG.md](../CHANGELOG.md). Здесь — только план и честные пометки «это идея, а не обещание».

Текущая версия — **0.13.0**.

## Сделано (крупными мазками)

- **0.9.x** — ядро: деньги, задачи, календарь, заметки, Telegram, голос, сайт, режимы `local`/`hybrid`/`cloud`; заказы и помодоро; люди и граф связей; фриланс-режим и финансовый пульс.
- **0.10** — присутствие: ассистент знает, за ПК ты или отошёл, и сам решает «сказать / отложить / промолчать»; цели → вехи → задачи; лента дня, решения, рутины, «проверь себя».
- **0.11** — **доска**: бесконечный лист (стикеры, текст, кадры, картинки, стрелки, карандаш) для раскадровок и сценариев, с хронометражем и экспортом PNG/PDF. Доска привязывается к заказу, и ассистент её «видит».
- **0.12** — органайзер монтажных папок, автоучёт времени из Premiere/After Effects/DaVinci, восстановление из бэкапов в настройках со страховочным слепком, автономное окно десктоп-клиента.
- **0.13** — привычки (умное откладывание по твоему же ритму), «что я упускаю» (просроченные оплаты, дела без срока, цели без движения), подсказка цены заказа по прошлым похожим, снимок месяца.

## В работе

**Доска мудбордов, сторибордов и референсов для монтажа — ещё в разработке.** Основа уже есть (доска 0.11: кадры, картинки, подписи, хронометраж, привязка к заказу), но именно как «мудборд/референс-борд для монтажа» это пока не готово — не выдаю за готовое. Как доведу, отмечу в [CHANGELOG.md](../CHANGELOG.md).

## Ближайшее (P1)

- **Доска**: довести мудборд/референсы для монтажа; ластик, стирающий часть штриха, а не весь штрих; общая история «отменить» на стороне сервера (сейчас отмена живёт в сессии вкладки).

## Надёжность и качество (P2)

- Pending-подтверждения привязать к id вопроса, а не только к каналу.
- Разбить `core/api/app.py` на роутеры (`finance`, `calendar`, `notes`, `settings`, `setup`) **при следующей крупной фиче**, а не отдельным PR «ради структуры».
- Rate-limit на `/api/chat` с не-loopback адресов (например 30/мин) — защита от залипшей кнопки или скрипта на телефоне.
- Health-проверка Ollama с таймаутом в мастере (сейчас при зависшем Ollama мастер ждёт до таймаута httpx).
- Тесты Telegram-хендлеров через фейковый `Message` (владелец / не владелец, голос, фото).
- `voice_client.py`: вынести `audio.py` (микрофон/VAD) и `client.py` (HTTP/состояние) — сейчас ~900 строк с глобальными состояниями.

## Гигиена и удобство (P3)

- `pyproject.toml` вместо `setup.py` + `requirements.txt`, закрепить версии.
- CI: добавить `ruff` (только `E,F`, без стилистики) и `python -m compileall`.
- Экспорт/импорт всей базы в JSON для переезда между ПК/Docker (сейчас — копирование папки `data/`).
- Один общий `Reply`-объект с полем `source` для всех каналов, чтобы метка ⚡/🧠/☁️ ставилась в одном месте.
- Документировать протокол SSE (`/api/events/stream`): какие события и поля бывают — для тех, кто захочет писать своих клиентов.

## Идеи (не обещания)

Помечаю честно: это направления, а не план.

- **Идея.** Автоподсказка «эта задача похожа на веху X — привязать?» (сейчас цели связываются только явно).
- **Идея.** Различать «Chrome: YouTube» и «Chrome: документация клиента» в присутствии (сейчас учитывается только имя программы).
- **Идея.** Недельное планирование в воскресном дайджесте, а не только утром.
- **Идея.** Отдельная сущность «проект» поверх целей и `Task.project` — сознательно не делаю, пока не станет ясно, что это не четвёртый список.
- **Идея.** Свой клиент на мобильном (PWA уже есть; отдельное приложение — вряд ли).

## Не планируется (осознанно)

- **Многопользовательский режим, роли, пароли/PIN на сайте.** Проект для одного человека; доступ ограничивается токеном и Tailscale.
- **HTTPS внутри проекта.** Tailscale шифрует канал; для VPS — reverse-proxy (Caddy) снаружи.
- **Переписывание на другой стек / микросервисы / очереди.** Не нужно при текущей нагрузке (один пользователь, SQLite).
