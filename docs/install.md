# Установка и настройка

## Windows (10–15 минут, программировать не нужно)

### Шаг 1. Python
1. Скачай **Python 3.12**: https://www.python.org/downloads/windows/ → «Windows installer (64-bit)».
2. Запусти установщик. **Обязательно поставь галочку «Add python.exe to PATH»** внизу первого экрана. Жми Install Now.

### Шаг 2. Telegram
1. Токен бота у тебя уже есть (от @BotFather). Скопируй его — выглядит как `123456789:AAF...`.
2. Узнай свой числовой ID: напиши боту **@userinfobot** — он ответит «Id: 123456789».

### Шаг 3. Папка Джарвиса
1. Положи папку `jarvis` куда удобно, например `C:\Jarvis`.
2. Запусти **`install.bat`** (двойной клик). Он сам поставит библиотеки и откроет `config.yaml` в Блокноте.
   Если `config.yaml` не открылся сам — открой его вручную: правой кнопкой → «Открыть с помощью» → Блокнот.
3. В Блокноте заполни две строки:
   ```yaml
   telegram:
     token: "123456789:AAF..."     # твой токен
     owner_id: 123456789           # твой ID
   ```
   Сохрани (Ctrl+S) и закрой.

### Шаг 4. Запуск
Двойной клик по **`start.bat`**. В окне появится логотип, а в Telegram бот напишет
«Система онлайн, сэр». Всё, работает.

- Окно можно свернуть. Закроешь окно — Джарвис выключится.
- Чтобы он запускался вместе с Windows — один раз запусти `autostart.bat`.

### Шаг 5 (по желанию, но советую). Локальный мозг — Ollama
Без него Джарвис понимает команды-шаблоны (см. ниже). С ним — свободную речь и вопросы.
1. Скачай Ollama: https://ollama.com/download → установи.
2. Открой командную строку (Win+R → `cmd`) и выполни: `ollama pull qwen3.5:4b` (для видеокарты 6 ГБ; ~2.8 ГБ один раз). Таблица моделей под другие видеокарты — в [brain.md](brain.md).
3. Перезапусти `start.bat`. Ollama работает на твоей видеокарте, ничего в интернет не отправляет.

### Шаг 6 (по желанию). Облако для общих вопросов — бесплатно и без VPN
Локальный мозг (Ollama) отвечает за всё личное. Для «объясни / напиши / посоветуй» можно подключить облачную модель — туда уходит только обезличенный вопрос.

**Рекомендую Groq** (бесплатно, из России без VPN, карта не нужна, очень быстро):
1. Открой [console.groq.com/keys](https://console.groq.com/keys) → войти через Google → **Create API Key** → скопировать `gsk_…`
2. На сайте Джарвиса: ⚙ Настройки → **облако** → провайдер **Groq** → вставить ключ → сохранить.
3. Перезапустить `start.bat`. Проверка: в чате «привет, как дела» или кнопка «проверить» в настройках.

Лимит бесплатного Groq — около 1000 запросов в день (проверено 10.09.2026; провайдер меняет лимиты и модели без предупреждения — если «посыпалось», см. [troubleshooting.md](troubleshooting.md)).

Альтернативы (тот же экран, другой провайдер): **OpenRouter** — бесплатные DeepSeek/GLM/Qwen, модель подбирается сама; **NVIDIA** — 120 моделей; **DeepSeek** официальный — платно, копейки, зарубежная карта; **Gemini** — только через прокси, не советую (скрытая опция); **свой** — любой OpenAI-совместимый адрес.

## С телефона

1. На ПК поставь [Tailscale](https://tailscale.com/download/windows), войди через Google/Apple. На телефоне — приложение «Tailscale» из App Store / Google Play, тот же аккаунт, включи.
2. Один раз запусти **`phone.bat`** — откроет порт 8765 в брандмауэре Windows (попросит права администратора) и покажет адреса.
3. На сайте открой **Настройки → «Телефон»** — там QR-код. Наведи камеру телефона → открыть → «Добавить на экран Домой». Всё, будет как приложение, из любой сети, наружу ничего не торчит.

Без Tailscale работает по домашнему Wi-Fi (адрес тоже в «Телефон»), но только пока телефон в той же сети.

> 🔒 С самого компьютера сайт открыт свободно. С любого другого устройства API требует ключ доступа — он зашит в QR/ссылку из ⚙ Настроек → «с телефона» и запоминается в браузере телефона на год. Ключ лежит в `data/api_token`; кнопка «новый ключ доступа» отзывает все старые ссылки.

### Прямо внутри Telegram, без VPN на телефоне

Тот же сайт можно открыть кнопкой в чате с ботом — Telegram сам подтвердит, что это вы, ключи и QR не нужны, Tailscale
на телефоне включать не надо. Нужен только `funnel.bat` на ПК (один раз) и перезапуск. Пошагово, с разбором безопасности:
[docs/telegram-miniapp.md](telegram-miniapp.md).

Если «не открывается»: 1) Джарвис запущен? 2) `phone.bat` запускали? 3) Tailscale на обоих устройствах включён (иконка активна)?

## Голос на ПК — «Джарвис, …» в микрофон
1. Наденьте гарнитуру. Запустите **`start.bat`** (ядро).
2. Двойной клик по **`voice.bat`**. Окно теперь **никогда не закрывается само**: оно открывается отдельно, проверяет пакеты
   (первый раз доставит их, 1–3 мин), делает самопроверку (`ok / FAIL` по каждому пункту: пакеты, микрофон, ядро) и только потом слушает.
   Первый запуск ещё скачает модели: wake word (45 МБ) и Whisper (~500 МБ) — нужен интернет, подождите.
   Если что-то `FAIL` — в окне написано, что сделать; полный лог в `data\voice.log` — пришлите его мне.
3. В трее появится кружок:
   серый — жду «Джарвис», синий — слушаю, жёлтый — думаю, зелёный — говорю, красный — микрофон выключен (клик правой кнопкой → вкл/выкл).
3. Скажите **«Джарвис, потратил семьсот на такси»** — короткий сигнал, потом ответ в наушники. Можно и в два приёма: «Джарвис» → сигнал → команда.
4. Не хочется говорить «Джарвис» — **Ctrl+Shift+J** и говорите.

**Беседа без «Джарвис» каждый раз.** После любого ответа ещё **12 секунд** можно говорить дальше без обращения (`voice.pc.conversation_sec`, 0 — выключить).
Хотите поболтать подольше — скажите **«Джарвис, режим беседы»**: окно становится 2 минуты после каждой реплики (`conversation_mode_sec`), в трее подпись «режим беседы».
Выход — **«хватит болтать»** / **«свободен»** / **«всё, спасибо»**. Если Джарвис сам задал вопрос, отвечать можно всегда (`followup_sec`).
Пока окно открыто, любая громкая речь рядом с микрофоном считается обращением — в шумной комнате уменьшите `conversation_sec`.

**Джарвис говорит сам.** Напоминания о встречах и задачах он произносит вслух, даже если микрофон выключен в трее:
«Джарвис, напомни через 20 минут достать стирку» → через 20 минут в наушниках: «Сэр, «Достать стирку» — уже сейчас». Отключается в config.yaml: `voice.pc.speak_reminders: false`.

Всё, что сказано голосом, попадает в тот же чат на сайте с пометкой «голос». Wake word — Vosk, распознавание — Whisper (офлайн). Голос: по умолчанию Microsoft (нужен интернет, ставится сразу). Хотите полностью офлайн-голос Silero — запустите один раз **`silero.bat`** (скачает ~2 ГБ), после этого voice.bat сам его подхватит. Во время ответа микрофон отключается, чтобы Джарвис не слушал сам себя.

### Быстрый режим — чтобы ответ звучал почти сразу
Голос по умолчанию работает «на скорость»: ответ **озвучивается по предложениям, пока мозг ещё дописывает**, распознавание в быстром режиме,
модель Ollama держится в видеопамяти, для голоса берётся быстрая модель Groq. В `data\voice.log` после каждой команды строка `⏱ распознавание … · мозг … · голос зазвучал через …` — по ней видно, что тормозит.

Что ещё ускоряет (по убыванию эффекта):
1. **`gpu.bat`** (один раз, ~1 ГБ) — Whisper на видеокарте NVIDIA: распознавание 0.3 с вместо 2–3 с. После него перезапустите `start.bat` и `voice.bat`.
2. **Модель поменьше для видеокарты 6 ГБ** — `qwen2.5:7b` в 6 ГБ не влезает целиком и половина считается на процессоре (ответ 10–30 с).
   В окне `start.bat` при запуске написано, сколько процентов модели в видеокарте. Если не 100 % — в командной строке `ollama pull qwen2.5:3b`,
   потом в Настройках → мозг → модель `qwen2.5:3b` (или `model:` в config.yaml). Ответ станет 1–2 с. Личные команды-шаблоны (траты, задачи, встречи) от модели не зависят.
3. `voice.stt.model: base` в config.yaml — Whisper ещё в 3 раза быстрее на процессоре (чуть хуже слышит тихую речь).
4. `voice.pc.silence_sec` — пауза, после которой команда считается сказанной (0.8 с). Меньше — быстрее, но может обрезать, если задумались на полуслове.

- Не тот микрофон? `voice.bat --mics` покажет список, номер — в Настройки → голос → «микрофон».
- Слишком часто срабатывает / не слышит — проверьте, что в Windows выбран микрофон гарнитуры (Параметры → Звук → Ввод).
- `voice.bat` можно добавить в автозагрузку так же, как `start.bat` (см. `autostart.bat`).

## Голосовые в Telegram
Просто наговорите боту голосовое — «Джарвис, потратил семьсот на такси» или «что у меня сегодня».
- Распознаёт **Whisper прямо на вашем ПК** — аудио никуда не уходит. Первый запуск качает модель (~500 МБ), потом голосовое в 10 секунд разбирается за 2–5 с.
- Отвечает текстом (с расшифровкой того, что услышал) **и голосом** — Silero, тоже офлайн (40 МБ, качается сам). Если Silero не смог — голос Microsoft через интернет.
- `/voice` — переключить: голосом только на голосовые (по умолчанию) / всегда / никогда.
- Голос и модель меняются в Настройках → «голос» (`eugene`/`aidar` мужские, `baya`/`kseniya`/`xenia` женские; `medium` — точнее, но медленнее).
- Работает и с видео-кружочками.

Установка пакетов для голоса — `update.bat` (один раз, 5–10 минут: ставится torch ~700 МБ).

## Google Календарь (Джарвис → Google, в одну сторону)
Всё, что попадает в календарь Джарвиса (сайт, Telegram, голос), появляется в Google Календаре — на телефоне, часах, где угодно. Обратно из Google ничего не читается: источник правды — Джарвис. Удалили/перенесли у Джарвиса — в Google тоже. Нет интернета — операции копятся и доезжают сами.

Нужен свой бесплатный «ключ приложения» от Google (5 минут, карта не нужна, командная строка не нужна):
1. Откройте [console.cloud.google.com](https://console.cloud.google.com) → войдите в Google-аккаунт → вверху «Select a project» → **New project** → имя `Jarvis` → Create.
2. Слева **APIs & Services → Library** → в поиске `Google Calendar API` → **Enable**.
3. **APIs & Services → OAuth consent screen** → **Get started**: имя приложения `Jarvis`, ваша почта, Audience **External**, контакт — ваша почта → Create.
   Затем там же **Audience → Test users → Add users** → ваша почта. **Важно:** после нажмите **Publish app** (кнопка «Publish» в разделе Audience) — иначе Google будет отзывать доступ каждые 7 дней. Предупреждение «unverified app» для своего аккаунта — нормально.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID** → Application type **Desktop app** → имя `Jarvis` → Create. Скопируйте **Client ID** и **Client secret**.
5. На сайте Джарвиса: **Настройки → google календарь** → вставьте оба значения → «сохранить» → кнопка **подключить** → выберите аккаунт → **Continue** (на экране «Google hasn't verified this app» — Advanced → Go to Jarvis) → галочка «календарь» → Continue. Google вернёт вас на сайт, и все будущие события выгрузятся.

Подключать нужно **с того же компьютера, где работает Джарвис** (Google возвращает на `localhost:8765`). Дальше — с любого устройства. Если Google не открывается напрямую — укажите прокси в этой же секции (или он возьмёт прокси Telegram).
Ключи и токен лежат только у вас: `config.yaml` и `data/google_token.json`. Отключить — кнопка «отключить» (события в Google останутся).

## Обновление Джарвиса (когда я присылаю новые файлы)
1. Закрой окно Джарвиса.
2. Скопируй новые файлы поверх старых (папки `core/`, `web/site/`, файлы `run.py`, `requirements.txt`, `*.bat`). `config.yaml` и папку `data/` **не трогай** — там твои настройки и база.
3. Двойной клик по **`update.bat`** — доставит недостающие пакеты и покажет номер версии ядра.
4. `start.bat`. В первой строке должна быть новая версия (сейчас **v0.9.13**).

Командную строку открывать не нужно. `start.bat` теперь и сам подтягивает пакеты при каждом запуске — так что если забудешь `update.bat`, ничего страшного.
