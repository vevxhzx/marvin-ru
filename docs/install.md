# Установка и настройка

## Установка на Windows (10 минут)

**1. Python.** Скачайте [Python 3.12](https://www.python.org/downloads/release/python-3120/) → при установке поставьте галочку **«Add python.exe to PATH»**.

**2. Проект.** Скачайте архив (кнопка **Code → Download ZIP** или [Releases](../../../releases)), распакуйте, например, в `C:\Assistant`.

**3. `install.bat`** — двойной клик. Создаст окружение и поставит библиотеки (2–5 минут).

**4. `start.bat`** — двойной клик. Откроется браузер с **мастером настройки**:

- **Имя** — как звать ассистента и как ему обращаться к вам.
- **Мозг** — мастер сам определит видеокарту и предложит один из трёх режимов (см. ниже) и модель. Если выбрали локальную — кнопка «скачать модель» прямо в мастере.
- **Облако** — ключ провайдера (бесплатный, карта не нужна) с проверкой в один клик.
- **Telegram** — токен от [@BotFather](https://t.me/BotFather), затем «напишите боту» — ваш ID подставится сам.

После «готово» ассистент перезапустится и напишет вам в Telegram. Окно `start.bat` держите открытым (или добавьте в автозагрузку: `autostart.bat`).

> Все настройки потом меняются на сайте: ⚙ **Настройки**. Файл `config.yaml` править руками не нужно.

**С телефона:** `phone.bat` откроет порт в брандмауэре, а ⚙ Настройки → «с телефона» покажет QR-код с адресом; для доступа откуда угодно — [Tailscale](https://tailscale.com) (бесплатно). На телефоне «Добавить на экран Домой» — будет как приложение.

> 🔒 С самого компьютера сайт открыт свободно. С любого другого устройства API требует ключ доступа — он зашит в QR/ссылку из настроек и запоминается в браузере телефона на год. Ключ лежит в `data/api_token`; кнопка «новый ключ доступа» отзывает все старые ссылки. Так соседи по Wi-Fi (и чужие сайты в вашем браузере) не смогут писать ассистенту или выключить ПК.

## Docker (Linux / Mac / VPS)

Скачайте архив (кнопка **Code → Download ZIP** на этой странице) и распакуйте. В терминале, в папке проекта:

```bash
cp config.example.yaml config.yaml
docker compose up -d
```

Ссылку на мастер с ключом доступа контейнер печатает в лог (`docker compose logs assistant | grep "ключ"`) — из Docker браузер приходит не с localhost, поэтому без ключа API закрыт. Дальше сайт работает по cookie. Ollama поднимается вторым контейнером (`OLLAMA_URL=http://ollama:11434` уже прописан); для NVIDIA раскомментируйте блок `deploy` в `docker-compose.yml`. Без видеокарты выбирайте режим **cloud** и можете убрать сервис `ollama`.

База и картинки — в `./data`, настройки — `./config.yaml`. Голос на ПК в Docker не работает (микрофон) — это отдельный аддон для Windows.

## Голос на ПК (аддон, Windows)

1. `install_voice.bat` — поставит распознавание (Whisper), слово-активацию (Vosk), микрофон и трей (~700 МБ). По желанию спросит про **Silero** (офлайн-озвучка, ~2 ГБ) и **GPU для Whisper** (CUDA, ~1 ГБ; распознавание 0.3 с вместо 2–3 с).
2. Запущен `start.bat` → двойной клик **`voice.bat`**. Кружок в трее: серый — жду имя, синий — слушаю, жёлтый — думаю, зелёный — говорю.
3. «**Марвин**, потратил семьсот на такси» (ваше имя из мастера) — или **Ctrl+Shift+J** без обращения.

После ответа ещё 12 секунд можно говорить без имени; «режим беседы» — 2 минуты. Напоминания произносятся вслух. Голосовые в Telegram расшифровываются и выполняются как текст — ответ приходит текстом.
Пауза, после которой команда считается сказанной: ⚙ Настройки → голос → `silence_sec`.

Без аддона распознавание голосовых сообщений Telegram недоступно (можно включить Groq Whisper в настройках — тогда голос уйдёт в облако).

## Google Календарь (в одну сторону: ассистент → Google)

⚙ Настройки → google календарь → инструкция на 5 шагов (создать OAuth-клиент в Google Cloud, вставить Client ID/Secret, «подключить»). Всё, что попадает в календарь ассистента, появится в Google — на телефоне, часах, где угодно. Обратно ничего не читается.
