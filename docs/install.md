# Установка

Ставлю ассистента на Windows или Linux/macOS за 10–15 минут. Всё, что нужно для работы, — Python. Node нужен только если ты сам меняешь интерфейс сайта, а Ollama — только если хочешь, чтобы «мозг» работал локально.

Ссылки на остальные документы: настройка — [CONFIGURATION.md](CONFIGURATION.md), режимы приватности — [PRIVACY.md](PRIVACY.md), голос — [VOICE.md](VOICE.md), что-то сломалось — [troubleshooting.md](troubleshooting.md).

## Что понадобится

| Компонент | Версия | Зачем | Обязателен |
|---|---|---|---|
| **Python** | 3.11–3.13 (рекомендую 3.12) | ядро, бот, сервер, планировщик | да |
| Node.js | 18+ | только пересборка веб-интерфейса (`build_web.bat`) | нет |
| Ollama | последняя | локальная модель для режимов `local` / `hybrid` | нет |
| ffmpeg | любая | редкие аудиоформаты (OGG/Opus из Telegram читает PyAV и без него) | нет |

Про **Python** подробнее: установщик (`setup.py`) умеет создавать окружение на 3.10–3.13. Если у тебя стоит что-то новее (3.14+), установщик честно предупредит и попробует с ним, но готовых сборок под самые новые версии может не быть — проще поставить рядом Python 3.12 и запустить `install.bat` заново, он выберет 3.12 сам (на Windows через лаунчер `py`).

Собранный сайт (`web/site/`) уже лежит в проекте — открыть интерфейс можно без Node. Node нужен, только если ты правил `web/src` и хочешь пересобрать.

## Windows

1. Поставь [Python 3.12](https://www.python.org/downloads/release/python-3120/) и при установке отметь галочку **«Add python.exe to PATH»**.
2. Скачай проект (кнопка **Code → Download ZIP** или [Releases](../../../releases)) и распакуй, например, в `C:\Assistant`.
3. Двойной клик по **`install.bat`**.

Что делает `install.bat` (он вызывает `setup.py`):

- проверяет, что Python вообще есть, и просит поставить его, если нет;
- создаёт виртуальное окружение `.venv`;
- ставит библиотеки из `requirements.txt` (~300 МБ, 2–5 минут);
- создаёт `config.yaml` из `config.example.yaml` (если его ещё нет).

> Никаких моделей на этом шаге не качается: выбор и скачивание — в мастере при первом запуске and по твоему явному «да».

4. Двойной клик по **`start.bat`** — запустится ядро и откроется браузер с мастером настройки.

Окно `start.bat` держи открытым — это и есть ассистент. Закроешь окно — он выключится. Чтобы запускался с Windows, запусти `autostart.bat` (создаст ярлык в автозагрузке; на вопрос про голос ответь `Y` или `N`).

## Linux / macOS

```bash
./install.sh      # или двойной клик по install.command в Finder (macOS)
./start.sh        # или start.command
```

`install.sh` делает то же, что `install.bat`: `.venv`, зависимости, `config.yaml`. На macOS есть `.command`-файлы с теми же именами (`install.command`, `start.command`, `voice.command`) — их удобно открывать двойным кликом.

## Первый запуск: мастер настройки

При первом старте в браузере открывается `http://localhost:8765/setup` (в Docker — ссылка с ключом, см. ниже). Мастер идёт по шагам:

1. **Имя.** Как звать ассистента и как он обращается к тебе. Имя — это и обращение в чате, и слово-активация для голоса; лучше 2–3 слога по-русски.
2. **Мозг.** Мастер сам определяет железо (процессор, память, видеокарту) и предлагает режим: `local`, `hybrid` или `cloud`, а также подходящую модель Ollama. Подробно про режимы — [PRIVACY.md](PRIVACY.md) и [brain.md](brain.md).
3. **Модель.** Если выбран локальный режим — кнопка «скачать модель» в мастере (`ollama pull` идёт фоном, прогресс видно). Ollama должна быть установлена; если её нет, мастер предложит [ollama.com/download](https://ollama.com/download).
4. **Облако.** Ключ провайдера (Groq, OpenRouter, NVIDIA, DeepSeek или свой OpenAI-совместимый адрес) с проверкой в один клик. Для режима `local` шаг пропускается.
5. **Telegram.** Токен от [@BotFather](https://t.me/BotFather), затем напиши боту `/start` — мастер сам определит твой ID. Если `api.telegram.org` недоступен, есть поле прокси. Можно нажать «без Telegram» и подключить позже.
6. **Готово.** Мастер запишет `config.yaml` и попросит перезапуск.

Позже всё это меняется на сайте: ⚙ **Настройки** (файл `config.yaml` руками править не нужно). Пройти мастер заново: `http://localhost:8765/setup?again`.

## Запуск и обновление

- **`start.bat`** / **`./start.sh`** — запустить ядро (API + сайт + Telegram + планировщик). Логи — прямо в этом окне; голос — в `data/voice.log`.
- Второе окно `start.bat` не нужно: порт занят, ассистент уже запущен. Найти скрытый процесс — Диспетчер задач → «python» → снять задачу.
- **`update.bat`** / **`./update.command`** — после распаковки новой версии поверх: доставит библиотеки. Папку `data/` и `config.yaml` при обновлении не трогай — там база и настройки.

## Проверка окружения: doctor

`doctor.bat` (Windows) или `./doctor.sh` (Linux/macOS) — стандартный Python-скрипт `doctor.py`, работает даже если зависимости ещё не встали. Показывает:

- версию Python и наличие `.venv`;
- каких обязательных библиотек не хватает;
- есть ли `config.yaml` / `.env` и настроен ли Telegram;
- доступна ли папка `data/` для записи и есть ли база;
- на месте ли собранный сайт (`web/site`);
- отвечает ли Ollama и какие модели загружены;
- найден ли ffmpeg и есть ли интернет.

В конце — список «что починить». Если doctor говорит «всё на месте» — можно запускать `start.bat`.

## Голос (аддон, по желанию)

Голос — отдельный аддон, потому что тянет свои пакеты (распознавание, слово-активация, микрофон, трей). Про то, как он устроен, — [VOICE.md](VOICE.md).

1. **`install_voice.bat`** — базовые пакеты (~700 МБ). По ходу спросит:
   - **Silero** (офлайн-озвучка, ~2 ГБ) — если `N`, ассистент будет говорить голосом Microsoft Edge (нужен интернет);
   - **GPU для распознавания** (CUDA, ~1 ГБ) — если `Y` и есть NVIDIA-драйвер, whisper ускоряется с 2–3 с до ~0.3 с.
2. Убедись, что запущен `start.bat`, и запусти **`voice.bat`**. В трее появится кружок: серый — жду имя, синий — слушаю, жёлтый — думаю, зелёный — говорю.
3. Скажи «**Имя**, потратил семьсот на такси» — или нажми горячую клавишу, чтобы слушать без слова-активации.

Дополнительно: `silero.bat` — доставить Silero отдельно, `gpu.bat` — GPU для распознавания отдельно.

## Пересборка интерфейса

Собранный сайт уже в `web/site/`. Если ты правил `web/src`:

```bat
build_web.bat        :: Windows; проверит npm, поставит зависимости, соберёт в web/site
```

или вручную:

```bash
cd web && npm install && npm run build
```

Нужен Node.js 18+. После сборки перезапусти `start.bat`.

## Docker (Linux / macOS / VPS)

В проекте есть `Dockerfile` и `docker-compose.yml`. Контейнер собирает сайт (Node-этап) и кладёт Python-ядро. Голос с микрофоном ПК в контейнере не работает — это отдельный аддон для Windows.

```bash
cp config.example.yaml config.yaml
docker compose up -d
```

Что происходит:

- поднимается контейнер `assistant` на порту `8765` (проброшен наружу) и, если раскомментирован, `ollama` (`OLLAMA_URL=http://ollama:11434` уже прописан);
- база, бэкапы и картинки — том `./data`; настройки — `./config.yaml`;
- `docker-entrypoint.sh` создаёт `config.yaml` из примера, если его нет;
- браузер из Docker приходит не с loopback, поэтому API закрыт ключом. Ссылку на мастер с ключом контейнер печатает в лог: `docker compose logs assistant | grep "ключ"` → открой `http://localhost:8765/setup?t=…`.

Без видеокарты выбирай режим **cloud** и можешь убрать сервис `ollama`. Для NVIDIA раскомментируй блок `deploy` в `docker-compose.yml` (нужен nvidia-container-toolkit).

## Доступ с телефона

- **Домашний Wi-Fi / Tailscale.** `phone.bat` открывает порт в брандмауэре (нужны права администратора), а ⚙ Настройки → «с телефона» покажет QR со ссылкой, в которой зашит ключ доступа. Телефон запоминает ключ в cookie на год.
- **Сайт прямо в Telegram.** `funnel.bat` один раз поднимает публичный HTTPS-адрес через Tailscale Funnel; после перезапуска `start.bat` в чате с ботом появляется кнопка «Открыть». Вход подтверждает сам Telegram — ни QR, ни VPN на телефоне не нужны. Подробно и с разбором безопасности — [telegram-miniapp.md](telegram-miniapp.md).
- **Google Календарь** (в одну сторону: ассистент → Google) — ⚙ Настройки → google календарь, инструкция на 5 шагов внутри.

## Если что-то не встало

Сначала `doctor.bat` / `./doctor.sh`, потом [troubleshooting.md](troubleshooting.md). Частые поводы:

- `Python не найден` — не отмечена галочка «Add python.exe to PATH»; переустанови Python и запусти `install.bat` снова.
- Установка библиотек падает — чаще всего слишком новый Python (поставь 3.12 и удали `.venv`) или нужен VPN до `pypi.org`.
- Облако отвечает ошибкой — провайдер снял модель или протух ключ: ⚙ Настройки → облако → «проверить».
- `Cannot connect to host api.telegram.org` — Telegram заблокирован у провайдера; включи VPN или впиши прокси в настройках Telegram.
