# Что умеет — подробно

## Кто отвечает: облако или локальная модель
| Фраза | Кто | Почему |
|---|---|---|
| «привет, как дела», «спасибо», «что умеешь» | ☁️ облако (Groq) | разговор, личных данных не нужно |
| «что такое инфляция», «напиши поздравление», «как приготовить карбонару» | ☁️ облако | общий вопрос |
| «потратил 700 на такси», «завтра в 10 зубной», «что у меня сегодня», «сколько денег» | 🧠 локально (или ⚡ правила) | личные данные — никуда не уходят |
| «мысль: …», «покажи заметки», «мои долги» | 🧠 локально | то же |
| «облако, …» | ☁️ принудительно | |
| «локально, …» | 🧠 принудительно | |

Признак «личного»: слова про деньги/календарь/задачи/заметки/файлы, даты и время, числа, «у меня / мои». Всё остальное — разговор. Если облако выключено — всё делает локальная модель.

## Как Марвин понимает фразы (без «задача:» и «встреча:»)

| Пишете | Что делает |
|---|---|
| `ужин в 7 вечера`, `в 19 созвон`, `завтра утром зубной`, `в субботу баня` | **событие** в календаре на это время (если время сегодня уже прошло — на завтра), напоминание за 30 мин в Telegram |
| `починить полку`, `надо купить молоко`, `позвонить маме` | **задача** без срока |
| `сдать отчёт до пятницы`, `купить подарок до 20 сентября`, `до конца недели …` | **задача с дедлайном** (конец того дня) |
| `позвонить маме завтра в 18` | событие на 18:00 (есть точное время → напомнит) |
| фраза с датой, но непонятно что это | Марвин **спросит**: «календарь или задача?» — ответьте одним словом |
| `потратил 700 на такси`, `зп 120к`, `долг Сберу 120к плачу 8к 25-го` | финансы |
| всё остальное (мысли, идеи) | заметка в «Мозг», редактор причешет |

Дубли не плодятся: одно и то же событие/задача, сказанные дважды (или из TG и с сайта), не задваиваются.

## Сайт и Telegram — одно целое
История чата общая: что написали боту — видно в чате на сайте (с пометкой «из telegram»), и наоборот. Всё, что сделано из Telegram, голосом или планировщиком, появляется на открытых страницах сайта **само, без обновления** (живое соединение с ядром).

## Повторы, правки и откат — прямо в чате
| Фраза | Что произойдёт |
|---|---|
| «тренировка каждый пн ср пт в 19» | повторяющееся событие; в календаре видно на все недели, напоминание за 30 мин перед каждым |
| «каждый день в 8 зарядка», «ежемесячно 25-го платить за квартиру», «др мамы каждый год 14 марта» | ежедневный / ежемесячный / ежегодный повтор |
| «сегодня тренировки не будет» | пропускается только этот раз, правило остаётся |
| «перенеси ужин на 20:30», «перенеси созвон на пятницу» | событие сдвигается (если сказать только время — день остаётся тот же) |
| «переименуй ужин в ужин с семьёй» | новое название |
| «удали задачу про полку», «удали событие иван» | удаление по части названия |
| «отмена», «не то, удали», «отбой» | откат **последнего действия любого типа** — событие, задача, трата, доход, долг, заметка, ссылка |

Уточняющий вопрос («это событие или задача?») переживает перезапуск — ответить можно и через час.

## Напоминания
- События — за N минут (по умолчанию 30), повторяющиеся тоже.
- Задачи с дедлайном — **утром в день дедлайна** (после 9:00) и **за час** до срока.
- Приходят в Telegram и, если включить на странице настроек, **в браузер** (на iPhone — после «Добавить на экран Домой»).

## Команды-шаблоны — работают без нейросети (⚡)

| Скажи / напиши | Что будет |
|---|---|
| `сколько потратил на еду` / `за неделю` / `на такси за месяц` / `в августе` / `вчера` | Сумма, число операций, средний чек, остаток лимита |
| `куда ушли деньги за месяц` / `траты за неделю` / `сколько заработал за месяц` | Разбивка по категориям / доходы |
| `что у меня завтра` / `что в пятницу` / `что на выходных` / `какие планы на неделе` / `что 12 сентября` | События + дедлайны + платежи на этот день/период |
| `сколько денег` / `сколько на т-банке` / `сколько на наличных` | Балансы |
| `700 такси` / `кофе 350` / `такси 700 вчера` | Трата без глагола — если сумма и слово из категорий |
| `потратил 1200 на еду вчера` / `… позавчера` / `… 5 сентября` | Трата задним числом |
| `заплатил Ване 2000` / `вернул Ване 2000` / `перевёл Ване 3000` | Платёж по долгу «Ване» (ищет по имени в любом падеже) |
| `закрой долг Ване` | Долг гасится остатком и закрывается |
| `Ваня вернул 5000` / `вернули долг 5000` | Доход «вернули» |
| `перевёл 5000 на сбер` / `снял 3000 наличных` | Перевод между счетами (общий баланс не меняется; «Наличные» создаются сами) |
| `подписка яндекс плюс 399 25-го` / `регулярный интернет 900 5-го` / `аренда 42000 1-го` | Регулярный платёж |
| `отмени подписку яндекс` | Останавливает регулярный платёж |
| `лимит на еду 20000` / `убери лимит на еду` | Месячный лимит категории |
| `какие долги` / `кому я должен` / `что по долгам` | Список долгов с прогнозом |
| `напомни маме позвонить` | Спросит «когда?» — ответьте «завтра в 10» / «через час» |
| `спасибо` / `ок` / `хватит` / `Марвин` | Короткие ответы без похода в LLM |

Исправлено: «-350 кофе» больше не превращается в 350 000 ₽ (буква «к» из «кофе» считалась «тысячами»); «задача позвонить врачу завтра в 10» — задача с дедлайном, а не событие «Задача позвонить врачу»; «надо позвонить врачу завтра в 11» — событие «Позвонить врачу» без «надо»; «перенеси встречу с ваней» находит «Встреча с Ваней» (поиск по падежам — для событий, задач, долгов, подписок); «до 6 сентября», сказанное 7-го, — это вчера, а не 2027 год; «на еду» → категория Еда (падежи в категориях).

## Заказы, помодоро и конверты (0.9.2)

Для фриланса: заказ — это дедлайн в календаре, ожидаемый доход в прогнозе кассы и таймер работы в одном месте.

| Скажи / напиши | Что будет |
|---|---|
| `заказ: ролик для Пятёрочки, 25к, до пятницы` | Заказ с клиентом, суммой и дедлайном (клиент — слово с заглавной после «для/от»). Дедлайн попадает в календарь как «Сдать: …» |
| `пришёл аванс 10000 за ролик` / `получил оплату 15к за монтаж` | Доход «Фриланс» с привязкой к заказу; полная сумма закрывает заказ как оплаченный. Крупные суммы — через подтверждение |
| `заказы` / `кто мне должен` / `дедлайны` | Что в работе, что горит, сколько не оплачено |
| `таймер` / `таймер на ролик` / `помодоро на 40 минут по монтажу` | Один таймер на сайт + Telegram + голос. По истечении — звук (в браузере и на колонках ПК), сообщение с кнопками «ещё N / перерыв / хватит» (в Telegram), тост на сайте, голосом на ПК. Длина фокуса/перерывов, авто-перерыв, звук и громкость — «Настройки → общее → помодоро» (0.9.3) |
| `стоп` / `перерыв` / `сколько я сегодня работал` | Остановить · перерыв 5 мин · минуты фокуса за день |
| `сдал ролик` / `правки по ролику` / `отменили монтаж` | Смена статуса (через модель — `update_order`) |
| `цель: подушка 300к к марту` / `копим на камеру 120 тысяч` | Конверт с суммой в месяц, чтобы успеть |
| `отложил 10к в подушку` / `взял 5к из подушки` | Расход «Накопления» с привязкой к цели — деньги уходят из «свободных», прогноз честный. Достигли — цель закрывается сама |
| `цели` / `конверты` | Прогресс по каждой |
| `50/30/20` | Обязательное / хотелки / накопления от дохода за месяц (корзина у категории — Финансы → категория) |
| `сравни с прошлым месяцем` | На тот же день прошлого месяца: траты, средний чек, по категориям |
| `на сколько хватит` | Runway: свободные деньги ÷ средний расход в день против дней до дохода |
| `хватит ли на платежи` | Ближайшие регулярные платежи против остатка на счетах (при нехватке Марвин сам предупредит в 10:30) |

На сайте: раздел **Заказы** (таймер, ставка в час, средний чек, доход по месяцам, фокус по дням, клиенты), мини-таймер в боковой панели на всех страницах (на телефоне — в шапке), блок «заказы» на «Сегодня», в **Финансах** — «конверты» и «техники» (50/30/20, месяц к месяцу, на сколько хватит, годовые: сколько откладывать в месяц на страховку/налоги). Telegram: `/orders`, `/pomo [заказ|stop]`, `/goals`.

## Люди, клиенты и граф связей (0.9.4)

Марвин сам помнит, кто есть кто. Достаточно один раз сказать, кто это — дальше заказы, встречи, задачи, долги и мысли
с этим именем (в любом падеже: Ваня / Ване / Иваном) собираются в одну карточку.

| Скажи / напиши | Что будет |
|---|---|
| `человек: Лена, сестра, др 12.03` / `клиент: Пятёрочка, магазин` | Карточка человека или клиента; «он же»-имена, день рождения, теги, заметка |
| `что по Ване` / `кто такая Лена` / `карточка клиента Пятёрочка` / `досье на Петрова` | Всё про него: заказы и деньги (получено / ждём / в работе), долги, ближайшая встреча, задачи, мысли, последний контакт |
| любая фраза с именем: `созвон с Ваней завтра в 15`, `отправить Ване правки` | Марвин делает своё дело и одной строкой напоминает важное: «👤 Иван Петров: не оплачено 80 000 ₽, долг «Долг Ване» 5 000 ₽, встреча сегодня в 15:00». Не повторяет то, что вы только что создали, и не бубнит чаще раза в 3 часа на человека |

- **Сайт → Люди** (Alt+9): плитки с тем, что важно сейчас (заказы в работе, ждём оплаты, скоро др), поиск по имени/прозвищу/тегу,
  карточка с правкой полей и ссылками в заказы/календарь/задачи/мозг, «спросить ассистента» — открывает чат с «что по …».
- **Главная → «кто сегодня»**: кто из людей есть в сегодняшнем календаре + строка контекста. Блок не показывается, если никого нет.
- **Мозг → граф**: люди · заказы · мысли · ссылки · теги · долги. Связи выводятся сами: имя в тексте, общий `#тег`,
  `[[ссылка на другую мысль]]`, похожие по смыслу записи (пунктир). Клик — фокус на окрестности, двойной клик — открыть,
  колесо — масштаб, легенда — скрыть тип. Данные: `GET /api/graph?focus=person:3`, обратные ссылки `GET /api/graph/backlinks/note/12`.
- Утренний дайджест добавляет до двух строк «кто сегодня». API: `GET/POST /api/people`, `GET/PUT /api/people/{id}`, `GET /api/people/today`.

## Режим фрилансера и финансовый пульс (0.9.5)

«Настройки → фриланс → я фрилансер». Выключен — заказов, таймера и всего ниже нигде нет. Включён — каждая штука своим тумблером.

| Скажи / напиши | Что будет |
|---|---|
| `кто задерживает` / `кто тянет с оплатой` / `задержки по оплатам` | Сданные, но не оплаченные заказы старше порога: клиент, сумма, сколько дней, за сколько он обычно платит |
| `заказы` | Как раньше + строки про задержки и налог за месяц (если включены) |
| утренний дайджест | После дедлайнов — до двух строк «💸 Пятёрочка задерживает 25 000 ₽ за «Ролик» — 5 дн. после сдачи (обычно платит за 4 дн.)» |
| недельный отчёт | «💼 За неделю по заказам: 60 000 ₽ · 18 ч фокуса · 3 333 ₽/ч · налог ~3 600 ₽» + кто задерживает |

- **Задержкой считать** — ползунок 0–30 дней после сдачи. Ожидаемая дата оплаты в прогнозе кассы берётся из истории клиента (медиана «сдал → оплатил»).
- **Ставка по факту** — в карточке заказа, только если есть часы по таймеру: `12 ч из 8 · 2 000 ₽/ч · план 3 000`; перерасход больше порога подсвечивается.
- **Налог** — 4 / 6 % НПД или 13 %: ожидаемые оплаты в прогнозе и runway идут за вычетом; в «Заказах» — «налог 6 % за месяц ~9 300 ₽ (из них … с ожидаемого)».
- Ничего не удаляется и не пересчитывается задним числом — это только то, что вы видите.

## Присутствие, цели и лента (0.10)

Марвин теперь не только отвечает — он **знает, что происходит**, и сам решает, когда сказать, а когда промолчать.

**Присутствие.** Тот же пульс voice.bat, что считает экранное время, теперь даёт состояние: сели · отошли · давно нет · рендер идёт · 4 часа без перерыва. Модель видит одну строку «Сейчас: за ПК 2 ч 40, Premiere Pro (работа) последние 50 мин» — без заголовков окон. Клик по точке в шапке сайта — карточка: вы за ПК/отошли, что открыто, что крутится в фоне, чего Марвин ждёт от вас, сколько инициатив на сегодня осталось.

**Одно решение «сказать / позже / молча».** Тихие часы, лимит в день, вас нет за ПК (→ отложить и отдать, когда вернётесь, пачкой), идёт рендер или игра (→ позже), только что сели (→ через 2 минуты), вы прямо сейчас печатаете (→ через минуту). Ваши напоминания (встречи, дедлайны) — всегда сразу. «Что происходит?» — покажет всё это одной фразой.

**Цели → вехи → задачи.** Не todo-лист, а то, ради чего он.

| Ты пишешь | Что происходит |
|---|---|
| `цель: собрать портфолио до конца года, потому что хочу брать заказы дороже` | цель с «зачем» и сроком (месяцы: «к декабрю», «за полгода»). С суммой («цель: подушка 300к») — по-прежнему денежный конверт |
| `веха: 3 сцены в портфолио` | первый ощутимый рубеж; при одной цели привязывается сама, иначе «веха: … к цели …» |
| `задача: сцена кухни к вехе 3 сцены` | обычная задача, привязанная к вехе; закрыл — «Шаг к «Портфолио». Следующий: «сцена спальни»» |
| `что мне сегодня делать?` / `фокус дня` | 1–3 шага, которые двигают цели (горящие → главная цель → остальные по очереди). Заблокированные — отдельно «мешает» |
| `сцена кухни заблокирована: жду референсы` / `… разблокирована` | задача уходит из фокуса в «мешает» и обратно |
| `мои цели` | прогресс по целям и вехам (+ денежные конверты, если есть) |
| `цель портфолио достигнута` / `закрой цель …` / `цель … активна` | цель сама **не закрывается** — когда все вехи закрыты, Марвин спрашивает |

Веха может быть заказом (`order_id`): сдан/оплачен — веха закрыта. Цель, которая стоит 14+ дней без единого шага, всплывает раз в неделю: «шаг, пауза или закрываем?» с кнопками. На «Сегодня» — карточка **«фокус дня»**, в «Задачах» — вкладка **«цели»** (утренний дайджест тоже начинается с фокуса).

**Лента дня** — «что я сегодня делал», «что было вчера», «что происходило с проектом вчера»: сессии за ПК (≥15 мин), что записал/закрыл, когда отходили, что сделал Марвин, разговор (счётчиком, без текста), его провалы. Память → вкладка «лента».

**Решения** — `решил: беру заказ у Лены только с предоплатой, потому что в прошлый раз ждал месяц` → через месяц `почему я так решил про Лену` вернёт ваши же слова. Это заметки с тегом `решение`, ничего нового не хранится.

**Рутины** — повторяющиеся события календаря: `мои рутины`, `как дела с тренировкой` — серия, пропуски подряд, N из M за месяц. Два пропуска подряд у привычки, которая держалась — один вопрос, не нотация.

**Самопроверка** — `проверь себя`: Ollama, облако, малая модель, ПК-клиент, Telegram, провалы за сутки, очередь Google-календаря, бэкап, зависшие фоновые работы, место на диске — выводами и что сделать. Ночная проверка пишет в чат только когда стало хуже (один раз).

**Фоновые работы** (бэкап, ночная уборка памяти) видны в карточке состояния; упали — Марвин скажет; `стоп` — остановит текущую. Перезапуск после паузы ≥10 мин с висящим вопросом: «Перезапустился. Висело: жду «да» на выключение ПК. Актуально ещё?».

## Доска: раскадровки, сценарии, мысли на плоскости (0.11)

Отдельный пункт меню **«доска»** (Alt+0): бесконечный лист, как в Miro/FigJam, но без Miro — пять типов объектов и карандаш, всё в базе Марвина, поэтому он **видит содержимое**.

| Что | Как |
|---|---|
| Объекты | **стикер** (6 цветов) · **текст** (маркдаун-лайт: `#` заголовок, `**жирный**`, `_курсив_`, `- список`, строки «СЦЕНА N» и ИМЕНА ПЕРСОНАЖЕЙ оформляются сами) · **кадр** (16:9 · 9:16 · 1:1 · 4:5 · 4:3 · 2.39:1, картинка внутрь, подпись, длительность) · **картинка** · **стрелка** (концы прилипают к точке на рамке объекта, тянутся за ним; за середину — перенос; концы можно перетащить) · **карандаш** (5 цветов, 4 толщины) · **ластик** (стирает штрих) |
| Текст | у любого текста: шрифт (Inter / Arial / Serif / Mono), размер, жирный, курсив, выравнивание, цвет (палитра + свой). Подписи кадров масштабируются вместе с кадром |
| Управление | как в FigJam: стартовый инструмент — **рука** (тянуть холст левой кнопкой), колесо — двигать, Ctrl+колесо / пинч — масштаб, пробел или средняя кнопка — рука в любом режиме; **инструмент + протянуть** — объект нужного размера сразу (клик — стандартный); рамка выделения, Shift/Ctrl+клик — добавить; ручки размера (у стикера/картинки/кадра — с пропорцией, Shift — свободно у текста), ручка поворота над объектом (Shift — по 15°); группа масштабируется за угол общей рамки; выравнивание выделенных (по краям/центру/в ряд); правая кнопка — меню; вставка текста/картинки из буфера, перетаскивание файлов (на кадр — внутрь) |
| Клавиши | H рука · V выбор · S стикер · T текст · F кадр · A стрелка · P карандаш · E ластик · I картинка · Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y · Ctrl+C/V/X/D · Ctrl+A · Delete · стрелки (Shift — по 10) · Alt+тянуть — копия · Ctrl+тянуть — к сетке · PgUp/PgDn — план · Ctrl+1 всё · Ctrl+2 выделенное · Ctrl+0 100% · Enter — править · Esc — закончить/снять выделение. Полный список — кнопка ⌨ в шапке доски |
| Сохранение | вся доска одним снимком через полсекунды после жеста (одна ревизия — один запрос, повтор при обрыве сети не создаёт дублей); статус «сохраняю… / сохранено» в шапке; если доску изменили в другой вкладке или из чата — баннер «подтянуть и оставить мои правки / взять их версию», ничего не затирается молча |
| Раскадровка | новая доска «раскадровка» — сетка N пустых кадров под нужное соотношение; «+» — следующий кадр в ряд; номера пересчитываются по положению; у кадра — длительность в секундах, сверху и в панели справа — общий хронометраж; **экспорт** — PNG всей доски/выделенного или лист раскадровки на печать (→ PDF) |
| Сценарий | доска «сценарий» — один длинный текст с шаблоном сцен, рядом стикеры и референсы |
| Заказ ↔ доска | в карточке заказа кнопка **«доска»** (создаст, если нет); доска заказа видна в графе «мозга» и в контексте заказа |
| Мозг → доска | на карточке мысли кнопка «на доску» — стикер (или картинка, если это фото), с привязкой к мысли |
| Чат и голос | `доска: название` · `раскадровка: ролик на 8 кадров 9:16` (найдёт заказ по названию и привяжет) · `сценарий: название` · `на доску: мысль` / `кинь … на доску ролика` · `что по доске …?` · `мои доски` |
| Телефон | рука по умолчанию, пинч, стикеры/текст/кадры/карандаш, отмена; тонкая раскладка — с компьютера |

Хранится: `board` (доска, ревизия, камера, привязка к заказу/цели) и `board_item` (объекты, JSON под тип); картинки — в `data/media/boards` (только PNG/JPG/WebP/GIF, проверяются и пережимаются, внешние URL не принимаются). Доска не удаляется — уходит в архив («вернуть» — в списке). Что **не** делается намеренно: совместная работа, фигуры/блок-схемы, слои/группы/автолейаут — это уже Figma.

## Всё остальное — одним списком

| Ты пишешь | Что происходит |
|---|---|
| `потратил 700 на такси` | Трата → категория «Транспорт» → минус с Т-Банка |
| `купил продукты 2500` / `-350 кофе` | Трата, категория определится сама |
| `зп 120 тыс` / `+5000 вернули долг` | Доход |
| `баланс т-банк 85000` | Сверить баланс с приложением банка |
| `отмени последнюю` | Откатить последнее действие (трату, задачу, событие, массовое удаление) |
| `сотри все финансы за последние 2 дня`, `удали задачи за неделю`, `очисти историю чата`, `удали все заметки за сегодня` | Массовая чистка. Сначала покажет, сколько записей и на какую сумму, и спросит «да/нет». После «да» удалит и пересчитает балансы; «отмена» вернёт всё из корзины |
| 🎙 «Марвин, …» в микрофон ПК | `voice.bat` — wake word, ответ в наушники, иконка в трее (см. «Голос на ПК») |
| 🎙 **голосовое сообщение** | Распознаётся на вашем ПК (Whisper), выполняется как текст, ответ приходит текстом + голосом. Можно начинать с «Марвин, …» |
| `поменяй голос` / `голос ксения` | Сменить голос ответа (Евгений, Айдар, Бая, Ксения, Ксения-2, Дмитрий, Светлана) — или в Настройках → голос с прослушиванием |
| `/voice` | Переключить голосовые ответы: на голосовые / всегда / никогда |
| `иду играть` / `/game` | Игровой режим: модель выгружается из видеопамяти, вопросы идут в облако. `игра окончена` — вернуть. (Без этого Ollama и так выгружает модель через 5 минут тишины) |
| `/diag` | Кто отвечает и за сколько: Ollama, облако, прокси. Если бот «печатает» и молчит — начни с этого |
| `встреча в среду в 15:00 с Ваней` | Событие в календаре + напоминание за 30 мин |
| `напомни завтра в 10 позвонить врачу` | Событие + напоминание за 10 мин |
| `задача: сдать отчёт через 3 дня` / `надо купить молоко` | Задача (с дедлайном или без) |
| `сделал молоко` | Закрыть задачу по части названия |
| `долг Сберу 120к плачу 8к 25-го` | Долг + авто-платёж каждое 25-е + прогноз «закроется через 15 мес.» |
| `должен Ване 5000` | Просто долг без графика |
| `мысль: …` / `запомни …` / `идея …` | Заметка во «второй мозг» |
| Любая ссылка (+ комментарий) | Сохраняется с заголовком, обложкой, доменом |
| `что сегодня` | События, задачи, платежи, баланс |
| `финансы`, `задачи`, `календарь`, `долги` | Быстрые отчёты |
| Всё остальное | Уходит в локальную LLM (если есть Ollama) → она сама вызывает нужные действия |

Команды в меню бота: `/today /money /tasks /events /debts /forecast /week /report /voice /game /diag`.

Автоматически:
- ⏰ напоминания о событиях,
- ☀️ утренний дайджест в 08:30 (меняется в `config.yaml`),
- 🌙 в 21:00 — вопрос про незакрытые задачи с дедлайном, кнопки «сделал / завтра» (не чаще раза в день),
- 🔕 тихие часы 23–8 (`notifications.quiet_from/quiet_to`): ночью Марвин сам не пишет, только напоминания, которые вы поставили,
- 💳 проведение регулярных платежей в срок,
- 💾 бэкап базы каждую ночь в `data/backups/` (хранится 30 дней).

## Управление компьютером, финансы, мозг, Telegram
Работает, когда запущен `voice.bat` (он же теперь сообщает ядру «я на связи» — на сайте точка в шапке пульсирует, когда Марвин слушает/думает/говорит).
Команды можно давать **голосом, в Telegram или в чате сайта** — всё равно выполнятся на ПК:

| Скажи / напиши | Что будет |
|---|---|
| `открой ютуб` / `открой habr.com` / `открой калькулятор` / `запусти телегу` / `открой загрузки` | Сайт, программа (ищет и по ярлыкам меню «Пуск») или папка |
| `найди файл договор` | Ищет в Документах/Рабочем столе/Загрузках (и дисках D–F), самый свежий показывает в Проводнике, список — в чат. С установленным Everything (voidtools) ищет по всему диску мгновенно |
| `разбери рабочий стол` / `прибери в загрузках` / `разгреби бардак` (обе папки) | **Уборка (0.9.3).** Сначала план: по каждой папке — категории (Документы, Картинки, Скриншоты, Видео, Проекты .aep/.psd, Архивы, Установщики…), сколько и какие файлы, что не трогает (папки, ярлыки, скрытые, недокачанное, свежее, открытое в программе). Скажите «да» — файлы переедут в `Рабочий стол/Разобрано/<Категория>` (для Загрузок — в `Загрузки/Разобрано`). Ничего не удаляется. «отмени уборку» — всё вернётся на место по журналу. Ночная уборка Загрузок (файлы старше N дней, 3–6 утра, отчёт в Telegram) — `voice.pc.tidy_downloads_days: 14`, по умолчанию выключена |
| `пауза` / `дальше` / `следующий трек` / `громче` / `тише` / `без звука` | Медиа-клавиши — работает с любым плеером и браузером |
| `что на экране` / `переведи это` / `что это за ошибка` | Скриншот → модель зрения → ответ. Локально: `ollama pull qwen2.5vl:3b` и укажите её в Настройки → мозг → «модель зрения». Без неё скриншот уйдёт в Groq (отключается: «скриншоты можно отправлять в облако» → выкл) |
| `запомни это` | Содержимое буфера обмена (текст или ссылка) → в Мозг |
| `статус костюма` | Процессор, память, температура, видеокарта, диски, аптайм |
| `заблокируй компьютер` / `выключи компьютер` / `перезагрузи` / `спящий режим` | Как сказано. Выключение — через 30 с, «отмена выключения» успеет |
| `Марвин, стоп` / `хватит` во время ответа | Перебивает — Марвин замолкает |
| `Марвин, запиши мысль` | Диктовка до минуты (пауза 2.5 с = конец) → заметка в Мозг |
| **Утренний доклад** | Сели за ПК утром после 6+ часов простоя → Марвин сам расскажет план дня. Выкл: `voice.pc.morning_report: false` |
| **Ночной режим** 23:00–7:00 | Говорит тише, вслух — только напоминания о встречах и дедлайнах |
| **Игровой режим сам** | Запустили CS2/Dota/GTA/Valorant… — мозг выгружается из видеокарты; закрыли — вернулся. Свои игры: `voice.pc.games` |
| `Секунду…` | Если мозг думает дольше 1.5 с, Марвин так и скажет, чтобы не было тишины |

**Финансы.** `прогноз` / `хватит ли до зарплаты` — касса на 30 дней с учётом регулярных и средних трат, безопасная сумма в день (график на «Сегодня» и в «Финансах»).
`подписки` — находит ежемесячные списания, которых нет в регулярных (клик по чипу на сайте добавляет). **Выписка Т-Банка** (CSV/PDF/Excel): пришлите файлом в Telegram или кнопка «выписка» в Финансах — дубликаты не задваиваются, переводы между своими счетами пропускаются.
**Фото чека** в Telegram → трата (читает только локальная модель зрения — чеки в облако не уходят). Лимиты по категориям: в 21:00 предупредит про 80 % и про перерасход (один раз на порог).

**Мозг.** Ссылки получают выжимку в 3–5 пунктов (локальная LLM), у заметок при наведении показываются связанные по смыслу. Воскресенье 19:00 — «Неделя в мыслях» (`/week`) и открытка-отчёт PNG (`/report`, `/report 30` — месяц); 1-го числа — итоги месяца. Утренний дайджест теперь тоже с картинкой-дашбордом.

**Telegram.** Под напоминаниями кнопки ✅ / ⏰ +1 час / 📅 завтра. Дни рождения («ДР Вани» в календаре) — напомнит за 3 дня с идеями подарка.

**Сайт.** `Ctrl+K` — палитра команд (страницы, действия, поиск по Мозгу, любой вопрос Марвину прямо там), `Ctrl+J` — чат (одна история с Telegram). Микрофон в шапке (Chrome/Edge) — сказать с сайта. Блоки «Сегодня» перетаскиваются. Тепловая карта и стрик — сколько дней подряд ведёте записи (`стрик`).

**Мелочи.** `подкинь монетку`, `выбери за меня: пицца или суши`, `протокол Чистый лист` (архивирует выполненные задачи старше месяца — ничего не удаляет), `я Железный человек`, `спокойной ночи`.
Частые общие вопросы кэшируются на сутки — облако не ждём второй раз. Распознавание речи можно перевести на Groq Whisper (~1 с): Настройки → голос → «через Groq Whisper» (по умолчанию выкл — голос уйдёт в облако).

## Мозг: коротко и с фото
- Пишите `мозг` (или `мозг-`, `мозг:`, «в мозг») и дальше что угодно — всё уходит в мысли: `мозг- идея для ролика про кофе`.
  Работает в Telegram, в чате на сайте и голосом («мозг, …»).
- Фото в Telegram: подпись `мозг …` → фото сохраняется в мозг вместе с подписью и кратким описанием (по нему потом ищется).
  Фото без подписи → Марвин реагирует по-человечески, под ответом кнопка **💾 в мозг**. Чек → трата, как раньше.
- На сайте, страница «мозг»: кнопка 🖼 рядом с полем, а также Ctrl+V скриншота или перетаскивание файла. Вкладка «фото».
- Картинки лежат в `data/media/` (ужимаются до 1600px), в облако уходят только на описание — если зрение выбрано облачное.
