# Что умеет — подробно


| Область | Примеры фраз | Что происходит |
|---|---|---|
| 💸 Деньги | `700 такси`, `зп 120 тыс`, `перевёл 5000 на наличные`, `сколько потратил на еду за неделю`, `куда ушли деньги` | Категории сами, балансы, лимиты, графики cashflow |
| 📉 Долги и подписки | `долг банку 120к плачу 8к 25-го`, `подписка яндекс 399 25-го`, `закрой долг Диме` | Автоплатежи в срок, прогноз «закроется через N мес.» |
| 📅 Календарь | `встреча завтра в 15 с Димой`, `напомни через 20 минут достать стирку`, `перенеси встречу на пятницу` | Напоминания в Telegram (и голосом), повторы, push в Google Календарь |
| ✅ Задачи | `надо сдать отчёт через 3 дня`, `сделал молоко` | Дедлайны, повторные напоминания, свайпы на телефоне |
| 🧠 Второй мозг | `мозг: …`, `запомни …`, любая ссылка, фото с подписью | Заголовок, обложка, авто-теги, смысловой поиск |
| 🧾 Чеки | фото чека в Telegram | Сумма и категория распознаются, трата записывается |
| 🖥 Компьютер | `открой браузер`, `найди файл договор`, `что на экране` | Открывает, ищет, показывает. **Никогда ничего не удаляет** |
| 🧹 Уборка | `разбери рабочий стол`, `прибери в загрузках`, `отмени уборку` | Сначала план (что куда по категориям, что не трогает), после «да» переносит в `Разобрано/<Категория>`. Ярлыки, папки, открытые и свежие файлы не трогает, ничего не удаляет, «отмени уборку» возвращает всё. Ночная уборка Загрузок — `voice.pc.tidy_downloads_days`, выкл по умолчанию |
| 🎙 Голос | «Марвин, …» в микрофон ПК; голосовые в Telegram | Wake word офлайн (Vosk), распознавание Whisper, озвучка Silero/Edge |
| 💼 Заказы (фриланс) | `заказ: ролик для Пятёрочки, 25к, до пятницы`, `пришёл аванс 10000 за ролик`, `заказы`, `сдал ролик` | Дедлайн в календаре и утреннем дайджесте, ожидаемая оплата в прогнозе кассы, кто должен, ставка в час, средний чек, клиенты |
| 🍅 Помодоро | `таймер на ролик`, `помодоро на 40 минут`, `стоп`, `перерыв`, `сколько я сегодня работал`, `/pomo` | Один таймер на сайт, Telegram и голос; мини-таймер в боковой панели; по истечении — звук (браузер и колонки ПК) и кнопки «ещё N / перерыв / хватит»; длина фокуса/перерывов, авто-перерыв, звук — в «Настройки → общее → помодоро»; минуты идут в заказ |
| 🎯 Конверты и техники | `цель: подушка 300к к марту`, `отложил 10к в подушку`, `50/30/20`, `сравни с прошлым месяцем`, `на сколько хватит`, `хватит ли на платежи` | Отложенное уходит из «свободных» (расход «Накопления»), цель закрывается сама; корзина категории задаётся в её редакторе; предупреждение, если на ближайшие платежи не хватает |
| 👤 Люди и клиенты | `человек: Лена, сестра, др 12.03`, `клиент: Пятёрочка`, `что по Ване`, `кто такая Лена`, `досье на Петрова` | Карточка собирается сама из всего, где всплыло имя (в любом падеже, по «он же»-именам): заказы и деньги, долги, встречи, задачи, мысли, последний контакт. Раздел «Люди» на сайте (Alt+9), блок «кто сегодня» на главной, строка-подсказка в чате, когда упомянут известный человек (неоплата, долг, встреча — не чаще раза в 3 часа) |
| 🎬 Доска | раздел «Доска» (Alt+0), `раскадровка: ролик на 8 кадров 9:16`, `сценарий: название`, `на доску: мысль`, `кинь … на доску ролика`, `что по доске …?`, `мои доски` | Бесконечный лист как в FigJam: рука по умолчанию, колесо — двигать, Ctrl+колесо — масштаб, пробел — рука. Стикеры (6 цветов), текст (шрифт/размер/жирный/курсив/выравнивание/цвет, маркдаун-лайт), кадры (16:9 · 9:16 · 1:1 · 4:5 · 4:3 · 2.39:1) с картинкой, масштабируемой подписью и длительностью, картинки, стрелки (прилипают к рамке, переносятся, концы перетаскиваются), карандаш, ластик. Объекты создаются протягиванием; ручки размера и поворота, группа за угол, выравнивание; Ctrl+Z/Y, C/V/X/D, A, стрелки, PgUp/PgDn (полный список — ⌨). Раскадровка нумеруется по положению, считает хронометраж, экспорт PNG/печать в PDF. Сохранение одним снимком с ревизией; правки из чата в открытой вкладке сливаются через баннер, не затираются. Доска привязывается к заказу, мысль кладётся стикером, узел в графе. Удаление = архив |
| 🕸 Граф связей | Мозг → «граф» | Люди · заказы · мысли · ссылки · теги · долги. Связи выводятся сами: имя в тексте, общий `#тег`, `[[ссылка на мысль]]`, похожие по смыслу записи. Клик — фокус, двойной клик — открыть, колесо — масштаб |
| 💸 Финансовый пульс | «Настройки → фриланс», `кто задерживает`, `кто тянет с оплатой` | Режим фрилансера одним тумблером (заказы, таймер, дедлайны, оплаты в прогнозе). Внутри — по отдельности: задержки оплат (порог в днях, «обычно платит за N дн.», строки в дайджесте и на главной), ставка факт/план по таймеру, налог 4/6/13 % (вычитается из ожидаемого в прогнозе), три строки фриланса в недельном отчёте. Выключено — нигде не показывается |
| ↩️ Откат | `отмени последнюю`, `сотри финансы за 2 дня` | Любое действие откатывается; массовые — с подтверждением |
| 🎯 Цели (0.10) | `цель: собрать портфолио до конца года, потому что хочу брать заказы дороже`, `веха: 3 сцены`, `задача: сцена кухни к вехе 3 сцены`, `что мне сегодня делать?`, `мои цели`, `X заблокирована: жду макет`, `цель X достигнута` | Цель → вехи → задачи; прогресс по закрытым задачам и заказам; «фокус дня» — 1–3 шага, которые двигают цели (карточка на «Сегодня», вкладка «цели» в задачах, первая строка утреннего дайджеста). Цель не закрывается сама — когда все вехи закрыты, ассистент спросит. С суммой (`цель: подушка 300к`) — это по-прежнему конверт |
| 👁 Присутствие (0.10) | `что происходит?`, клик по точке в шапке сайта | Из пульса voice.bat: за ПК / отошли / давно нет · что открыто · рендер · фон · чего ассистент ждёт. Модель видит одну строку «Сейчас: за ПК 2 ч 40, Premiere Pro» — без заголовков окон. Любая инициатива проходит через одно решение «сейчас / позже / молча»: тихие часы, лимит в день, вас нет за ПК (отложить до возвращения), рендер/игра, только что сели |
| 🧾 Лента и решения (0.10) | `что я сегодня делал`, `что было вчера с проектом`, `решил: … потому что …`, `почему я так решил про Лену`, `мои рутины`, `проверь себя` | Лента дня — сессии за ПК, действия, события присутствия, разговор счётчиком, провалы ассистента (Память → «лента»). Решения — заметки с тегом «решение». Рутины — серии по повторяющимся событиям. Самопроверка — что не так и что сделать, в чат только когда стало хуже |

Плюс: утренний дайджест, вечерний вопрос про незакрытые задачи («сделал / завтра» кнопками), недельный отчёт, ночные бэкапы базы, экспорт в JSON/CSV, импорт банковских выписок, тёмная тема, ⌘K-палитра. Ночью (23–8, настраивается) ассистент сам не пишет — только напоминания, которые вы поставили. Крупные суммы (от 100 000 ₽) и выключение компьютера — только после вашего «да».
