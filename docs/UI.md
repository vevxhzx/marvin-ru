# Веб-интерфейс

Открой **http://localhost:8765** — сайт раздаётся тем же процессом, что и бот, ничего дополнительно ставить не нужно. С телефона — QR/ссылка из ⚙ Настроек или кнопка внутри Telegram (см. [INSTALL.md](INSTALL.md) и [telegram-miniapp.md](telegram-miniapp.md)). Работает как приложение (PWA): «Добавить на экран Домой».

## Разделы

| Раздел | Что там |
|---|---|
| **Сегодня** (`Alt+1`) | Приветствие, баланс, «свободно в месяц», события дня, ближайшие, задачи, платежи недели, лента памяти. Блоки перетаскиваются, их можно включать/выключать и менять плотность |
| **Задачи** (`Alt+2`) | Группы: просрочено / сегодня / на неделе / позже / без срока. Вкладка **«цели»** — карточки целей с вехами, прогрессом и фокусом дня. Быстрый ввод понимает даты: «позвонить маме завтра в 18» |
| **Календарь** (`Alt+3`) | Месяц и неделя, клик по дню → события, создание/редактирование/удаление, повторы, связанные задачи и дедлайны заказов |
| **Финансы** (`Alt+4`) | Денежный поток (доход − регулярные − долги = свободно), траты по категориям, график по дням, долги с прогресс-баром и датой закрытия, регулярные, счета, все операции, конверты-цели и фин-техники (50/30/20, месяц к месяцу, runway) |
| **Заказы** (`Alt+5`) | Таймер работы, ставка в час, средний чек, доход по месяцам, фокус по дням, клиенты, этапы заказа, «кто задерживает», налог |
| **Мозг** (`Alt+6`) | Мысли и ссылки карточками, смысловой поиск, теги, фото, граф связей. Редактор приводит «как есть» к аккуратному виду, оригинал сохраняется |
| **Доска** (`Alt+0`) | Бесконечный лист: стикеры, текст, кадры (соотношения, картинки, длительности), картинки, стрелки, карандаш. Раскадровки с хронометражом и экспортом PNG/PDF |
| **Люди** (`Alt+9`) | Карточки людей и клиентов: заказы, деньги, долги, встречи, задачи, мысли, дни рождения; «спросить ассистента» |
| **Память** (`Alt+7`) | Лента всего, что происходило (события, траты, задачи, заметки) по дням, с поиском; вкладка **«лента»** — сессии за ПК, действия, разговор |
| **Настройки** (`Alt+8`) | Токен бота, Telegram ID, ключ облака, режим мозга, озвучка, вид, бэкапы и восстановление из них, органайзер папок. Тут же «состояние»: мозг, Telegram, последний бэкап, ошибки |

## Чат и палитра

- **`Ctrl+J`** — чат с той же историей, что в Telegram (с пометкой канала). Ответ локальной модели появляется по словам.
- **`Ctrl+K`** — палитра: страницы, действия, поиск по Мозгу и любая фраза ассистенту прямо там.
- Кнопка **↶** в шапке чата — откат последнего действия.
- Микрофон в шапке (Chrome/Edge) — сказать с сайта.

## Горячие клавиши

| Клавиши (Windows / Mac) | Что |
|---|---|
| `Ctrl+K` / `⌘K` | палитра: страницы, действия, поиск по Мозгу, любая фраза |
| `Ctrl+J` / `⌘J` | чат |
| `Alt+1…0`, `Alt+7…9` / `⌥…` | разделы |
| `Enter` / `Shift+Enter` | отправить / новая строка |
| `Esc` | закрыть окно |

На доске — свой набор: `H` рука · `V` выделение · `S` стикер · `T` текст · `F` кадр · `A` стрелка · `P` карандаш · `E` ластик · `I` картинка · `Ctrl+Z/Y`, `Ctrl+C/V/X/D`, `Delete`, стрелки (Shift — по 10), `PgUp/PgDn` — план, `Ctrl+1` — всё, `Ctrl+2` — выделенное, `Ctrl+0` — 100%. Полный список — кнопка `⌨` в шапке доски.

## На телефоне

- Задачу **смахнуть вправо** — выполнена, **влево** — удалить; операцию в финансах — влево, удалить.
- Нижняя панель вкладок настраивается в ⚙ Настройки → вид (2–5 разделов).
- Столбик на графике трат — тап: сумма дня, на что ушло больше всего, число операций.
- Пустые разделы предлагают готовую фразу — тап открывает чат с ней.
- На доске: рука по умолчанию, пинч-масштаб, базовые инструменты; тонкую раскладку удобнее с компьютера.

## Вид и настройки на сайте

⚙ Настройки → **вид**: тема (авто/светлая/тёмная), акцентный цвет, масштаб, скругления, анимации, какие разделы показывать в боковой панели и что — в нижней панели телефона. На главной — «настроить главную»: порядок блоков перетаскиванием, плотность «спокойно / подробно», обращение.

Остальные настройки (токен бота, ключ облака, режим мозга, голос, бэкапы, Google) тоже правятся здесь и пишутся в `config.yaml`; после смены Telegram/мозга/порта нужен перезапуск `start.bat`. Что именно меняется на сайте, а что в файле — [CONFIGURATION.md](CONFIGURATION.md).

## Внутри Telegram (Mini App) иначе

- Нет боковой панели — как на телефоне: нижние вкладки, свайпы, чат по кнопке.
- Системная кнопка «назад» ведёт на главную; с главной Telegram показывает «закрыть».
- Тема подстраивается под телеграмную.
- Микрофон внутри Telegram на iPhone не работает (ограничение iOS) — говори голосовыми боту или открой сайт в обычном браузере. На Android обычно работает.
- Уведомления браузера не приходят — напоминания и так идут в Telegram.

Исходники сайта — `web/src`, пересборка — `build_web.bat` (нужен Node.js); собранная версия лежит в `web/site`. Дизайн-система — [`web/DESIGN.md`](../web/DESIGN.md).
