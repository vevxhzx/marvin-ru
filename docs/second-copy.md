# Джарвис для мамы — вторая копия на вашем ПК

Маме нужен «такой же», но без Python, Ollama и настроек. Решение: **вторая копия Джарвиса в соседней папке** на вашем
компьютере, со своим ботом, своей базой и своей памятью. Мозг — облако Groq (вашу видеокарту не трогает).
Мама получает только Telegram: чат + кнопка «Открыть». Ей ничего не ставить.

**Вы делаете один раз ~10 минут: `mama.bat`.** Всё остальное он спрашивает и проверяет сам.

## Что понадобится заранее

1. **Токен нового бота**: в Telegram @BotFather → `/newbot` → имя («Помощник мамы») → юзернейм (`…_bot`) → скопировать токен.
2. **Ключ Groq**: console.groq.com → API Keys → Create. Бесплатно, карта не нужна. Лучше **отдельный аккаунт** (у бесплатного
   тарифа ~1000 запросов в день на ключ; вдвоём на одном тесно).
3. **Телефон мамы** рядом (или её Telegram на вашем) — на 30 секунд, нажать «Start» у нового бота. Так Джарвис сам узнает её ID.

## Шаги

1. Запустите **`mama.bat`** (в папке Джарвиса). Он:
   - копирует проект в `…\jarvis-mama` (без вашей базы, конфига и голосовых моделей; библиотеки общие);
   - спрашивает, как обращаться к маме («мам», «Наталья»…) — Джарвис будет говорить так вместо «сэр»;
   - просит токен бота, проверяет его; просит нажать «Start» у бота с её телефона → ловит её ID и здоровается;
   - просит ключ Groq, проверяет живым запросом;
   - пишет её `config.yaml`: **только облако**, порт **8766**, спокойный характер без подколов, голосовые в Telegram
     распознаются через Groq Whisper, фото — через Groq, анонимайзер выключен (иначе облако не сможет записать «850 на продукты»);
   - предлагает включить **второй Tailscale Funnel** (порт 8443) для кнопки «Открыть» — если у вас уже сделан `funnel.bat`;
   - предлагает ярлык автозагрузки `Jarvis (jarvis-mama)`.
2. Запустите `…\jarvis-mama\start.bat` — второе окно, можно свернуть. В логе: «Мозг: только облако (Groq)» и
   «Telegram OK: @имя_бота».
3. Отправьте маме файл **`docs\ДЛЯ_МАМЫ.md`** (или распечатайте) — там всё без единого технического слова.

`mama.bat` можно запускать повторно: обновит файлы копии, не тронет её базу и настройки; спросит, перенастраивать ли.

## Что мама получает

- **Чат**: «потратила 850 на продукты», «завтра в 10 к врачу», «запомни: паспорт в верхнем ящике», «что я говорила про врача?»,
  «сколько я потратила за неделю», «что у меня завтра». Голосовые — тоже (расшифровка + ответ).
- **Память** — главное для неё. Всё, что она пишет без команды («вчера была у врача, сказали пить таблетки», «утром давление
  140 на 90»), сохраняется как заметка; облако ставит заголовок и теги; оригинал не теряется. Потом: «что я говорила про
  давление?» → Джарвис ищет по заметкам, ссылкам и журналу и отвечает по найденному.
- **Бюджет**: траты по категориям, доходы, остаток, «сколько за неделю/месяц», лимиты («лимит на еду 15000»), долги.
- **Кнопка «Открыть»** — тот же сайт внутри Telegram: Сегодня / Календарь / Дела / Деньги / Память. Можно править и удалять.
- Утренний план дня, напоминания, воскресный обзор. Ночной бэкап её базы в `jarvis-mama\data\backups`.

## Приватность — честно

В режиме «только облако» **всё, что она пишет, уходит в Groq** (текст, суммы, имена). База при этом лежит у вас на ПК.
Скажите ей об этом простыми словами. Если неприемлемо — в её `config.yaml` поставьте `brain.mode: hybrid` и общий
`brain.ollama.url` (тогда её личные запросы пойдут в вашу Ollama, видеокарта на двоих).

Ваш Джарвис и её — независимые: разные боты, базы, ключи. Ваш её сообщений не видит, и наоборот.

## Обслуживание

| Что | Как |
|---|---|
| Обновить обе копии | Обновите свою как обычно, затем `mama.bat` — он перекопирует файлы (данные не трогает) |
| Посмотреть её копию | окно с заголовком **«J.A.R.V.I.S. - MAMA (port 8766)»** (у вашего — просто «J.A.R.V.I.S.»); в первой строке её лога — «копия для мамы · jarvis-mama · :8766»; сайт `http://localhost:8766` |
| Кнопка «Открыть» не появилась | у вас должен быть включён `funnel.bat`; затем `mama.bat` → шаг 5 «да». Проверка: `tailscale funnel status` — две строки Funnel on (443→8765 и 8443→8766) |
| «Лимит исчерпан (429)» | отдельный ключ Groq на её копию. Модель для инструментов выбирается из живого списка Groq сама (`gpt-oss-120b` → `gpt-oss-20b` → …); можно задать явно в `brain.cloud.model` |
| Она потеряла телефон | бот и так отвечает только её ID; в её копии ⚙ Настройки → «новый ключ доступа» сбросит и Telegram-сессии |
| Убрать | закрыть её окно, удалить ярлык из автозагрузки (`shell:startup`), удалить папку, `tailscale funnel --https=8443 off` |

Техническая сторона: `brain.mode: cloud` теперь полноценный режим — инструменты (траты, задачи, события, заметки, поиск по
памяти) выполняет облачная модель по OpenAI-формату tools, заметки редактируются облаком, недельный обзор тоже. Без Ollama.
