# Вторая копия — для близкого человека

Сценарий: у тебя уже работает свой ассистент, а близкий человек хочет «такого же». Ставить Python и Ollama ему не хочется, а тебе — быть его сисадмином. Решение: **вторая копия на твоём ПК** со своим ботом, своей базой и своей памятью. Человек получает только чат в Telegram и кнопку «Открыть» — никаких установок, ключей и VPN.

Ты тратишь ~10 минут один раз. Он открывает Telegram.

Вторая копия обычно работает **в режиме «только облако»** (`brain.mode: cloud`) — ей не нужна твоя видеокарта, и она не мешает твоему ассистенту. Мозг — бесплатный Groq (или другой провайдер); в режиме `cloud` он умеет всё то же: записывать траты и задачи, вести календарь, хранить и находить заметки.

> **Честно о приватности.** В режиме `cloud` **всё**, что человек пишет ассистенту, уходит провайдеру облака (тексты, суммы, имена). База при этом лежит на твоём ПК, но обработка — на серверах провайдера. Скажи об этом человеку.
> Если для него это неприемлемо — режим `hybrid` с общей Ollama (`brain.ollama.url` тот же, что у тебя; видеокарта будет общей на двоих) или выделенная машина. Подробности режимов — [PRIVACY.md](PRIVACY.md).

## Часть 1 (ты, на ПК): вторая копия

1. **Скопируй папку** ассистента целиком, например `C:\Marvin` → `C:\Marvin-2`. Из копии **удали**:
   - папку `data/` — там твоя база и ключи;
   - файл `config.yaml` — там твой токен бота.
   Папку `.venv` удалять не обязательно — она подойдёт как есть (если удалил, запусти установку).
2. В `C:\Marvin-2` запусти **`start.bat`** (или `./start.sh`). Откроется мастер первого запуска. Пройди его:
   - **Имя** — какое хочет человек (2–3 слога по-русски). **Обращение** — как звать хозяина.
   - **Характер** — «По делу» (`persona.style: neutral`): спокойные реплики без подколов.
   - **Мозг** → **Только облако**.
   - **Провайдер** → например Groq → ключ. Лучше **отдельный** ключ (второй аккаунт по другой или запасной почте): у бесплатного тарифа лимит на ключ, вдвоём на одном тесновато.
   - **Telegram** → создай **нового бота** в [@BotFather](https://t.me/BotFather) (`/newbot`, имя, юзернейм) → токен в мастер → попроси человека написать этому боту `/start` (или сделай это с его телефона) → мастер определит его ID.
   - Готово → мастер попросит перезапуск.
3. **Порт.** Две копии не могут слушать один порт. Открой `C:\Marvin-2\config.yaml`, найди блок `server:` и поставь `port: 8766`. Либо просто поменяй порт в ⚙ Настройках второй копии.
4. Снова `start.bat`. В логе: `Telegram-бот онлайн, отвечает только ID …` — это ID человека. С этого момента он может пользоваться чатом.
5. **Автозагрузка** (по желанию): `autostart.bat` в папке второй копии. Обе копии будут стартовать с системой.

### Сайт внутри Telegram для второй копии (по желанию)

Один Tailscale Funnel = один публичный адрес = один порт. Для второй копии нужен **второй адрес** — Tailscale даёт их на других портах того же имени: `https://имя-пк.tail….ts.net:8443`.

В командной строке:

```
tailscale funnel --bg --https=8443 8766
```

Затем в `config.yaml` второй копии:

```yaml
telegram:
  webapp_url: "https://имя-пк.tail….ts.net:8443"
```

(адрес — как у первой копии, плюс `:8443`). Перезапусти `start.bat` второй копии → в её боте появится кнопка «Открыть».

> *`funnel.bat` для второй копии не запускай — он настроит порт 443 и собьёт первую.*
> Порты, которые Funnel разрешает снаружи: 443, 8443, 10000. Третьему человеку — `--https=10000`.

## Часть 2 (человек): что ему сказать

Инструкция без единого технического слова:

1. Открой Telegram → бот по ссылке `t.me/…` → **Start** (или «Запустить»). Он поздоровается — можно писать.
2. Пиши как человеку: «потратила 700 на продукты», «завтра в 10 к врачу», «запомни: паспорт в верхнем ящике», «что я говорила про дачу?», «что у меня на неделе».
3. Слева от строки ввода — кнопка **≡ / «Открыть»**: там всё то же в виде календаря, списка дел, кошелька и памяти. Можно поправить или удалить любую запись пальцем.
4. Он отвечает только ему. Ничего устанавливать не нужно.
5. Если ответил не то — «отмени последнюю» или просто сказать, как правильно. Если написал про «лимит» или «облако» — на сегодня бесплатные ответы кончились, к утру вернётся; записи при этом не пропадают.

Подробнее про интерфейс — [UI.md](UI.md), про команды — [COMMANDS.md](COMMANDS.md).

## Что человек получает по памяти

- Любая фраза-мысль без команды («идея: …», «вспомнила, что нужно поменять фильтр в апреле») → заметка; облако приводит её к аккуратному виду, ставит заголовок и теги, оригинал сохраняется.
- Всё, что произошло (траты, встречи, задачи, заметки, ссылки) — в ленте на сайте, с датами.
- Поиск: «что я записывала про врача», «найди про дачу», «когда я платила за интернет» — по заметкам, ссылкам и журналу. *(Смысловой поиск по векторам работает только с Ollama; в режиме `cloud` — поиск по словам.)*
- Утренний дайджест, недельный обзор, напоминания о встречах и платежах.
- Ночной бэкап его базы в `data/backups` (30 дней); можно указать вторую папку.

## Обслуживание

| Что | Как |
|---|---|
| Обновить обе копии | Скопируй новые файлы в обе папки (`data/` и `config.yaml` не трогать), затем `update.bat` в каждой |
| Посмотреть, что с его копией | Окно `start.bat` второй копии или `http://localhost:8766` на твоём ПК |
| Он потерял телефон | В его копии ⚙ Настройки → «новый ключ доступа» (сбрасывает и Telegram-сессии); бот и так отвечает только его ID |
| Лимиты провайдера (429) | Отдельный ключ на копию; если всё равно упирается — другой провайдер как запасной |
| Убрать копию | Закрыть `start.bat`, удалить ярлык из автозагрузки, удалить папку, `tailscale funnel --https=8443 off` |

Обе копии полностью независимы: разные базы, разные боты, разные ключи. Твой ассистент её сообщений не видит, и наоборот.
