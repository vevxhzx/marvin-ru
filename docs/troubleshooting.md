# Если что-то не так

- **`Cannot connect to host api.telegram.org`** → Telegram заблокирован у провайдера. Два варианта:
  1. Включить VPN на ПК (самое простое). Джарвис сам переподключится, перезапускать не нужно.
  2. Или прописать прокси в `config.yaml` → `telegram.proxy: "socks5://логин:пароль@хост:порт"`.
  Пока Telegram недоступен, API и сайт всё равно работают — падать Джарвис не будет.
- **Бот молчит** → проверь токен и `owner_id` в `config.yaml`; напиши боту `/id` — он покажет твой ID.
- **«Локальный мозг не запущен»** → Ollama не установлена или не запущена (значок в трее). Шаблонные команды работают и без неё.
- **Ошибка при установке** → запусти `install.bat` ещё раз, проверь интернет.
- Логи — прямо в окне `start.bat`.

## Облако (Groq) «посыпалось» — как вернуть за минуту
1. В боте или на сайте напишите **`облако сброс`** — Джарвис перечитает ключ и модель из настроек, сбросит кэш и сделает живой запрос. В ответе будет либо «Отвечает ✅», либо точная причина (ключ не принят / модель не найдена / нет сети).
2. Ключ не принят → console.groq.com/keys → Create key → вставить в Настройки → облако → ключ → сохранить (теперь применяется сразу, без перезапуска).
3. Модель не найдена → очистить поле «модель облака» (пустое = стандартная `openai/gpt-oss-120b`). Джарвис и сам пробует стандартную, если вписанная отвергнута.
4. Нет сети → Джарвис сам перебирает: напрямую → прокси Telegram → системный прокси. Если всё мимо — включите VPN или впишите прокси в Настройки → облако.

## Бот в Telegram «печатает» и молчит — что проверить
0. **Старая папка `core/`.** Напишите боту `/start` — он ответит, какая у него версия ядра. Должно быть **ядро v0.9.0**. Если версия старее — новые файлы не скопировались, повторите шаг «Обновление» ниже. В консоли при старте должна быть строка `Telegram: обработчики в порядке`; если вместо неё красная `ТЕКСТОВЫЙ ОБРАБОТЧИК НЕ ПРИВЯЗАН` — та же причина.
1. **Второе окно Джарвиса.** Самая частая причина: запущены два экземпляра (автозагрузка + вручную, или старое окно свёрнуто). Telegram отдаёт сообщения только одному из них. Закройте ВСЕ окна Джарвиса (и проверьте Диспетчер задач → python), запустите `start.bat` один раз. Теперь при попытке запустить второй он сам об этом скажет и не стартует.
2. В боте `/diag` — покажет, живы ли Ollama и облако.
3. Смотрите консоль: на каждое сообщение теперь пишется `← tg: …` (получил) → `ОБЛАКО/ЛОКАЛЬНО …` (кто ответил, за сколько) → `→ tg: отправлено` (доставил). Строка, на которой цепочка оборвалась, и есть причина; при ошибке отправки в консоли будет `→ tg: … НЕ доставлен` с объяснением.
4. Прокси/VPN для Telegram отвалился — консоль напишет `сеть до Telegram`, Джарвис сам повторит 3 раза.
