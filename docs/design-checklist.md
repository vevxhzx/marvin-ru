# Чек-лист дизайна Marvin (mobile-first, premium / liquid-glass)

Источник правды по видению — этот файл + `web/DESIGN.md` (токены и классы).
Каждую страницу проходим по этому списку, минимум **2–3 прохода** со скриншотами
(390px в приоритете; затем 375/430 и ПК 1440), в обеих темах. Скрины — на демо-стенде,
не на боевых данных.

## Дирекция стиля (что НЕ делаем — анти-слоп)
- НЕ «бенто из одинаковых квадратов»: контент живёт в **grouped-списках** внутри
  поверхностей, а не в сетке одинаковых коробок.
- НЕ стекло везде: glassmorphism — только на **плавающих слоях** (док, шапка при
  скролле, шторки, плитки героя). Контент — плотные поверхности + волосяные линии.
- НЕ `rounded-2xl` + `shadow-lg` на каждой карточке подряд: радиусы по шкале,
  тени по 3 уровням elevation.
- НЕ фиолетово-синие градиенты «по умолчанию», не неон; акцент — синий.
- НЕ `transition-all`: только конкретные свойства (`transform`, `opacity`, `color`).
- НЕ Inter/Roboto по умолчанию: интерфейс — Onest (+ моно для чисел).

## A. Типографика
- [ ] Не больше 4 кеглей в UI (12 / 13.5 / 16 / 22 / 44–52 для героя).
- [ ] Крупные числа — табличные цифры (`.num`), 44–52px, не переносятся.
- [ ] ₽ — мельче и легче числа (0.55em), не спорит с суммой.
- [ ] Неразрывные пробелы в разрядах.
- [ ] Никаких обрезанных/выезжающих строк: длинный текст — `.fade-r` (затухание)
      или `.clamp-2/3`, короткий не трогаем.
- [ ] Строка не длиннее ~60 символов на мобиле.

## B. Контраст и цвет
- [ ] Подписи ≥ 4.5:1 в обеих темах (свет `--ink2/3`, тём `--ink2/3`).
- [ ] На тёмном фоне текст белый; на ярко-светлом — тёмный; по теме.
- [ ] Цвет только по смыслу: деньги=зелёный, риск=красный, ожидание=янтарь, ИИ=фиолет.
- [ ] Текст на акценте берётся из `--accent-ink` (авто-подбор), никогда не «на глаз».

## C. Раскладка и ритм
- [ ] Отступы кратны 4px; поля страницы 20px; сетка воздуха одинаковая.
- [ ] Заголовки — слева; ничего по центру, кроме явных центрированных блоков.
- [ ] Кнопки одного действия — **в один ряд**, не столбиком; ряд не переносится
      (скрытый скролл при необходимости).
- [ ] Нет горизонтального переполнения страницы (320–430px).
- [ ] Ничего не «прыгает» при загрузке: шимер с зарезервированной высотой.

## D. Зоны нажатия и доступность
- [ ] Тач-цель ≥ 44px (лучше 48), зазор 8–12px.
- [ ] У каждой кнопки `aria-label`/подпись и иконка/title.
- [ ] Фокус-кольцо видно; `Esc` закрывает шторки (`role="dialog"`, ловушка фокуса).
- [ ] `prefers-reduced-motion` гасит анимации.

## E. Мобильная оболочка
- [ ] `100dvh`, safe-area, док над индикатором; поля ввода 16px (если есть).
- [ ] Док: сменные разделы + «+» по центру + **постоянная** кнопка «все разделы».
- [ ] Верхней строки на телефоне нет; заголовок — первый элемент страницы.

## F. Состояния
- [ ] Загрузка — шимер (не спиннер); пусто — `Empty` с подсказкой; ошибка — `ErrorState`.
- [ ] Долгое нажатие/наведение не ломает верстку; активный тап — пружина 0.97.

## G. Стекло и глубина
- [ ] Ровно 3 уровня elevation; стекло с внутренней светящейся линией.
- [ ] На стекле текст читаем (контраст проверен), фон под ним не «просвечивает» грязно.
