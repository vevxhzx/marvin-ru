# Сайт

Открой **http://localhost:8765** — сайт раздаётся тем же процессом, что и бот, ничего дополнительно ставить не нужно.

| Раздел | Что там |
|---|---|
| **Сегодня** | Приветствие, баланс, «свободно в месяц», события дня, ближайшие, задачи, платежи недели, лента памяти |
| **Финансы** | Денежный поток (доход − регулярные − долги = свободно), траты по категориям, график по дням, долги с прогресс-баром и датой закрытия, регулярные платежи, счета, все операции. Кнопки: операция / долг / регулярный / сверить балансы / внести платёж |
| **Календарь** | Месяц и неделя, клик по дню → события, создание/редактирование/удаление |
| **Задачи** | Группы: просрочено / сегодня / на неделе / позже / без срока. Быстрый ввод понимает даты: «позвонить маме завтра в 18» |
| **Мозг** | Мысли и ссылки в виде карточек. **Редактор**: всё, что ты пишешь «как есть» (с опечатками, без запятых), локальная модель через пару секунд приводит к аккуратному виду — заголовок, чистый текст, теги. Оригинал сохраняется (кнопка « на карточке). Клик по тегу — фильтр |
| **Память** | Лента всего, что происходило: события, траты, задачи, заметки — по дням, с поиском |
| **Чат** | Кнопка «чат» или **Ctrl+J** с любой страницы (Ctrl+K — палитра команд) — тот же Джарвис, что и в Telegram. Ответ локальной модели появляется по словам. Кнопка ↶ в шапке чата — откат последнего действия |
| **Настройки** ⚙ | Токен бота, Telegram ID, ключ облака (Groq), режим мозга, бэкапы — всё правится здесь, `config.yaml` руками трогать не нужно (после смены Telegram/мозга — перезапустить `start.bat`). Тут же **состояние**: мозг, Telegram, последний бэкап, ошибки. Уведомления в браузере, экспорт CSV/JSON, бэкап сейчас |

**Финансы — новое:**
- **«Можно потратить сегодня»** = (деньги на счетах − обязательные платежи до следующего дохода) ÷ дней до дохода. Джарвис показывает, сколько уже ушло сегодня и есть ли перебор.
- **Бюджеты**: нажми на категорию → задай лимит на месяц. Полоска желтеет на 80 %, краснеет при перерасходе; тонкая риска — где «должны» быть по календарю.
- **Свои категории** («+ категория»): значок, название, ключевые слова — по ним Джарвис сам относит траты («потратил 300 в кофейне» → «Кофейни»).

**Мозг — смысловой поиск.** Поиск в разделе «Мозг» ищет по смыслу, а не по буквам: «та статья про сон» найдёт заметку про мелатонин. Нужна модель эмбеддингов (один раз): `ollama pull nomic-embed-text`. Без неё поиск работает по словам. Индексируется само раз в 10 минут (или кнопка «переиндексировать мозг» в настройках). Всё локально.

**Бэкап на другой диск / в облако.** В настройках → «Вторая копия» укажи папку, например `D:/Backups/jarvis` или `C:/Users/Имя/YandexDisk/jarvis` — каждую ночь копия ляжет и туда.

**Вид.** ⚙ Настройки → «вид»: тема (авто/светлая/тёмная), акцентный цвет, масштаб, скругления, анимации, какие разделы показывать в боковой панели и какие 2–5 вкладок — в нижней панели телефона. На главной — «настроить главную»: порядок блоков перетаскиванием, плотность «спокойно/подробно», обращение.


## Сайт на телефоне — жесты
- Задачу **смахнуть вправо** — выполнена, **влево** — удалена. Операцию в финансах — влево, удалить.
- Столбик на графике трат — тап: покажет сумму дня, на что ушло больше всего и число операций.
- Пустые разделы предлагают готовую фразу — тап открывает чат с ней, остаётся нажать «отправить».

## Горячие клавиши

| Клавиши | Что |
|---|---|
| `Ctrl+K` | палитра: страницы, действия, поиск по Мозгу, любая фраза Джарвису |
| `Ctrl+J` | чат |
| `Alt+1…7` | разделы |
| `Enter` / `Shift+Enter` | отправить / новая строка |
| `Esc` | закрыть окно |

(на Mac — ⌘ и ⌥, подписи в интерфейсе подстраиваются сами)

Исходники сайта — `web/src`, пересборка — `build_web.bat` (нужен Node.js). Собранная версия уже лежит в `web/site`. Дизайн-система — [`web/DESIGN.md`](../web/DESIGN.md).
