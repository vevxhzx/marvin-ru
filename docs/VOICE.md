# Голос

Голос — отдельный аддон: голосовой клиент `voice_client.py` (запуск `voice.bat` / `./voice.command`) ходит к ядру по HTTP, как сайт и Telegram. Ядро должно быть запущено (`start.bat`). Всё распознавание по умолчанию происходит на твоём ПК; наружу ничего не уходит, кроме случая, который ты сам включишь (`voice.stt.cloud`).

## Что умеет

- **Слово-активация.** Скажи «*Имя*, потратил семьсот на такси» — клиент ждёт имя (Vosk, офлайн), потом пишет команду до паузы и распознаёт её.
- **Горячая клавиша.** `voice.pc.hotkey` (в примере `ctrl+shift+space`) — начать слушать без имени. Если ключ не задан, клиент берёт `ctrl+shift+j`.
- **Управление ПК.** Открыть программу/сайт/папку, найти файл, убраться в Загрузках и на Рабочем столе, медиа-клавиши, скриншот, буфер обмена, питание — всё то же, что можно написать в чат (см. [COMMANDS.md](COMMANDS.md)).
- **Озвучка ответов** в наушники/колонки (Silero офлайн или Edge онлайн).
- **Диктовка.** «*Имя*, запиши мысль» — говори до минуты (пауза 2.5 с завершает) → заметка в Мозг.
- **«Режим беседы».** «*Имя*, режим беседы» — окно, в котором можно говорить без обращения; «хватит болтать» / «*Имя*, стоп» — выключить. После любого ответа есть короткое окно (`voice.pc.conversation_sec`), когда имя не нужно.
- **Кэш озвучки.** Частые фразы не синтезируются заново — ответ приходит быстрее.
- **Иконка в трее.** Кружок: серый — жду имя, синий — слушаю, жёлтый — думаю, зелёный — говорю. Меню: слушать сейчас, открыть сайт, выключить микрофон.

## Как это работает

```
микрофон → Vosk (wake word, офлайн) → запись до паузы → faster-whisper (локально)
        → HTTP POST /api/chat → ядро → ответ → озвучка (Silero/Edge) → «Стоп» перебивает
```

### Wake word

`core/voice/wake.py` использует Vosk small-ru (~45 МБ, скачивается один раз в `data/models/`). Имя берётся из `assistant.name` (и `assistant.aliases`), а паттерн ловит искажённые варианты: «Марвин» → «марвин», «джервис», «джарвиз». Пока клиент ждёт, он ещё умеет расслышать «стоп / хватит / тихо / замолчи», чтобы прервать.

### Распознавание речи (STT)

`core/voice/stt.py` — **faster-whisper**, полностью локально, модель качается в `~/.cache/huggingface` (или в `HF_HOME`).

| `voice.stt.model` | Размер | Комментарий |
|---|---|---|
| `tiny` / `base` | десятки МБ | быстро, но заметно ошибается на русском |
| `small` (по умолчанию) | ~500 МБ | баланс скорости и точности на CPU |
| `medium` | ~1.5 ГБ | точнее, но медленнее на процессоре |
| `large-v3-turbo` | больше всех | лучшее качество; на CPU непрактично, нужен `gpu.bat` |

`voice.stt.device` — `cpu` (int8, по умолчанию) или `cuda` (после `gpu.bat`, whisper 0.3 с вместо 2–3 с). `voice.stt.fast` — быстрый режим (луч 1, одна температура) для коротких команд.

**Словарь-подсказка из твоих же данных.** Перед распознаванием Whisper получает `initial_prompt`: имена людей и клиентов, названия заказов, активные задачи, цели и свежие заметки — поэтому «Пятёрочка» и «Хедвей» слышатся правильно. Строится локально, кэш 5 минут, чужие данные никуда не уходят.

**Переспрос при неуверенности.** Для каждой расшифровки считаются `confidence` и `no_speech`. Если уверенность ниже порога (`MIN_CONFIDENCE = 0.50`) или похоже на шум (`MAX_NO_SPEECH = 0.60`), действие **не выполняется**:

- на ПК: «Расслышал так себе: … Повторите, пожалуйста»;
- в Telegram: показывается расшифровка и кнопки **Верно / Повторить / Исправить**.

Также отсекаются классические «галлюцинации» Whisper на тишине («субтитры», «продолжение следует»).

**Облачный вариант (по желанию).** `voice.stt.cloud: true` — распознавание через Groq `whisper-large-v3-turbo` (~1 с вместо 5–15 с на CPU). Нужен провайдер `groq` и его ключ. Голос в этом случае уходит в облако; в режиме `local` облако не используется никогда.

### Озвучка (TTS)

`core/voice/tts.py`, `voice.tts.engine`:

- **`silero`** — офлайн, русский, модель ~40 МБ (скачивается сама). Голоса: `eugene`, `aidar` (муж.), `baya`, `kseniya`, `xenia` (жен.). Ставится через `silero.bat` или галочкой в `install_voice.bat`.
- **`edge`** (по умолчанию) — онлайн, голоса Microsoft (`voice.tts.edge_voice`, например `ru-RU-DmitryNeural`). Красиво и без установки, но текст ответа уходит в Microsoft.
- **`off`** — без озвучки.

Текст перед синтезом готовится: числа → слова, `₽` → «рублей», эмодзи и markdown вырезаются. Выход — ogg/opus (Telegram показывает как голосовое) или wav.

### Голосовые в Telegram

Голосовое сообщение боту распознаётся на ПК, выполняется как текст, ответ приходит текстом и — по настройке `voice.tts.reply_in_telegram` — голосом: `voice` (голосом на голосовые, по умолчанию), `always` (на всё), `never` (только текст). Переключается командой `/voice` или в ⚙ Настройках → голос.

## Настройки `voice.*`

| Ключ | По умолчанию | Что |
|---|---|---|
| `voice.enabled` | `true` | распознавать голосовые в Telegram |
| `voice.stt.model` / `device` / `fast` | `small` / `cpu` / `true` | модель, устройство, быстрый режим |
| `voice.stt.cloud` | `false` | Groq Whisper (~1 с, голос в облако) |
| `voice.tts.engine` / `speaker` / `edge_voice` | `edge` / `eugene` / `ru-RU-DmitryNeural` | озвучка и голос |
| `voice.tts.reply_in_telegram` | `voice` | голосом на голосовые / всегда / никогда |
| `voice.pc.hotkey` | `ctrl+shift+space` | горячая клавиша «слушать» |
| `voice.pc.mic` | пусто | микрофон (пусто — системный; номер из `voice.bat --mics`) |
| `voice.pc.silence_sec` | `1.5` | пауза в речи, после которой команда считается сказанной. 0.8 — быстро, 1.5–2 — если обрывает на раздумьях |
| `voice.pc.max_command_sec` | `20` | максимальная длина одной команды |
| `voice.pc.followup_sec` / `conversation_sec` / `conversation_mode_sec` | `6` / `12` / `120` | окна «можно говорить без имени» после ответа и в режиме беседы |
| `voice.pc.filler_sec` | `1.5` | через сколько секунд молчания сказать «Секунду…» (0 — никогда) |
| `voice.pc.beep` / `stream` / `speak_reminders` | `true` | звуковой сигнал, потоковый ответ, озвучивание напоминаний |
| `voice.pc.morning_report` | `true` | утренний доклад вслух, когда впервые сел за ПК |
| `voice.pc.night_from` / `night_to` / `night_volume` | `23` / `7` / `0.45` | ночной режим: тише, вслух — только напоминания о встречах и дедлайнах |
| `voice.pc.games` | `[]` | свои exe-имена для авто-игрового режима (популярные игры распознаются сами) |
| `voice.pc.screen_time` | `enabled: false` | экранное время: `idle_min` (минут без мыши = «отошёл»), `nudges` (редкие подколы), `keep_days` (хранение). Пишутся только имя программы и сайт/заголовок окна, **локально**; в облако — никогда |
| `voice.pc.tidy_downloads_days` | `0` | ночная уборка «Загрузок»: файлы старше N дней → `Загрузки/Разобрано` (0 — выключено) |
| `voice.pc.api` / `api_token` | пусто | если ядро на другой машине. Правятся только в файле |

Правки `voice.pc.*` подхватываются при следующем запуске `voice.bat`; `voice.stt.model` — при перезапуске.

## Управление ПК

Работает, когда запущен `voice.bat`. Команды можно давать голосом, в Telegram или в чате сайта — выполнится на ПК: открыть сайт/программу/папку, найти файл, разобрать Рабочий стол и Загрузки (с планом и откатом, файлы не удаляются), медиа-клавиши, «что на экране», буфер в Мозг, статус железа, блокировка/выключение/перезагрузка/сон. Полный список — [COMMANDS.md](COMMANDS.md).

Перебить ответ голосом: «*Имя*, стоп» / «хватит» — Марвин замолкает.

## Требования и установка

- Python из основного окружения (`.venv`), ядро запущено (`start.bat`).
- Пакеты аддона: `vosk`, `sounddevice`, `faster-whisper`, `numpy`, `httpx`, плюс опционально `pystray` (трей), `keyboard` (горячая клавиша), `torch` (Silero). Всё ставит **`install_voice.bat`** (~700 МБ; по ходу спросит про Silero ~2 ГБ и GPU ~1 ГБ). На Linux/macOS — `./voice.command`.
- Микрофон, разрешённый в системе: Windows → Параметры → Конфиденциальность → Микрофон.
- `ffmpeg` не обязателен: OGG/Opus из Telegram читает PyAV.

Проверка и мелочи:

```bat
voice.bat --check     :: что установлено и что чинить
voice.bat --mics      :: список микрофонов (номер — в voice.pc.mic)
voice.bat --deps      :: только проверка пакетов (используется скриптами)
voice.bat --gpu-on    :: проверить GPU и включить voice.stt.device: cuda
```

Отдельно: `silero.bat` — доставить офлайн-озвучку, `gpu.bat` — CUDA для распознавания. Лог клиента — `data/voice.log`.

## Если не работает

| Симптом | Что делать |
|---|---|
| Микрофон не найден | `voice.bat --mics`, затем `voice.pc.mic`; проверь разрешение микрофона в системе |
| Слышит имя, но не команду | Пауза слишком короткая/длинная — подстрой `voice.pc.silence_sec` (0.8–2) |
| Часто «расслышал так себе» | Поставь модель побольше (`small` → `medium`) или GPU (`gpu.bat`); проверь словарь-подсказку (имена/заказы в базе) |
| Голос роботизированный / нужен офлайн | `voice.tts.engine: silero` (или `silero.bat`) |
| Нет трея / горячей клавиши | Не критично: поставь `pystray` / `keyboard` (входят в пакеты аддона) |
| Голос тормозит | Включи `voice.stt.fast`, GPU (`gpu.bat`) или облачный whisper (`voice.stt.cloud`, уйдёт в облако) |

Больше — [troubleshooting.md](troubleshooting.md).
