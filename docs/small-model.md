# Малая модель для мини-задач (судья, проактив)

С 0.9.12 мелкие решения — «сайт 15000» это трата или заказ?, формулировка подсказки — можно снять с основной
модели и отдать маленькой. Она грузится только когда нужна и сама выгружается из видеопамяти через 5 минут,
поэтому играм, монтажу и рендеру не мешает.

## Какую ставить (GTX 1660 Super, 6 ГБ)

| Модель | Память | Русский / JSON | Вердикт |
|---|---|---|---|
| **qwen2.5:1.5b** | ~1,0 ГБ | хорошо | **ставьте эту** — лучший баланс |
| qwen3:1.7b | ~1,2 ГБ | хорошо, но любит «думать» (мы это отключаем) | равноценная замена, чуть медленнее |
| qwen2.5:0.5b / qwen3:0.6b | ~0,4–0,6 ГБ | путает русские падежи, ломает JSON | не стоит — судья начнёт ошибаться |
| gemma3:1b | ~0,8 ГБ | русский слабее qwen | нет |

Основная (qwen3.5:4b, ~3 ГБ) + малая (~1 ГБ) + эмбеддинги (~0,3 ГБ) — в 6 ГБ влезают одновременно.

## Как включить — три шага

1. В `cmd` (это единственная команда, .bat не нужен):
   ```
   ollama pull qwen2.5:1.5b
   ```
2. В `config.yaml` (блок `brain: → ollama:`):
   ```yaml
   small_model: "qwen2.5:1.5b"
   small_keep_alive: "5m"
   ```
3. Перезапустить `start.bat`. В логе при старте не должно быть строки «Малой модели … нет в Ollama».

Проверка: напишите в чат «логотип для Кати 8к» — ответ придёт с ⚡ и пометкой «(понял как заказ — если не то…)».
Если малой модели нет — то же самое сделает основная, просто медленнее и подержит её в памяти дольше.

## Чтобы модели не конкурировали с вашими программами

- **`small_keep_alive: "5m"`** — малая живёт 5 минут после задачи и уходит. Хотите жёстче — `"0"` (выгружать сразу;
  каждый вызов +1–2 с на загрузку).
- **`keep_alive: "2h"` у основной** — это осознанно: она нужна для чата, и загрузка 4b занимает 5–15 с.
  Если жалко видеопамять днём — поставьте `"30m"`.
- **Игра / рендер:** скажите «иду играть» — Ассистент выгружает **все** модели из видеопамяти и отвечает через облако;
  «игра окончена» — возвращает. Малая модель в игровом режиме тоже не грузится.
- **Ollama целиком** можно ограничить одной моделью в памяти: переменная окружения `OLLAMA_MAX_LOADED_MODELS=1` —
  тогда основная и малая будут вытеснять друг друга по очереди. На 6 ГБ это не нужно, обе влезают; включайте,
  только если видите, что видеопамяти не хватает (в логе Ollama «out of memory»).

## Куда ходят задачи (кто что решает)

| Задача | По умолчанию | Ручка |
|---|---|---|
| Судья «трата / заказ / долг?» | малая (или основная) на ПК | `brain.judge.where: local` |
| Формулировка инициативных подсказок | малая на ПК, без неё — шаблон | — |
| Извлечение фактов о вас, портрет, стиль | облако, при сбое ПК | `brain.memory.where: cloud` |
| Связи в Мозге | облако, при сбое ПК | `brain.relations.where: cloud` |
| Эмбеддинги (поиск, дубли, уроки) | только ПК | `brain.ollama.embed_model` |
| Разговор, общие вопросы | облако | `brain.mode` |
| Личное с инструментами | основная на ПК | `brain.mode` |

Судья специально стоит на `local`: он дёргается часто, ответ — 20 токенов, и гонять это в облако — расточительно.
