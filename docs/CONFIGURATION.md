# Настройки

Настройки живут в трёх местах, и это не случайно: файл удобно носить с собой, переменные окружения — для Docker и тестов.

## Приоритет: переменная окружения → `.env` → `config.yaml`

`core/config.py` при старте читает `config.yaml` (если его нет — берёт `config.example.yaml`), а поверх накладывает переменные окружения. Что задано раньше в списке — то и побеждает:

1. **Переменная окружения процесса** (`ASSISTANT_TG_TOKEN`, `OLLAMA_URL`, `GEMINI_API_KEY` и т. д.) — самый высокий приоритет.
2. **Файл `.env`** в корне проекта. Читается автоматически, но только те ключи, которых нет в окружении (уже заданные переменные он не перетирает). Значения берутся как есть, кавычки снимаются.
3. **`config.yaml`** — основной файл настроек. Именно сюда пишет мастер первого запуска и страница ⚙ Настройки на сайте.

`config.yaml` и `.env` лежат в `.gitignore` — в git они не попадают. Если `config.yaml` ещё нет, ядро молча работает по `config.example.yaml`, поэтому ассистент запустится даже с пустыми настройками.

> В текущей версии `install.bat` / `install.sh` создают **только `config.yaml`**. `.env` — дело добровольное: скопируй `cp .env.example .env` и заполни, если хочешь держать секреты в переменных, а не в YAML. (В комментариях `.env.example` написано, что установщик создаёт `.env` сам, — по коду это не так.)

## Что можно менять прямо на сайте

Страница ⚙ Настройки читает и пишет `config.yaml` построчно, сохраняя комментарии. Через неё доступны ключи из белого списка `EDITABLE` в `core/config.py`:

- `assistant.*`, `owner.*` — имя, обращение, часовой пояс;
- `telegram.*` — токен, ваш ID, утренний дайджест, прокси, быстрые шаблоны, адрес Mini App;
- `notifications.*` — тихие часы, проактивные сообщения;
- `brain.*` — режим, Ollama, зрение, сортер, память, судья, связи, облако, Gemini, контекст и `keep_alive`;
- `persona.*`, `cards.*`, `finance.*`;
- `voice.*` — модель распознавания, облачный whisper, озвучка, горячая клавиша, микрофон, паузы, экранное время, свои игры;
- `server.port`, `google.*`, `backup.*`.

`trace.*` на сайте **нет** — журнал работы включается и хранится только через файл.

Секреты (токен бота, ключи облака, Google client_secret) API отдаёт **замаскированными** — при сохранении маска не затирает настоящий ключ.

Часть изменений применяется на лету, часть — после перезапуска. Точный признак — что вернул сайт при сохранении (`restart: true/false`):

- **на лету**: `brain.cloud.*`, `brain.gemini.*`, `brain.mode`, `brain.vision.*`, `brain.sorter.*`, `brain.ollama.small_*`, `owner.*`, `persona.*`, `google.*`;
- **нужен перезапуск**: `telegram.*`, `backup.*`, `brain.ollama.*` (кроме `small_*`), а также `server.port` и `voice.*` (последние — перезапуск `voice.bat` / `start.bat`).

Если сомневаешься — закрой окно `start.bat` и запусти снова: настройки читаются из файла при старте.

А вот эти вещи в `config.yaml` правятся **только руками** (в белый список не входят):

- `trace.enabled`, `trace.keep_days` — журнал работы;
- `voice.pc.api` и `voice.pc.api_token` — если ядро крутится на **другой** машине (по умолчанию голосовой клиент ходит на `127.0.0.1`);
- `files.index_dirs`, `files.trash_dir`;
- `server.host`.

Всё, чего нет в белом списке `EDITABLE` в `core/config.py`, меняй в файле.

## Разбор `config.example.yaml`

### `assistant`

- `name` — имя ассистента: так он представляется и на это слово откликается голосом. Латиницей — `name_latin` (заголовки окон, логи).
- `aliases` — другие варианты имени через запятую (например `марв, marvin`), ловятся и голосом, и в тексте.

### `owner`

- `name` — как ассистент к тебе обращается («сэр», «босс», имя; пусто — без обращения).
- `timezone` — часовой пояс для дат и напоминаний (`Europe/Moscow`).

### `telegram`

- `token`, `owner_id` — доступ бота (мастер заполняет сам).
- `webapp_url` — публичный HTTPS-адрес для кнопки-приложения внутри Telegram (появляется после `funnel.bat`, см. [telegram-miniapp.md](telegram-miniapp.md)); пусто — кнопки нет.
- `morning_digest` — время утреннего дайджеста `ЧЧ:ММ`; пусто — выключить.
- `proxy` — если `api.telegram.org` недоступен: `socks5://логин:пароль@хост:1080` или `http://хост:8080`.
- `quick` — быстрые шаблоны одним тапом: `/exp 700 такси`, `/inc 15000 аванс`, `/task …`, `/event …`.

### `notifications`

- `quiet_from` / `quiet_to` — тихие часы (часы 0–23). Ночью ассистент сам ничего не пишет: ни бюджет, ни подписки, ни вечерний обзор. Напоминания о встречах и дедлайнах, которые ты поставил сам, приходят всегда.
- `proactive_enabled` — писать о том, что заметил (клиент тянет с оплатой, дело без срока висит, «как самочувствие?»).
- `proactive_per_day` — не больше стольких инициатив в день (по умолчанию 5).
- `proactive_vibe` — иногда просто написать днём, если по делам поводов нет, а в чате тихо 5+ часов. Тоже считается в `proactive_per_day`.

### `brain` — главное

| Ключ | Значения | Что делает |
|---|---|---|
| `brain.mode` | `local` / `hybrid` / `cloud` | Куда уходит «мозг». `local` — только Ollama, ничего в интернет; `hybrid` — личное локально, общие вопросы обезличенно в облако; `cloud` — всё у провайдера. Разбор — [PRIVACY.md](PRIVACY.md). |
| `brain.ollama.url` | адрес | Где Ollama (в Docker обычно `http://ollama:11434`). |
| `brain.ollama.model` | имя модели | Основная локальная модель (мастер подбирает под видеокарту). |
| `brain.ollama.embed_model` | `nomic-embed-text` | Смысловой поиск по мозгу. |
| `brain.ollama.vision_model` | имя | Отдельная модель зрения; пусто — если основная сама видит картинки. |
| `brain.ollama.keep_alive` / `small_keep_alive` | `2h` / `5m` / `0` | Сколько модель живёт в видеопамяти после ответа. |
| `brain.ollama.small_model` | `qwen2.5:1.5b` | Малая модель для мини-задач (судья «трата/заказ/долг?», проактивные фразы); пусто — основная. |
| `brain.ollama.num_ctx` | число | Окно контекста. 4096 мало; 8192 влезает на 6 ГБ с моделью 4b. |
| `brain.vision.where` | `auto` / `cloud` / `local` | Где смотреть картинки (скриншоты, чеки). Чеки в облако не уходят никогда. |
| `brain.sorter.where` | `cloud` / `local` / `auto` | Кто разбирает длинные смешанные списки на записи. `cloud` надёжнее, но текст уходит целиком. |
| `brain.sorter.confirm` | `true` / `false` | Сначала показать разбор и ждать «да» или писать сразу. |
| `brain.memory.enabled` / `where` | bool / `cloud`·`auto`·`local` | Память о тебе: факты, портрет, подтягивание нужного. Поиск по памяти — всегда локально. |
| `brain.memory.short_days` | число | Сколько дней факт живёт в «сейчас», прежде чем стать постоянным или уйти в архив. |
| `brain.judge.enabled` / `where` | bool / `local`·`cloud`·`auto` | Судья спорных фраз без явного глагола («сайт 15000»). По умолчанию `local`. |
| `brain.relations.enabled` / `where` | bool / `cloud`·`auto`·`local` | Связи между записями в Мозге. Кандидатов всегда отбирает ПК. |
| `brain.cloud.*` | `provider`, `api_key`, `model`, `base_url`, `proxy`, `voice_model` | OpenAI-совместимый провайдер: `groq`, `openrouter`, `nvidia`, `deepseek`, `openai`, `gemini`, `custom`. Для `custom` (LM Studio, vLLM) укажи `base_url` вида `http://127.0.0.1:1234/v1`. |
| `brain.gemini.*` | `api_key`, `model`, `proxy`, `anonymize`, `auto`, `mark_source` | Ключ и поведение Google Gemini; `anonymize` — вырезать имена/суммы/телефоны перед отправкой (в режиме `cloud` не действует); `mark_source` — подписывать источник ответа ⚡/🧠/☁️. |

### `trace`

Журнал работы: на каждую фразу — строка в базе (путь, модель, инструменты, время, переспросил ли, поправили ли). Из него растут «отчёт о себе» в чате, блок в воскресном дайджестe и `/api/runs` на сайте. `enabled: false` — не писать ничего (отчёты будут пустыми); `keep_days` — сколько дней хранить, старше удаляет ночная уборка.

### `persona`

- `style` — `neutral` (спокойный, по делу; по умолчанию) или `swag` (живой, с подколами).
- `humor_level` — 0–10: 0–2 без шуток, 3–5 мягкая ирония, 6–8 сухой сарказм по конкретике, 9–10 жёстко.
- `nicknames` — как ещё тебя звать, через запятую («шеф, босс»).
- `where` — кто формулирует инициативные фразы: `cloud` (при сбое — ПК) / `auto` (ПК, при сбое — облако) / `local` (только ПК). Без обоих — короткие шаблоны.
- `voice_accents` — иногда присылать итог дня и «разнос» по висящему делу голосовым (не чаще раза в день; нужен включённый TTS в Telegram).

### `cards`

`mode` — картинки-карточки в Telegram: `always` (всегда), `important` (важные отчёты + короткие карточки на траты и задачи), `never`. Рисуются локально (Pillow), в облако не уходят и кэшируются.

### `finance`

- `currency` — валюта (`RUB`).
- `main_account` — название главного счёта (мастер спрашивает).

### `files`

- `index_dirs` — папки, которые учитывать в поиске файлов.
- `trash_dir` — куда собирать файлы «на удаление». Ассистент сам **ничего не удаляет** — только переносит; пусто — `Документы/_на_удаление`.

### `voice`

- `enabled` — распознавать голосовые сообщения в Telegram.
- `voice.stt.model` — модель whisper: `tiny` / `base` / `small` (баланс, ~500 МБ) / `medium` (точнее, ~1.5 ГБ) / `large-v3-turbo` (нужен `gpu.bat`). `device` — `cpu` (int8) или `cuda`. `fast` — быстрее в ущерб чуть-чуть точности.
- `voice.stt.cloud` — распознавать через Groq whisper-large-v3-turbo (~1 с, но голос уходит в облако). По умолчанию `false`; в режиме `local` облако не используется никогда.
- `voice.tts.engine` — `edge` (онлайн, голоса Microsoft) / `silero` (офлайн, `silero.bat`) / `off`. `speaker` — голос Silero (`eugene`, `aidar`, `baya`, `kseniya`, `xenia`), `edge_voice` — голос Microsoft.
- `voice.tts.reply_in_telegram` — `voice` (голосом отвечать на голосовые, по умолчанию) / `always` (на всё) / `never` (только текст).
- `voice.pc.hotkey` — горячая клавиша «слушать» (в примере `ctrl+shift+space`; если ключ пуст, клиент берёт `ctrl+shift+j`).
- `voice.pc.mic` — микрофон (пусто — системный; номер из `voice.bat --mics`).
- `voice.pc.silence_sec` — пауза, после которой команда считается сказанной. 0.8 — быстро, 1.5–2 — если обрывает на раздумьях.
- `voice.pc.max_command_sec`, `followup_sec`, `conversation_sec`, `conversation_mode_sec`, `filler_sec` — тайминги диалога; `beep`, `stream`, `speak_reminders` — звук, потоковый ответ, озвучивание напоминаний.
- `voice.pc.morning_report` — утренний доклад вслух, когда впервые сел за компьютер; `night_from` / `night_to` / `night_volume` — ночной режим.
- `voice.pc.tidy_downloads_days` — ночная уборка «Загрузок»: файлы старше N дней едут в `Загрузки/Разобрано` (журнал, «отмени уборку»). 0 — выключено.
- `voice.pc.games` — свои exe-имена для авто-игрового режима.
- `voice.pc.screen_time` — `enabled`, `idle_min`, `nudges`, `keep_days`: экранное время (только имя программы и сайт/заголовок окна, локально в базу, **в облако никогда**).

Полностью голос разобран в [VOICE.md](VOICE.md).

### `server`

`host` (по умолчанию `0.0.0.0`, чтобы сайт открывался с телефона) и `port` (по умолчанию `8765`).

### `google`

`enabled`, `client_id`, `client_secret`, `calendar_id`, `proxy`. Календарь работает **в одну сторону**: всё, что попало в календарь ассистента, уезжает в Google; обратно ничего не читается.

### `backup`

`enabled`, `dir` (`./data/backups`), `keep_days` (30), `extra_dir` — вторая копия на другой диск или в папку Яндекс.Диска.

## Переменные окружения из `.env.example`

| Переменная | Что задаёт | Обязательна |
|---|---|---|
| `ASSISTANT_TG_TOKEN` | `telegram.token` | нет |
| `ASSISTANT_TG_OWNER` | `telegram.owner_id` | нет |
| `OLLAMA_URL` | `brain.ollama.url` (в Docker — `http://ollama:11434`) | нет |
| `OLLAMA_MODEL` | имя модели Ollama — **по коду ядро его не подхватывает** для основной модели (только `core/pc/organize.py` как запасной вариант): задавай модель в `config.yaml` / на сайте | нет |
| `GEMINI_API_KEY` | ключ облака. Комментарий в `.env.example` упоминает ещё `GROQ_API_KEY`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, `DEEPSEEK_API_KEY`, `NVIDIA_API_KEY`, но **по коду подхватывается только `GEMINI_API_KEY`** — остальные ключи задавай в `config.yaml` / на сайте | только для `hybrid` / `cloud` |
| `ASSISTANT_PORT` | порт окна-приложения `desktop_app.py` (его читает только оно) | нет |
| `ASSISTANT_HOST` | **по коду не читается** — адрес сервера берётся из `server.host` в `config.yaml` | нет |
| `HF_HOME` | куда качать модели распознавания речи (по умолчанию `~/.cache/huggingface`) | нет |
| `ASSISTANT_NO_VOICE_WARMUP` | не прогревать голос на старте | нет |
| `ASSISTANT_NO_BROWSER` | не открывать браузер при старте | нет |
| `ASSISTANT_DOCKER` | режим Docker: скрыть проверки звука и ограничения | нет |
| `ASSISTANT_TEST` | обход авторизации **только для тестов**, никогда не включать у себя | нет |
| `PORT` / `HOST` / `ALLOWED_ORIGINS` / `LLM_API_KEY` / `LLM_URL` / `LLM_MODEL` | только для Node-стенда `server.ts`, Python-ядро их не использует | нет |
