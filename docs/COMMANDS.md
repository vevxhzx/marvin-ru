# Команды

Отвечать можно двумя способами, и это не одно и то же:

- **⚡ офлайн** — правила-шаблоны (`core/brain/quick.py` и `rules()` в `core/brain/agent.py`) и инструменты, вызванные по шаблону. Работают мгновенно и **без нейросети** — даже если Ollama не запущена, а облака нет.
- **🧠 / ☁️ модель** — та же фраза, но её разбирает локальная модель (🧠) или облако (☁️). Нужна для гибких формулировок и всего, что не попал в шаблоны.

Около 40 бытовых команд попадают в первый список. Ниже — сначала офлайн-команды, потом полное меню бота, потом примеры фраз по областям.

## Офлайн-команды (⚡, без нейросети)

### Деньги

| Скажи / напиши | Что будет |
|---|---|
| `сколько потратил на еду` / `за неделю` / `на такси за месяц` / `в августе` / `вчера` | Сумма, число операций, средний чек, остаток лимита |
| `куда ушли деньги за месяц` / `траты за неделю` / `сколько заработал за месяц` | Разбивка по категориям / доходы |
| `сколько денег` / `сколько на т-банке` / `сколько на наличных` | Балансы |
| `700 такси` / `кофе 350` / `такси 700 вчера` | Трата без глагола (сумма + известная категория) |
| `потратил 1200 на еду вчера` / `… позавчера` / `… 5 сентября` | Трата задним числом |
| `зп 120 тыс` / `+5000 вернули долг` | Доход |
| `баланс т-банк 85000` | Сверить баланс счёта |
| `заплатил Ване 2000` / `вернул Ване 2000` / `перевёл Ване 3000` | Платёж по долгу (имя в любом падеже) |
| `закрой долг Ване` | Долг гасится остатком и закрывается |
| `Ваня вернул 5000` / `вернули долг 5000` | Доход «вернули» |
| `перевёл 5000 на сбер` / `снял 3000 наличных` | Перевод между счетами (общий баланс не меняется) |
| `подписка яндекс плюс 399 25-го` / `регулярный интернет 900 5-го` | Регулярный платёж |
| `отмени подписку яндекс` | Остановить регулярный платёж |
| `лимит на еду 20000` / `убери лимит на еду` | Месячный лимит категории |
| `какие долги` / `кому я должен` / `что по долгам` | Список долгов с прогнозом |
| `подписки` / `на что я подписан` | Регулярные и «тихие» списания, которых нет в регулярных |
| `прогноз` / `хватит ли до зарплаты` / `сколько можно тратить в день` | Касса на 30 дней |
| `хватит ли на платежи` | Ближайшие регулярные против остатка на счетах |
| `50/30/20` / `сравни с прошлым месяцем` / `на сколько хватит` | Фин-техники и сравнения |
| `долг Сберу 120к плачу 8к 25-го` / `должен Ване 5000` | Долг (+ авто-платёж каждое 25-е и прогноз закрытия) |
| `отмени последнюю` / `отмена` / `не то, удали` / `отбой` | Откат последнего действия любого типа |
| `сотри все финансы за последние 2 дня` / `удали задачи за неделю` / `очисти историю чата` | Массовая чистка: сначала покажет, сколько записей и на какую сумму, и спросит «да/нет»; «отмена» вернёт всё из корзины |

### Календарь, задачи, повторы

| Скажи / напиши | Что будет |
|---|---|
| `что у меня завтра` / `что в пятницу` / `что на выходных` / `какие планы на неделе` / `что 12 сентября` | События + дедлайны + платежи |
| `встреча в среду в 15:00 с Ваней` / `ужин в 7 вечера` / `завтра утром зубной` | Событие в календаре (напоминание за 30 мин) |
| `напомни завтра в 10 позвонить врачу` | Событие + напоминание за 10 мин; без времени — спросит «когда?» |
| `починить полку` / `надо купить молоко` / `позвонить маме` | Задача без срока |
| `сдать отчёт до пятницы` / `купить подарок до 20 сентября` | Задача с дедлайном |
| `тренировка каждый пн ср пт в 19` / `каждый день в 8 зарядка` / `др мамы каждый год 14 марта` | Повторяющееся событие |
| `сегодня тренировки не будет` | Пропуск только этого раза |
| `перенеси ужин на 20:30` / `перенеси созвон на пятницу` | Перенос события |
| `переименуй ужин в ужин с семьёй` | Новое название |
| `удали задачу про полку` / `удали событие иван` | Удаление по части названия |
| `сделал молоко` / `сделала — позвонила в поликлинику` | Закрыть задачу (или событие) по части названия |
| `задача: сдать отчёт через 3 дня` | Явная задача (в т. ч. с датой) |
| `что мне сегодня делать?` / `фокус дня` | 1–3 шага, которые двигают цели |

Если есть дата, но непонятно, что это, — ассистент **спросит**: «календарь или задача?». Уточняющий вопрос переживает перезапуск.

### Заказы, помодоро, цели

| Скажи / напиши | Что будет |
|---|---|
| `заказ: ролик для Пятёрочки, 25к, до пятницы` | Заказ с клиентом, суммой, дедлайном (дедлайн уходит в календарь как «Сдать: …») |
| `пришёл аванс 10000 за ролик` / `получил оплату 15к за монтаж` | Доход «Фриланс» с привязкой к заказу |
| `заказы` / `кто мне должен` / `дедлайны` | Что в работе, что горит, сколько не оплачено |
| `кто задерживает` / `кто тянет с оплатой` | Сданные, но не оплаченные заказы старше порога |
| `таймер` / `таймер на ролик` / `помодоро на 40 минут по монтажу` | Один таймер на сайт + Telegram + голос |
| `стоп` / `перерыв` / `сколько я сегодня работал` | Остановить · перерыв 5 мин · минуты фокуса |
| `сдал ролик` / `правки по ролику` / `отменили монтаж` | Смена статуса заказа |
| `цель: подушка 300к к марту` / `копим на камеру 120 тысяч` | Денежный конверт с суммой в месяц |
| `отложил 10к в подушку` / `взял 5к из подушки` | Расход/возврат с привязкой к конверту |
| `цели` / `конверты` | Прогресс по целям (и долгосрочным, и денежным) |

### Мозг, память, люди

| Скажи / напиши | Что будет |
|---|---|
| `мысль: идея для ролика` / `мозг- идея` / `запомни: …` / `идея …` | Заметка во «второй мозг» (редактор причешет, оригинал сохранится) |
| любая ссылка (+ комментарий) | Сохранится с заголовком, обложкой, доменом |
| `что я говорил про врача?` / `где лежит паспорт?` / `найди рецепт пирога` | Поиск по заметкам, ссылкам и журналу |
| `исправь заметку про очки: они в комоде` / `дополни мысль о ролике: добавить титры` | Правка заметки без модели |
| `человек: Лена, сестра, др 12.03` / `клиент: Пятёрочка, магазин` | Карточка человека/клиента |
| `что по Ване` / `кто такая Лена` / `карточка клиента Пятёрочка` / `досье на Петрова` | Всё про человека: заказы, долги, встречи, задачи, мысли |
| `решил: беру заказ только с предоплатой, потому что…` / `почему я так решил про Лену` | Журнал решений |
| `мои рутины` / `как дела с тренировкой` | Серия, пропуски, N из M за месяц |

### Присутствие, отчёты, мелочи

| Скажи / напиши | Что будет |
|---|---|
| `сегодня` / `дайджест` / `бриф` / `брифинг` | События, задачи, платежи, баланс |
| `что происходит?` | Состояние одной фразой (за ПК/отошёл, что открыто, чего ждёт) |
| `сколько сидел за компом` / `на что ушёл день` / `сколько ютуба сегодня` | Экранное время |
| `стрик` / `сколько дней подряд` | Серия дней с записями |
| `проверь себя` | Самопроверка по 10 пунктам (Ollama, облако, ПК-клиент, Telegram, бэкап…) |
| `сверься` / `откуда ты это взял` / `у меня другие данные` | Перечитать базу по теме последних сообщений |
| `подкинь монетку` / `выбери за меня: пицца или суши` | Случайный выбор |
| `протокол Чистый лист` | Архивировать выполненные задачи старше месяца (ничего не удаляется) |
| `я Железный человек` / `ты тут?` / `спокойной ночи` | Пасхалки и короткие реплики |
| `спасибо` / `ок` / `хватит` / `привет` / `как дела` | Короткие ответы без похода в модель |

### Управление ПК (нужен `voice.bat`)

| Скажи / напиши | Что будет |
|---|---|
| `открой ютуб` / `открой habr.com` / `открой калькулятор` / `открой загрузки` | Сайт, программа или папка |
| `найди файл договор` | Поиск в Документах/Рабочем столе/Загрузках (и D–F) |
| `разбери рабочий стол` / `прибери в загрузках` | План уборки, по «да» — перенос по категориям (ничего не удаляется), «отмени уборку» вернёт |
| `пауза` / `дальше` / `громче` / `тише` / `без звука` | Медиа-клавиши |
| `что на экране` / `переведи это` / `что это за ошибка` | Скриншот → модель зрения |
| `запомни это` | Содержимое буфера → в Мозг |
| `статус костюма` | Процессор, память, температура, видеокарта, диски, аптайм |
| `заблокируй компьютер` / `выключи компьютер` / `перезагрузи` / `спящий режим` | Питание (выключение — через 30 с, «отмена выключения» успеет) |
| `иду играть` / `игра окончена` | Игровой режим: выгрузить/вернуть локальную модель |

## Команды бота (меню Telegram)

Это полный список из `set_my_commands` — он виден при вводе `/` в чате с ботом. Все они работают офлайн (⚡).

| Команда | Описание |
|---|---|
| `/today` | Что сегодня |
| `/money` | Финансы |
| `/tasks` | Задачи |
| `/events` | Календарь на неделю |
| `/debts` | Долги |
| `/forecast` | Прогноз кассы на месяц |
| `/orders` | Заказы: дедлайны и кто должен |
| `/missed` | Что я упускаю: оплаты, долги, цели |
| `/pomo` | Помодоро 25 мин (`/pomo ролик` · `/pomo stop`) |
| `/goals` | Цели и конверты |
| `/week` | Обзор недели: мысли и задачи |
| `/report` | Открытка-отчёт за неделю (`/report 30` — месяц) |
| `/month` | Как я жил в этом месяце — снимок |
| `/summary` | Итог дня одной карточкой |
| `/find` | Поиск по «второму мозгу» |
| `/exp` | Трата одним тапом: `/exp 700 такси` |
| `/task` | Задача одним тапом: `/task сдать отчёт` |
| `/voice` | Голосовые ответы: на голосовые / всегда / никогда |
| `/game` | Игровой режим вкл/выкл (освободить видеокарту) |
| `/diag` | Диагностика мозга и облака |
| `/app` | Открыть сайт внутри Telegram |

Есть и команды, которых нет в меню (но они работают):

| Команда | Что |
|---|---|
| `/start` | Приветствие и шпаргалка |
| `/id` | Твой Telegram ID |
| `/расход`, `/exp` / `/доход`, `/inc` / `/задача`, `/task` / `/встреча`, `/event` | Быстрые шаблоны: `/расход 700 такси`, `/доход 15000 аванс`, `/задача сдать отчёт`, `/встреча в среду в 15:00` (выключается `telegram.quick: false`) |
| `/найди`, `/поиск`, `/find` | Поиск по Мозгу |
| `/итог`, `/итоги`, `/summary`, `/evening` | Итог дня |
| `/упускаю`, `/missed` | Что упускаю |
| `/месяц`, `/month` | Снимок месяца |

## Примеры фраз по областям

**Деньги**
`потратил 700 на такси` · `купил продукты 2500` · `-350 кофе` · `заплатил за свет 2300` · `зп 120к` · `аванс 15000` · `долг Сберу 120к плачу 8к 25-го` · `сколько у меня осталось` · `куда ушли деньги за месяц`

**Задачи и цели**
`надо позвонить в поликлинику` · `сдать отчёт до пятницы` · `сделал молоко` · `цель: собрать портфолио до конца года, потому что хочу брать заказы дороже` · `веха: 3 сцены в портфолио` · `задача: сцена кухни к вехе 3 сцены` · `что мне сегодня делать?`

**Календарь**
`встреча в среду в 15:00 с Ваней` · `завтра в 10 к врачу` · `напомни в четверг купить лекарства` · `тренировка каждый пн ср пт в 19` · `перенеси ужин на 20:30` · `что у меня завтра`

**Заказы**
`заказ: ролик для Пятёрочки, 25к, до пятницы` · `пришёл аванс 10000 за ролик` · `заказы` · `кто задерживает` · `таймер на ролик` · `стоп`

**Заметки и мозг**
`мысль: …` · `запомни: паспорт лежит в верхнем ящике комода` · `сдала анализы, результат в четверг` · ссылка без слов · `что я говорила про врача?` · `найди рецепт пирога`

**Люди**
`человек: Лена, сестра, др 12.03` · `клиент: Пятёрочка, магазин` · `что по Ване` · `отправить Ване правки` (ассистент напомнит важное по человеку)

**Отчёты**
`/today` · `/summary` · `/week` · `/report` · `/report 30` · `/month` · `проверь себя` · `что я сегодня делал` · `что было вчера`
