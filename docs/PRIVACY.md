# Приватность: local / hybrid / cloud

Три режима — и вся разница в том, куда уходит «мозг» для ответа. Выбирается в мастере первого запуска или потом в ⚙ Настройках (`brain.mode`). Ниже — честно, без «мы заботимся»: что именно и когда покидает компьютер, а что не покидает никогда.

## Коротко

| Режим | Где думает | Что уходит наружу | Кому подходит |
|---|---|---|---|
| **`local`** | только Ollama на твоём ПК | ничего, работает без интернета | видеокарта от 4–6 ГБ; максимум приватности |
| **`hybrid`** (по умолчанию) | личное — локально, общие вопросы — в облако | только общие вопросы и разговор, **обезличенно** | есть видеокарта, хочется и быстро, и умно |
| **`cloud`** | всё у провайдера API | по факту всё: заметки, траты, календарь | нет видеокарты / слабый ноутбук / второй ассистент |

Каждый ответ подписан источником: ⚡ правило (без нейросети) · 🧠 локально · ☁️ облако. Около 40 бытовых команд работают **вообще без модели**, в любом режиме.

## Режим `local`

`llm.cloud_enabled()` возвращает `false` — и это единственная точка, через которую в проекте спрашивают «а есть ли вообще облако». Когда она `false`:

- разговор и общие вопросы ведёт локальная модель (медленнее и проще, но приватно);
- распознавание речи — всегда локально (Whisper на ПК), даже если `voice.stt.cloud: true`;
- зрение (скриншоты, чеки) — локально;
- сортер списков, память, связи, судья — на ПК;
- в интернет не уходит ничего. Ассистент работает без сети (кроме Telegram, если он тебе нужен).

Единственное, что может «ходить в интернет» в режиме `local`: обновление модели Ollama, проверка прокси Telegram и — отдельно — **озвучка Edge**. Об этом ниже.

## Режим `hybrid`

Что остаётся на ПК:

- всё, что `agent.is_personal()` считает личным: деньги, счета, траты, календарь, задачи, заметки, файлы, «мои …», даты, числа;
- любые действия, которые что-то пишут или читают в базе, — инструменты выполняет **локальная** модель;
- распознавание речи — локально (`voice.stt.cloud` по умолчанию `false`);
- чеки с фото — только локальная модель зрения, в облако не уходят никогда;
- поиск по памяти — всегда локально (эмбеддинги считает ПК).

Что уходит в облако:

- «разговор» и общие вопросы («что такое инфляция», «напиши поздравление») — если в настройках включено `brain.gemini.auto` (по умолчанию да). Можно выключить и вызывать облако только словом «облако, …»;
- разбор длинного смешанного сообщения-списка (`brain.sorter.where: cloud`) — **текст уходит целиком**, но через общий анонимайзер;
- извлечение фактов о тебе и портрет (`brain.memory.where: cloud`), связи между записями (`brain.relations.where: cloud`), формулировка инициативных фраз (`persona.where: cloud`);
- скриншот «что на экране» — если выбран облачный вариант зрения (`brain.vision.where: auto` с `allow_cloud: true`, по умолчанию так). Чеки исключены всегда.

**Анонимайзер.** Перед отправкой в облако `llm.anonymize()` вырезает секреты (пароли, ключи, токены, CVV — «[скрыто]»), телефоны, email, номера карт, суммы, а также имена людей, которые уже есть в твоей базе (`[имя]`). Модели отдельно говорится не повторять плейсхолдеры в ответе.

## Режим `cloud`

Тут честно: облако видит всё. Инструменты (записать трату, найти заметку, «что сегодня») выполняет облачная модель — значит, и данные уходят полными. База при этом **по-прежнему лежит на твоём ПК**: провайдер обрабатывает запросы, но не хранит у себя твою базу.

Важная деталь: у OpenAI-совместимых провайдеров (Groq, OpenRouter, NVIDIA, DeepSeek, свой) анонимайзер в режиме `cloud` **выключен намеренно** — иначе «[сумма]» вместо 700 портил бы заметки и записи. У Gemini анонимайзер остаётся, если `brain.gemini.anonymize: true`.

## Что не уходит наружу никогда

- Файлы на диске. Ассистент читает и **переносит**, но не удаляет и не отправляет их содержимое в облако (кроме текста, который ты сам вставил в чат).
- Содержимое `data/` и `config.yaml` — они не в git и не покидают машину по инициативе ассистента.
- Заголовки окон при учёте экранного времени — только для классификации сайта/программы, в промпт, события и ленту не попадают.
- Пароли и PIN: `agent.is_personal` относит фразы с ними к личному, а `anonymize` дополнительно скрывает похожие на секрет значения.

## Голос: локально по умолчанию

| Что | По умолчанию | Уходит в облако? |
|---|---|---|
| Слово-активация (Vosk) | офлайн | нет |
| Распознавание речи (faster-whisper) | локально | нет (пока `voice.stt.cloud: false`) |
| Озвучка Silero (`tts.engine: silero`) | офлайн | нет |
| Озвучка Edge (`tts.engine: edge`) | **по умолчанию edge** | да: **текст ответа** уходит в Microsoft (синтез речи онлайн) |
| Голосовые в Telegram | расшифровка на ПК | нет |

Отдельно отмечу Edge: это удобно и красиво, но текст озвучиваемого ответа уходит в Microsoft. Хочешь полностью офлайн — поставь `voice.tts.engine: silero` (или `off`). Подробности — [VOICE.md](VOICE.md).

## Где лежат данные

| Что | Где |
|---|---|
| Вся база (события, задачи, деньги, заметки, люди, память, доска, чат) | `data/assistant.db` (SQLite, WAL) |
| Картинки заметок и чеков, ассеты досок | `data/media/` |
| Ключ доступа с других устройств | `data/api_token` (создаётся сам, права 600 вне Windows) |
| Секрет серверных сессий Telegram Mini App | `data/session_secret` |
| Модели голоса (Vosk, Silero) | `data/models/` |
| Лог голосового клиента | `data/voice.log` |
| Настройки и секреты (токен бота, ключи облака, Google) | `config.yaml` — в `.gitignore`, в API отдаётся замаскированным |
| Переменные окружения (если используешь) | `.env` — тоже в `.gitignore` |

## Бэкапы

Каждую ночь (3:00) ядро делает копию базы через `sqlite3.backup()` в `data/backups/` и хранит `backup.keep_days` дней (по умолчанию 30). Картинки из `data/media/` зеркалируются в `backups/media/` инкрементально. Можно задать `backup.extra_dir` — вторую копию на другой диск или в папку Яндекс.Диска. Восстановление — из ⚙ Настроек, и перед ним сохраняется страховочный слепок текущего состояния (`backup-pre-restore-*.db`). Бэкапы — это копии на **твоих** дисках, в облако они не уезжают.

## Как проверить самому

- `llm.cloud_enabled()` в `core/brain/llm.py` — истина, только если `brain.mode` = `hybrid`/`cloud` и задан ключ. Эту же функцию использует `core/services/health.py` для диагностики.
- ⚙ Настройки → раздел «система → состояние»: показывает режим, включено ли облако, провайдера и модель.
- `GET /api/status` — те же поля в JSON (`gemini.enabled`, `gemini.mode`, `gemini.provider`).
- `/diag` в Telegram — что отвечает и за сколько, включая облако.
- «проверь себя» в чате — самопроверка по 10 пунктам.

## Как полностью запретить облако

Один переключатель решает всё:

```yaml
brain:
  mode: "local"
```

`cloud_enabled()` вернёт `false`, и все места, где раньше стояло `where: cloud`, сами упадут на локальную модель. Для страховки и отсутствия случайных утечек можно заодно:

```yaml
brain:
  vision: { where: "local", allow_cloud: false }
  sorter: { where: "local" }
  memory: { where: "local" }
  relations: { where: "local" }
  judge: { where: "local" }
persona: { where: "local" }
voice:
  stt: { cloud: false }
  tts: { engine: "silero" }   # или "off", если озвучка не нужна
```

И удалить ключи облака (`brain.cloud.api_key`, `brain.gemini.api_key`), чтобы их не было даже случайно. Это не отдельная «настройка приватности», а честное отсутствие ключа.

> Отдельно про доступ по сети: Tailscale Funnel и Mini App делают сайт доступным из интернета — это про **доступ**, а не про то, куда уходят данные для ответа. Разбор — [telegram-miniapp.md](telegram-miniapp.md).
