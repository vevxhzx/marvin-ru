## 6. Чек-лист ручной проверки для владельца

1. `cd web && npm run build` (обязательно — сайт пока в старой сборке), затем `cd web && npm run test:e2e`.
2. **Заказы, первый заход в чистом профиле:** сверху открыта подсказка «Как это работает» → свернуть →
   появилась кнопка «?» → открывает снова; подсказка гаснет навсегда после закрытия.
3. **Строка заказа:** кликается целиком (открывается панель); кнопки-пилюли-ряд отсутствуют;
   одна главная кнопка с текстом по стадии («Отправить на правки», «Сдать», «Запросить оплату»,
   «Отметить оплату»); в «⋯» — таймер, изменить, обсудить, оплата, удалить — все с текстом.
4. **Панель заказа:** степпер меняет стадию, «потерян» требует причину; в «оплате» — сумма/предоплата/остаток
   и «записать оплату»; в «времени» — таймер и ручной ввод; в «клиенте» — ссылка на карточку и список
   стадий клиента с подписью «вручную»/«вернуть авто».
5. **Новый заказ:** стадии подписаны как в воронке; чекбокс «Заказ уже выполнен» включает поле оплаты;
   поле подписано «Сколько часов планируете».
6. **Канбан:** у каждой колонки — количество и сумма; пустая колонка — «Перетащите карточку сюда»;
   на десктопе карточка тащится мышью, на телефоне — выпадающий список стадии на карточке.
7. **Люди:** у карточек клиента есть бейдж стадии и список (смена → появляется «вручную»),
   сверху фильтр по стадиям со счётчиками; откройте человека → «следующий шаг» + дата → «сохранить».
8. Мобильный вид (375 px): заказы, панель заказа, люди — без горизонтального вылезания.
