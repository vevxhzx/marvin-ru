## Этап 3 — Карточки-картинки — ВЫПОЛНЕНО

- **Выбор рендера: Pillow** (а не headless Chromium). Почему: Pillow уже работает и не тянет браузер (~150 МБ + Playwright),
  надёжен на Windows без Node и без GUI, детерминирован, быстрый (десятки мс). HTML-рендер дал бы больше гибкости, но добавил бы
  тяжёлую зависимость и хрупкость на чистой установке — для «открытки в Telegram» это перевес в сторону Pillow.
- **Фирменный стиль** (`core/services/cards.py`): акцент `#0a3cff` (10,60,255), градиентная шапка, знак **split-asterisk**
  (8 лучей), бейдж раздела, крупная типографика, bento-плитки. Обновлены и прежние карточки (утро/вечер/отчёт) — единый стиль.
- **Новые короткие карточки действий**: `expense_card` (сумма, категория, баланс, остаток/перерасход лимита),
  `task_card`, `event_card`, `done_card` (+ общий `action_card`). Рисканные образцы — в `data/tmp/samples/`.
- **Режим `cards.mode`**: `always` / `important` (важные + короткие карточки на траты и задачи — по умолчанию) / `never`.
  Настройка в ⚙ Настройки → «голос и ПК» → «картинки». Дайджесты/отчёты уважают режим (`should_send`).
- **Не задерживает ответ**: текст уходит сразу, картинка — следом (`_maybe_send_card`). **Кэш** по содержимому
  (`data/card_cache`), одну карточку не рисуем дважды.
- Тесты: `tests/test_cards_brand.py` (+4); всего `python -m pytest tests -q` → **385 passed**; сайт пересобран.

## Этап 2 — Голос — ВЫПОЛНЕНО

- **STT-словарь из своих данных** (`core/voice/stt.py::_hotwords`): имена людей/клиентов (+алиасы), названия заказов,
  активные задачи, цели, недавние заметки → `initial_prompt`/`prompt` Whisper. Локально, кэш 5 минут.
- **Уверенность и шум**: `transcribe_detailed()` → `{text, confidence, no_speech, via}`; `looks_unsure()` (порог 0.5 / шум 0.6).
  Мусорную расшифровку **не отправляем в LLM**.
- **Telegram**: при низкой уверенности бот показывает расшифровку и спрашивает **✅ Верно / 🔁 Повторить / ✏️ Исправить**
  (callback `vc:*`, только владельцу). Защита от повторной доставки апдейта (`_once`).
- **ПК-клиент** (`voice_client.py`): при низкой уверенности озвучивает «расслышал так себе… повторите» и не выполняет команду.
- **Облако/локально**: Groq `whisper-large-v3-turbo` в hybrid/cloud (гейт `_cloud_ok()` — в `local` никогда), иначе/при сбое —
  локальный faster-whisper. Локальная модель по умолчанию в `config.yaml` — `medium` (для GPU — `large-v3-turbo` после `gpu.bat`).
- **TTS**: дефолт `reply_in_telegram: "voice"` (голосом на голосовые); **кэш озвучки** `data/voice_cache` (одинаковые фразы не
  синтезируются дважды, авто-очистка до 400 файлов). Голос по умолчанию — `edge ru-RU-DmitryNeural` (спокойный мужской, под
  сухой ироничный тон; офлайн — Silero `eugene`/`aidar`).
- Тесты: `tests/test_voice.py` (+6); всего `python -m pytest tests -q` → **381 passed**.

## Этап 9 — Доработка по просьбе — ВЫПОЛНЕНО

Порядок: сначала баги, потом Tailscale, потом карточки и 5 улучшений.

**Баги.**
- **«Мозг» падал** с `W.map is not a function`. Причина: API отдаёт `tags` **строкой** `"монтаж,друг"`,
  а фронт звал `it.tags?.map(…)`. Добавлен `listOf()` в `web/src/lib/api.js`; исправлены `Mind.jsx` и `People.jsx`
  (в «людях» теги ещё и разворачивались в буквы при поиске). Проверено: 27 карточек, 0 ошибок JS.
- **Карточка важного ответа на сайте**: `/api/chat` и `/api/chat/stream` теперь возвращают `card` (URL),
  файл отдаёт `GET /api/cards/{name}` (принимаем только имя файла — обход каталога закрыт). В чате карточка рисуется
  ссылкой-картинкой. Отдельно починено «мигание»: `bump()` перезагружал историю (карточек там нет) — теперь карточка
  переносится по совпадению (роль + текст без хвостового «⚡») и вешается **только на последнее** совпавшее сообщение.

**Tailscale (без VPN на телефоне).**
- Уже реализовано: `funnel.bat` включает **Tailscale Funnel** — сайт получает публичный HTTPS (`https://имя-пк.имя-сети.ts.net`),
  и Telegram Mini App работает с телефона **без VPN-приложения**. Нужно лишь: Tailscale на ПК, вход, в админке включить
  HTTPS и Funnel, затем `funnel.bat`. Ограничения: ПК включён; бесплатный тариф (лимиты Funnel). Альтернатива без Tailscale —
  `cloudflared`/ngrok (не делал: это смена внешней зависимости, вынес как опцию).

**Карточки (редизайн, «не фулл-фотка»).**
- Тема карточек переведена на **светлую**, как «утренний дайджест» на сайте (эталон `MorningDigestCard`, `web/src/index.css`);
  прежние утро/вечер/отчёт перерисованы автоматически (та же логика, новая палитра).
- Короткие карточки — **полоса 21:9** (`band_card`, 1260×540): бейдж со знаком, крупный заголовок, bento-плитки
  (hero-градиент + пастельные), подвал. Образцы: `data/tmp/samples/new_*.png`.
- Новые: **«финансы»** (`finances_card`), `order_card`. Выбор карточки для важного ответа — единый `cards.for_result()`
  (Telegram и сайт показывают одно и то же → синхронизированы).

**Пять улучшений.**
1. **PWA-ярлыки** (`manifest.json` в `app.py`): Трата/Доход/Задача/Мысль → чат с готовым началом (`/?quick=exp`,
