# macOS: как «настоящее» приложение

Другу на MacBook **не нужны** чёрные окна терминала.

## Один раз

1. Скачать ZIP репо, распаковать (например `~/Assistant`).
2. Дважды кликнуть **`Install-Mac.command`** (ПКМ → Открыть, если Gatekeeper ругается).
3. Дождаться установки → «Запустить сейчас».

Появится **`Marvin.app`** в `~/Applications`. Иконка в **строке меню** (справа вверху).

| Меню | |
|---|---|
| Открыть сайт | браузер → localhost |
| Перезапустить | ядро |
| Папка данных | `data/` |
| Выйти | гасит процесс |

Первый запуск откроет **мастер** (имя, мозг, Telegram). Потом — обычный сайт.

## Автозагрузка

`Install-Mac.command` спросит. Или вручную: объекты входа → `~/Applications/Marvin.app`.

## Голос / Ollama

Как раньше: `install_voice.command`, [Ollama](https://ollama.com/download). Не обязательны.

## Без «приложения»

`./start.command` — старый путь с окном Терминала.

## Dev

```bash
.venv/bin/python mac/host.py
```

Сборка .app руками — тот же `Install-Mac.command`.
