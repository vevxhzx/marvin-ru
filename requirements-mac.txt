# Ядро для macOS (Apple Silicon и Intel). Отдельный файл не для красоты:
# в requirements.txt лежит `torch>=2.2`, а у torch на macOS НЕТ колёс для Intel
# (`macosx_*_x86_64` не публикуются вообще) и нет колёс для macOS ниже 14.0.
# То есть на Intel Mac и на macOS 13 базовая установка падала бы на сборке
# из исходников — а torch нужен только Silero (офлайн-озвучка), то есть
# отдельному голосовому аддону (requirements-silero.txt).
#
# Что здесь НЕ ставится по умолчанию:
#   · torch                → requirements-silero.txt (озвучка Silero, ~2 ГБ), не обязателен;
#                            без него работает edge-tts (озвучка Microsoft, нужен интернет);
#   · nvidia-cublas/cuDNN  → requirements-gpu.txt, только для NVIDIA (на Mac нет смысла);
#   · vosk/sounddevice/keyboard/pystray → requirements-voice.txt (микрофон и wake word);
#   · pywebview            → requirements-windows.txt (настольное окно; на mac своё — mac/host.py).
#
# Остальное — ровно то, что нужно ядру (FastAPI, БД, Telegram, LLM-клиент,
# документы, распознавание голосовых в Telegram). Версии — нижние границы,
# как в requirements.txt: не сужаем, чтобы не ломать обновление у пользователя.
# Проверено: у всех пакетов ниже есть macOS-колёса (arm64 + x86_64).
