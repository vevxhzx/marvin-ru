## Устройство

| Слой | Где | Что делает |
|---|---|---|
| Точка входа | `run.py` | один процесс: HTTP API (FastAPI/uvicorn, порт 8765) + Telegram-бот (aiogram, long polling) + планировщик (APScheduler) |
| Мозг | `core/brain/` | маршрутизация: быстрые правила → локальная модель (Ollama) → облако (Groq/OpenRouter/Gemini/…) → честное «не понял» |
| Инструменты | `core/tools/registry.py` | ~45 инструментов для function calling: календарь, деньги, задачи, доски, заказы, люди, цели, заметки |
| Данные | `core/db.py` | одна SQLite (`data/jarvis.db`), SQLModel, ручные миграции `ALTER TABLE` в `_migrate()` |
| Сервисы | `core/services/` | финансы, календарь, задачи, заказы, люди, память, связи, граф, экранное время, бэкапы, карточки-отчёты |
| Telegram | `core/telegram/bot.py` | команды, голосовые, фото/чеки, документы-выписки, инлайн-кнопки, Mini App |
| Голос на ПК | `voice_client.py` + `core/voice/` | wake word (Vosk) → Whisper → ядро → Silero/Edge TTS, иконка в трее, горячая клавиша |
| Сайт | `web/` (Vite + React + Tailwind) | сборка `npm run build` → `web/site/`, раздаётся Python API как SPA |
| Установка | `install.bat` → `setup.py`, `start.bat` | venv + зависимости + автоперезапуск |

## Что умеет (кратко)

- **Быстрые ответы без модели** — `core/brain/quick.py`, работают мгновенно и офлайн и первыми в цепочке:
  «сколько денег», «баланс», «сколько потратил за неделю», «что у меня завтра», «какие долги»,
  «заплатил по долгу», «переведи 5000 на сбер», «подписка яндекс плюс 399 25-го», «лимит на еду 20000»,
  короткие отклики («спасибо», «пока»).
- **Правила и разбор фраз** — `core/brain/agent.py`, тоже без модели: траты, доходы, события, задачи,
  заметки, долги, отмена/перенос/удаление/переименование, массовые чистки, присутствие («ушёл/вернулся»),
  здоровье («давление 140 на 90» → память), люди, заказы, ожидание уточнений (`pending:*`, TTL 5 мин).
- **Деньги** — счета и категории, бюджет 50/30/20, регулярки, долги с прогнозом, конверты целей,
  импорт выписки Т-Банка, чек фото → трата, переводы между счетами.
- **Календарь и задачи** — повторы, дедлайны, перенос словами, напоминания в Telegram и вслух,
  выгрузка в Google Календарь (в одну сторону), каскад: галочка на встрече закрывает задачу и двигает заказ.
- **Заказы (фриланс)** — воронка из девяти стадий с канбаном, карточка заказа и клиента, follow-up,
  оплаты без дублей, помодоро, прогноз кассы.
- **Второй мозг** — заметки и ссылки с заголовками, обложками и тегами, смысловой поиск,
  правка текста с сохранением оригинала и историей версий, граф связей.
- **Память** — факты с затуханием: старые уходят в архив (не удаляются), подтверждённые не гаснут,
  устойчивое (вкусы, люди, здоровье) нейронка ночью помечает ядром — такое не гаснет никогда,
  новые факты предлагает тост «Запомнить?».
- **Голос и ПК** — wake word офлайн, распознавание и озвучка, медиа-клавиши, файлы **никогда не удаляются**.
- **Бэкапы** — ночной снимок с ротацией, облачный бэкап (WebDAV, шифрование паролем) — выключено по умолчанию.
- **Отчёты** — карточки PNG, недельная открытка, CSV/выписки, самодиагностика в настройках.

## Скрипты запуска

**Windows**

| Скрипт | Что делает |
|---|---|
| `install.bat` | первый раз: venv, зависимости, `config.yaml` |
| `start.bat` | ядро + Telegram + сайт на http://localhost:8765 |
| `phone.bat` | адрес и QR для телефона |
| `voice.bat` · `gpu.bat` | голосовой клиент ПК; `gpu.bat` — точное распознавание на видеокарте |
| `install_voice.bat` | распознавание и офлайн-озвучка |
| `funnel.bat` | сайт внутри Telegram без VPN на телефоне |
| `autostart.bat` · `update.bat` | автозагрузка и обновление |
| `build_web.bat` | пересборка сайта после правок в `web/src` |
| `mama.bat` | вторая копия на том же ПК для близкого человека (свой бот и база) |
| `publish.bat` | сборка и публикация релиза |

**macOS** — `Install-Mac.command` (установка со значком в строке меню), `start.command`,
`build_web.command`, `install_voice.command`, `autostart.command`; подробности в [docs/macos.md](docs/macos.md).

## Опциональные части

- **Локальная модель** — [Ollama](https://ollama.com/download) + `ollama pull qwen3.5:4b`:
  разбор фраз и ответы идут на своём железе (`brain.mode: local`).
- **Node-стенд** — `server.ts` + `desktop.mjs`: тот же фронт на Express без Python (`npm install && npm run dev`,
  порт 3000), состояние в `data/server-state.json` — демо-данные, **не** ваша база. Контракт фронта — `npm test`.
- **Docker** — `Dockerfile` и `docker-compose.yml`, переменная `OLLAMA_URL`; секреты (`config.yaml`, `.env`, `data/`) в образ не попадают.
- **Telegram Mini App** — сайт прямо в чате с ботом, вход подтверждает Telegram: [docs/telegram-miniapp.md](docs/telegram-miniapp.md).
