# FEATURES.md — что умеет личное издание Marvin и что пришло из публичной версии

Составлено при объединении проектов (30.09.2026) по результатам чтения кода обоих репозиториев.
Пути указаны относительно корня проекта.

---

## 1. Общее устройство (есть и там, и там)

Оба проекта — один и тот же персональный AI-ассистент (форки одной базы, версия ядра `0.12.0`):

| Слой | Где | Суть |
|---|---|---|
| Ядро / точка входа | `run.py` | один процесс: HTTP API (FastAPI/uvicorn, порт 8765) + Telegram-бот (aiogram, long polling) + планировщик (APScheduler) |
| Мозг | `core/brain/` | маршрутизация: быстрые правила → локальная LLM (Ollama) → облако (Groq/OpenRouter/Gemini/…) → честное «не понял» |
| Инструменты | `core/tools/registry.py` | ~45 инструментов для function calling (календарь, деньги, задачи, доски, заказы, люди, цели, заметки) |
| Данные | `core/db.py` | одна SQLite (`data/jarvis.db`), SQLModel, 27 таблиц, ручные миграции `ALTER TABLE` в `_migrate()` |
| Сервисы | `core/services/` (45 модулей) | финансы, календарь, задачи, заказы, люди, память, связи, граф, экранное время, бэкапы, карточки-отчёты… |
| Telegram | `core/telegram/bot.py` | команды, голосовые, фото/чеки, документы-выписки, инлайн-кнопки, Mini App |
| Голос на ПК | `voice_client.py` + `core/voice/` | wake word (Vosk) → Whisper → ядро → Silero/Edge TTS, иконка в трее, горячая клавиша |
| Сайт | `web/` (Vite + React + Tailwind) | сборка `npm run build` → `web/site/`, раздаётся Python API как SPA |
| Установка | `install.bat` → `setup.py`, `start.bat` | venv + зависимости + автоперезапуск |

## 2. Что умеет личное издание Marvin (ОСНОВА — данные и рабочая логика)

### 2.1 Быстрые ответы без нейросети — `core/brain/quick.py`
Работают мгновенно и офлайн, первыми в цепочке:
- **Спасибо / ок / пока / «марвин» / одинокие «да-нет»** — короткие отклики с сарказмом.
- **Деньги:** «сколько денег», «баланс», «сколько на сбер» (`balance_q`); «сколько потратил/ушло на еду за неделю/в месяц/N дней» с разбором периода и категории, учёт лимита бюджета (`spent`); «доходы/заработал».
- **Календарь:** «что у меня завтра/на выходных/в следующую пятницу» — события + дедлайны задач + ближайшие регулярные платежи (`agenda`).
- **Долги:** «какие долги», «заплатил/погасил по долгу X N», «закрой долг», «мне вернули» (`debts`).
- **Переводы:** «переведи 5000 на сбер», «снял 3000 наличных», перевод человеку → трата/платёж по долгу (`transfers`).
- **Регулярки и лимиты:** «подписка яндекс плюс 399 25-го», «отмени подписку X», «лимит на еду 20000» (`subscriptions`).

### 2.2 Правила-регексы в `core/brain/agent.py` (до любого LLM)
Траты, доходы, события, задачи, заметки, долги, отмена/перенос/удаление/переименование, массовые чистки, присутствие («ушёл/вернулся»), здоровье («давление 140 на 90» → память), люди, заказы, правки, «это задача», ожидание уточнений (`pending:*`, TTL 5 мин) и подтверждений.

### 2.3 Сценарии и умная маршрутизация — `core/brain/agent.py`
- `is_personal()` — деньги/календарь/файлы «мои …» жёстко только локально, в облако не уходят.
- Ручной выбор: «облако, …» / «локально, …» (`CLOUD_RX` / `LOCAL_RX`).
- **Судья** спорных фракций (`services/judge.py`, работает на локальной малой модели) — «сайт 15000» → трата/заказ/доход, откат + перезапись + `Lesson`.
- `_truth_gate()` — финальная проверка: ответ «записал» без реальной записи = ошибка.
- Журнал ходов `run` (`services/trace.py`) — «почему так решил / сколько длилось».
- История чата общая для сайта и Telegram.

### 2.4 Команды Telegram — `core/telegram/bot.py`
`/start`, `/today`, `/week`, `/money`, `/forecast`, `/tasks`, `/orders`, `/pomo`, `/goals`, `/events`, `/debts`, `/report` (картинка), `/voice`, `/game`, `/app`, `/diag`, `/id` — плюс голосовые, фото, документы-выписки, инлайн-кнопки, проактив.

### 2.5 Данные и логика, написанные пользователем (сохранены в merge)
- `config.yaml` — рабочий конфиг: имя хозяина `вовчик`, персона (юмор 9, ники «Вовчик, шеф, босс, чел»), гибридный режим мозга, Groq + Ollama `qwen3.5:4b`, голос (edge/Дмитрий, cuda-whisper), Google Календарь, бэкапы в `./data/backups`.
- `data/jarvis.db` — реальная база: траты, события, задачи, заказы, люди, заметки, факты памяти, доски, экранное время (см. §2.8).
- Вторая копия «для мамы»: `mama.bat`, `mama_setup.py`, `docs/ДЛЯ_МАМЫ.md`, `docs/second-copy.md`, `_instance_label()` в `run.py` (метка окна/лога для копии на другом порту).
- macOS-обёртка: `mac/`, `*.command`, `Install-Mac.command`.
- Тест бэкапов: `tests/test_backup_restore.py`.
- Диагностика/аудиты: `docs/AUDIT-2026-09-21-board.md`, `docs/AUDIT-2026-09-21-product.md`, `IMPROVEMENTS.md`, `PLAN.md`, `docs/site.md`, `docs/design-home.svg`.

### 2.6 Сервисы (общие для обеих версий, реализовано в `core/services/`)
Финансы (счета/категории/бюджеты 50-30-20/регулярки/долги/конверты `goals.py`), импорт выписок Т-Банка `bank_import.py` (офлайн, дедуп по `import_hash`), календарь + повторы + Google-синхронизация `gcal.py` (в одну сторону), задачи и цели `tasks.py`/`aims.py`, заказы/клиенты/помодоро `orders.py`, память о хозяине `memory.py`, смысловые связи `relations.py`, граф `graph.py`, семантика `semantic.py`, люди `people.py`, заметки/ссылки `brain_notes.py`, полировка `polish.py`, проактив `proactive.py`, инсайты `insights.py`, пульс фрилансера `pulse.py`, карточки-отчёты PNG `cards.py`, самодиагностика `health.py`, экранное время `screen.py`, ПК-действия `pc.py` + `core/pc/*`, доски `boards.py`, откат `undo.py`, массовые чистки `bulk.py`, таймлайн `timeline.py`, решения `decisions.py`.

### 2.7 Интеграции
Telegram (Mini App `tg_auth.py`, прокси, OAuth-вход `auth.py`), Google Календарь, Ollama + облачные провайдеры (Groq/OpenRouter/Nvidia/DeepSeek/свой/Gemini), импорт CSV/PDF-выписок, PC-клиент по SSE (`/api/events/stream`), голос.

## 3. Что пришло из публичной версии (код, веб-интерфейс, дизайн, фичи)

### 3.1 Новый веб-интерфейс и дизайн
- **Полный редизайн** по эталону `docs/dzharvis-app-v7.html`: токены светлой/тёмной темы, Inter Tight + JetBrains Mono, радиусы 30px, анимации aurora/sheen/draw/breathe, 13 акцентов и оттенки поверхностей (`web/src/index.css`, `src/index.css`).
- **Новые страницы/компоненты** (перенесены в `web/src/`): `ReportCards.jsx`, `layout.jsx` — **редактор главной страницы** (bento: порядок/ширина/скрытие карточек, drag&drop, wiggle-режим), `DayStrip`, `Focus`, `Widgets` (тепловая карта, прогноз кассы, дни рождения, импорт выписки), `ScreenTime`, `Graph`, `TaskSheet`, `Palette` (⌘K), `Aims`.
- Мобильная версия, PWA-манифест, свайпы, Toaster, инлайн-редактирование.
- Документация редизайна: `docs/redesign-map.md`, `docs/redesign-checklist.md` (все пункты выполнены), `docs/redesign-progress.md` (6 этапов, все завершены).

### 3.2 Новые API и фичи ядра
- `GET /api/finance/forecast` — график «кассы» (прошлое по операциям, будущее по регуляркам и среднему темпу, runway) — `core/api/app.py`.
- `finance.summary()` отдаёт `balance/avg_daily/runway_days/weekday/month_days` — алгоритмы для главной (Today.jsx) — `core/services/finance.py`.
- **Каскад галочек:** встречу можно привязать к задаче/заказу (`event.task_id`, `event.order_id`, миграция в `db.py`), одна галочка закрывает задачу и меняет статус заказа; отрицательные id — проекции задач/дедлайнов заказов (`/api/events/{id}/done`).
- **Судья раньше правил** — фикс приоритета: спорные фразы («отдал Ване») сначала идут в судью, затем в правила (`core/brain/agent.py`).
- `reload_cloud_settings()` перечитывает OLLAMA_MODEL/OLLAMA_URL/VISION_MODEL без перезапуска + авто-выбор vision-модели; ключ LLM больше не светится последними 4 знаками в логах (`core/brain/llm.py`).
- Улучшенные сообщения об ошибках финансов («неправдоподобно мнение. Разбейте на части»).

### 3.3 Мастер первого запуска
- `core/setup_wizard.py` (345 строк): детект железа (RAM/GPU/Ollama), рекомендация модели по VRAM, проверка Telegram-токена и владельца, проверка облачного ключа живым запросом, скачивание моделей Ollama с прогрессом.
- `core/api/setup.html` — страница-мастер (5 шагов: имя → железо/модель → облако → Telegram → готово), редирект на `/setup`, пока мастер не пройден (`setup_done()` в `core/config.py`).
- ⚠️ В исходнике Marvin **обработчики `/api/setup/*` отсутствуют** (есть только страница и логика) — при объединении мастер помечен пройденным (`setup.done: true`), чтобы не блокировать уже настроенный Marvin. Подробности в `REPORT.md`.

### 3.4 Имя ассистента из конфига — `core/identity.py`
Одно место для имени: обращение в промпте, wake word для голоса (fuzzy-regex для Vosk), подпись на карточках, варианты имени через запятую. Задаётся `assistant.name` в `config.yaml` / в настройках сайта.

### 3.5 Загрузка `.env` — `core/config.py`
`_load_env_file()` читает `.env` в переменные окружения (не перезаписывает уже заданные), приоритет: env ОС > `.env` > `config.yaml`. Новые переменные: `ASSISTANT_TG_TOKEN`, `ASSISTANT_TG_OWNER`, `OLLAMA_URL`, `ASSISTANT_DOCKER`, `ASSISTANT_NO_VOICE_WARMUP`. Есть `.env.example`.

### 3.6 Node-стенд (параллельный бэкенд без Python)
- `server.ts` (~150 REST-роутов, Express) + `desktop.mjs` (окно браузера), `npm run dev` → сайт на :3000, состояние в `data/server-state.json` (in-memory демо-данные, **не** ваша база).
- Чат в нём ходит в настоящую модель по ключу из `.env` (`LLM_API_KEY`/`LLM_URL`/`LLM_MODEL`), проверка `GET /api/llm`.
- Переключатель изданий «личное / для GitHub» (`/api/edition`; технические значения остаются `jarvis` и `marvin`), экспорт данных (CSV, BOM; `/api/export/all.json`).
- Тесты контракта фронта: `tests/server_api.test.mjs` (17 тестов, `npm test`).

### 3.7 Прочее из Marvin
`.dockerignore`, Docker-сборка с `OLLAMA_URL`, ISSUE_TEMPLATE, `publish.bat` (публикация релиза — **локально не используется**), `RELEASE-*.md`, `tools/release_notes.py`, `install_voice.bat`, `docs/audit.md` (инженерный аудит: безопасность API, валидация аргументов LLM, SSRF, CSRF), `docs/for-family.md`, `docs/second-assistant.md`, `docs/small-model.md`, расширенные `docs/development.md`, `.github/workflows`.

## 5. Что выбрано при объединении (кратко; подробности — в `REPORT.md`)

- Код ядра: **взята версия Marvin** (новее по функциям), поверх неё сохранены личные особенности (имя «Марвин» в `assistant.name`, метка второй копии, `persona.display_name`, правило озвучки имени латиницей в логах).
- БД: **остаётся `data/jarvis.db`** (ваши данные), путь захардкожен обратно в `core/config.py`.
- Интерфейс: **`web/` из Marvin** (новый дизайн, собирается в `web/site` и раздаётся Python-ядром).
- Node-стенд Marvin сохранён как отдельная опция (не участвует в обычном запуске).
