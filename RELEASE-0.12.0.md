# Marvin 0.12.0

- **Органайзер монтажных папок**: структурирование папок видеомонтажа и графики по категориям с профилями (видео, графика, SFX), безопасным перемещением, предпросмотром плана и откатом.
- **Учёт времени по проектам**: автоматическое распознавание активных проектов Premiere Pro / After Effects / DaVinci с переносом времени в заказы и ручной ввод времени.
- **Восстановление базы из бэкапов**: управление копиями `data/assistant.db` прямо из настроек со страховочными снимками `backup-pre-restore-*.db`.
- **Автономное окно приложения**: запуск через `jarvis_app.py` / `start_app.bat` на PySide6/webview.
- **Стабильность**: все 335 тестов пройдены, полная поддержка чистого запуска и безопасной работы.
