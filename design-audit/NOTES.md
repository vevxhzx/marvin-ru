# Дизайн-аудит по скринам (для прохода Sonnet в самом конце)

> ДИРЕКТИВА ХОЗЯИНА (12.10.2026): не редизайн, а шлифовка. По скринам искать ошибки;
> анимации; карточки должны нормально отрисовываться в любых состояниях + удобная их настройка;
> шрифты/заголовки чётко, без съездов и наложений; отступы везде крутые. Координально не менять —
> текущий стиль нравится. Референс вайба: глянцевые стеклянные карточки, коралловые акценты (см.Today-мокап от хозяина).

Папка: `design-audit/shots/{pc,mob}/` — 10 экранов × 2 вьюпорта (1440×900 → ужато до 1280, 375×812),
тёмная тема, демо-данные e2e-стенда. `-down` — второй кадр проскролленных длинных экранов.
Спектакль: `tests/e2e/specs/design-shots.spec.js` (переснять: `npx playwright test ../tests/e2e/specs/design-shots.spec.js --project=desktop --project=mobile` из `web/`).

Правила для исполнителя: менять только оформление (CSS/JXS-классы, токены), логику и API не трогать;
e2e-селекторы (`role=tab`, `.row`, pill, `.label`, `data-testid`) и i18n-ключи не ломать (ключи только добавлять ru+en);
сборка `npm run build` + `i18n.test.mjs`/`i18n_check.mjs` после каждого шага.
Общее на все экраны: нижний док перекрывает последнюю карточку/строку — добавить `padding-bottom` под док на уровне `.pg` (web/src/index.css), а не на каждой странице.

- ИТОГО ≈ $0.70 из $2.50 — запас тройной. Кэш (повторные картинки в следующих запросах той же сессии) ещё удешевит.
