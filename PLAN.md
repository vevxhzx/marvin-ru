# J.A.R.V.I.S. — план проекта

> Личный ассистент: голос на ПК (Windows) + Telegram + одна база + сайт в стиле Apple.
> Дата старта: 06.09.2026. Пользователь почти не программирует → всё «под ключ», запуск одной кнопкой.

---

## 0. Решения, принятые по итогам вопросов

| Вопрос | Решение | Почему |
|---|---|---|
| Железо | Xeon E5-2670v3, GTX 1660 Super 6 ГБ, 32 ГБ RAM, Windows | Хватает на локальную LLM 7B + Whisper |
| «Мозг» | **Гибрид.** По умолчанию — локальная `Qwen2.5-7B-Instruct` через Ollama. Gemini — только для «общих» вопросов (объясни, напиши, посчитай), **без личных данных** | Заметки/финансы/календарь никогда не покидают ПК |
| Приватность к Gemini | Фильтр-анонимайзер: в облако не уходят имена, суммы, содержимое базы. Можно выключить Gemini совсем одной строкой в настройках | «нужна хоть какая-то анонимность» |
| Где живёт | **Этап 1 — всё на ПК.** Архитектура сразу разделена на *Ядро* (база+API+TG+сайт) и *Голосовой клиент* (микрофон, TTS, файлы). Ядро при желании переезжает на дешёвый VPS в РФ (~300 ₽/мес) без переделки | Комп почти всегда включён; переезд — не трагедия |
| Доступ с телефона | Tailscale (бесплатно, приватная сеть, ничего не торчит в интернет) | Сайт открывается с телефона без публичного адреса |
| «Не трагедия перезапустить» | Автозапуск при старте Windows + автобэкап базы каждый день (в папку + опционально в облако/на флешку) | |
| Календарь | Сначала свой (в базе + напоминания в TG). Google Calendar — отдельный этап 5 | |
| Финансы | Счета: **Т-Банк (основной)** + 2 банка только с обязательствами (долги/кредиты). Рубли. Ввод — голос / TG / сайт. Импорт выписок — опционально, для сверки | |
| Файлы и ПК | Полный доступ на чтение/поиск/открыть/переместить/переименовать. **Удаление запрещено**: «удали старые видео» → собирает в папку `_Jarvis_на_удаление`, финальное решение за тобой. Открыть браузер/программу, громкость, таймер выключения — можно | |
| Заметки/ссылки | Кинул ссылку → карточка с обложкой, заголовком, авто-тегами (локальная LLM). Мысли — текстом/голосом, с поиском по смыслу | |
| Telegram | Токен есть. Бот отвечает **только твоему Telegram ID** | |
| Голос (TTS) | Silero v4 (русский, офлайн, голос `aidar`/`eugene` — низкий, «дворецкий»). Запасной — Edge TTS `Dmitry` при интернете | Быстро, бесплатно, без аккаунтов |
| Слух (STT) | `faster-whisper` (модель `small`/`medium`, GPU) | Русский распознаёт отлично |
| Wake word | Vosk (маленькая русская модель, офлайн, ловит слово «Джарвис» на CPU). Альтернатива — Picovoice Porcupine (у них есть встроенный «Jarvis») | Без регистраций |
| Характер | Максимальный свэг, шутит где уместно, обращение «сэр», коротко и по делу когда речь о задачах | |

## 1. Архитектура

```
┌─────────────────────────────  ТВОЙ ПК (Windows)  ─────────────────────────────┐
│                                                                                │
│   ┌──────────── ГОЛОСОВОЙ КЛИЕНТ (jarvis-voice) ─────────────┐                 │
│   │  микрофон → Vosk «Джарвис?» → faster-whisper (речь→текст) │                 │
│   │  → отправка в Ядро → ответ → Silero TTS (голос)           │                 │
│   │  + локальные действия: файлы, браузер, программы, громкость│                 │
│   └──────────────────────────┬────────────────────────────────┘                 │
│                              │ HTTP (localhost)                                 │
│   ┌──────────────────────────▼────────────── ЯДРО (jarvis-core) ──────────────┐ │
│   │  FastAPI                                                                   │ │
│   │   ├─ Мозг: роутер → Ollama (Qwen2.5-7B, локально) | Gemini (обезличено)    │ │
│   │   ├─ Инструменты (tools): календарь, задачи, финансы, заметки, ссылки, файлы│ │
│   │   ├─ Telegram-бот (aiogram) — текст, голосовые (тоже через Whisper)        │ │
│   │   ├─ Планировщик: напоминания, регулярные платежи, бэкапы                   │ │
│   │   └─ Сайт (React, Apple-style) — раздаётся тем же процессом                 │ │
│   │  База: SQLite (один файл jarvis.db) — просто бэкапить/переносить            │ │
│   └────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                │
└──────────────┬─────────────────────────────────────────────────┬───────────────┘
               │ Tailscale (приватно)                             │ Telegram API
        📱 сайт с телефона                                  📱 TG-бот
```

Позже Ядро можно перенести на VPS целиком (одна команда `docker compose up`), голосовой клиент останется на ПК и будет ходить к Ядру по Tailscale.

## 2. Стек

- **Python 3.11** — ядро, бот, голос
- **FastAPI + SQLite (SQLModel)** — API и база
- **aiogram 3** — Telegram
- **APScheduler** — напоминания / регулярные траты / бэкапы
- **Ollama + Qwen2.5-7B-Instruct (Q4_K_M, ~4.7 ГБ VRAM)** — локальный мозг с вызовом инструментов
- **google-generativeai** — Gemini для общих вопросов (через анонимайзер)
- **faster-whisper** — распознавание речи
- **Vosk** — wake word «Джарвис»
- **Silero TTS v4 / edge-tts** — голос
- **React + Vite + Tailwind** — сайт (собранный, статика; тёмная/светлая тема, SF-подобная типографика, карточки, плавные анимации)
- **Tailscale** — доступ с телефона

## 3. Модель данных (одна база)

- `events` — встречи/события (заголовок, дата-время, длительность, место, напоминание, источник: voice/tg/web, google_id для будущей синхронизации)
- `tasks` — задачи (статус, приоритет, дедлайн, проект)
- `accounts` — счета (Т-Банк основной, наличные, + банки с обязательствами)
- `transactions` — операции (сумма, категория, счёт, дата, комментарий, источник; хэш для дедупликации при импорте выписок)
- `categories` — категории трат/доходов
- `recurring` — регулярные платежи (подписки, аренда, кредитные платежи) с датой следующего списания
- `debts` — долги/кредиты: сумма, ставка, платёж, дата платежа → расчёт «закроется через N месяцев», график
- `notes` — мысли (текст, теги, embedding для поиска по смыслу)
- `links` — ссылки (url, заголовок, обложка, домен, теги, комментарий)
- `files_index` — индекс выбранных папок (путь, тип, размер, дата, краткое содержание для документов)
- `memory` — «second brain»: журнал всех действий и диалогов (что, когда, через какой канал)
- `settings` — настройки (персона, ключи, папки для индексации)

## 4. Этапы (в порядке сборки)

### Этап 0 — Подготовка (30–40 мин, по инструкции)
- Установить Python 3.11, Ollama, Git, Tailscale
- `ollama pull qwen2.5:7b`
- Заполнить `config.yaml`: TG-токен, твой TG ID, ключ Gemini (опционально), папки для файлов
- Запуск `start.bat` → всё поднимается, бот пишет «Система онлайн, сэр»

### Этап 1 — Ядро + Telegram (текст) ✅ ГОТОВО
- База, API, планировщик, персона
- В TG текстом: «встреча в среду в 15:00 с Ваней» → событие в базе + подтверждение + напоминание
- «потратил 700 на такси» / «должен Сберу 120к, плачу 8к 25-го» / «запиши мысль…» / ссылка
- Утренний дайджест в TG: планы на день, платежи, задачи

### Этап 2 — Сайт (Apple-style) ✅ ГОТОВО
- **Сегодня**: события, задачи, баланс, ближайшие платежи
- **Финансы**: общий счёт, траты по категориям, регулярные, долги с прогресс-баром и датой закрытия
- **Календарь**: месяц/неделя/день
- **Задачи**
- **Мозг**: заметки и ссылки (карточки с обложками, теги, поиск по смыслу)
- **Память**: лента «что было» (second brain)
- Чат с Джарвисом прямо на сайте

### Этап 3а — Голосовые в Telegram ✅ ГОТОВО
- Whisper (faster-whisper small, CPU, локально) → agent.handle → ответ текстом + голосом (Silero v4 eugene / Edge TTS запасной)
- `/voice` переключает режим ответа, настройки в `voice.*`

### Этап 3 — Голос на ПК ✅ ГОТОВО (voice_client.py / voice.bat)
- Wake word «Джарвис» (Vosk small-ru) → запись до паузы → Whisper → ядро /api/chat (channel=voice) → Silero в наушники
- Иконка в трее (серый/синий/жёлтый/зелёный/красный), горячая клавиша Ctrl+Shift+J, follow-up 6 с после вопроса

### Этап 4 — Файлы и управление ПК ✅ ГОТОВО (v0.7.0: core/services/pc.py + core/pc/*, через voice.bat)
- Открыть сайт/программу/папку (ярлыки «Пуска»), поиск файлов по имени (Everything, если есть), медиа-клавиши, блокировка/выключение
- Скриншот → модель зрения (локальная qwen2.5vl / Groq), буфер обмена → Мозг, «статус костюма» (psutil + nvidia-smi)
- Прерывание «стоп», заглушки «Секунду…», диктовка «запиши мысль», ночной режим, утренний доклад при пробуждении ПК, авто-игровой режим по процессам
- Осталось на потом: переместить/переименовать/«собрать на удаление», поиск по содержимому файлов

### Этап 5 — Расширения
- ✅ Импорт выписок Т-Банка (CSV/PDF/Excel) с дедупликацией — TG-файл или кнопка на сайте
- ✅ Голосовые сообщения в TG · ✅ фото чека → трата (локальное зрение)
- ✅ Аналитика: прогноз кассы, подписки, лимиты, стрик/тепловая карта, дни рождения, недельный дайджест, PNG-открытки
- ✅ Сайт: ⌘K-палитра, индикатор состояния + микрофон, перетаскиваемые блоки; TG: инлайн-кнопки на напоминаниях
- ✅ Google Calendar — push-only Джарвис → Google (v0.8.0: core/services/gcal.py, OAuth Desktop, очередь при офлайне, RRULE для повторов)
- ✅ Аудит v0.8.0: ~40 бытовых фраз без LLM (core/brain/quick.py), нечёткий поиск по падежам (core/services/match.py), даты в прошлом, «к» из «кофе»
