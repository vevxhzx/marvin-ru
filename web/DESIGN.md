# Дизайн-система сайта

Один источник правды — `src/index.css`. Всё остальное собирается из этих классов и токенов; новые «локальные» стили в компонентах не заводим. React-примитивы живут в `src/components/ui.jsx`, страница — только раскладка и текст через `t()`.

## Принципы
- Ассистент — центр. На главной сверху: контекст дня и композер; ниже — задачи и события; деньги свёрнуты.
- **Четыре ступени поверхности.** `--bg` (страница) → `--sf` (карточка) → `--sf2` (вложенное) → `--fill/--fill-2` (плашки, зоны). Тёмная тема: `#0f1530 / #151c3d / #1c2550`; светлая: `#e9ecf3 / #ffffff / #f0f1f6`. Ступени те же самые токены в обеих темах.
- **Один лаймовый герой на экран** (`.hero`) — только деньги/успех. Второго героя на странице не бывает.
- **Цвет только по смыслу.** Лайм = деньги/ок, янтарь = ожидание, красный = просрочка/риск, фиолетовый = ИИ. Всё остальное — нейтральные поверхности. Смысловые карточки — `.tint-ok/.tint-warn/.tint-neg/.tint-ai/.tint-acc` (тинт 11 % + рамка 1px).
- Плоские поверхности, тонкие линии, тени только для приподнятых слоёв.
- Действия ассистента показываются карточкой результата (`.act-card`), а не техническим логом.
- Каждая пустота объясняет, что делать (`Empty` + подсказка-кнопка → чат). Пустой виджет компактный, а не «полупустой на пол-экрана».
- **Подписи читаемы.** `--ink-3` подобран под WCAG AA (светлая тема `#666b76` — 5.3:1 на `#e9ecf3`, тёмная `#9aa0ab` — 5.6:1 на `#1c2550`). Мелкий текст — не меньше 12px (`--fs-xs` и правило для `text-[9…11px]`).

## Заголовок экрана
Один и тот же на всех страницах: `.top` (заголовок `h1` + `.sub`) и `.hr.head-actions` (действия справа). На телефоне `.head-actions` становится сеткой в две колонки: главная кнопка `.head-primary` занимает ширину, ничего не сжимается и не уезжает. `PageHead` (ui.jsx) — та же разметка для экранов без бенто (`Заказы`, `Память`, `Доска`).

## Мобильный режим — как настоящее приложение
- **Нижняя навигация (≤820px): ровно 5 вкладок** — 4 раздела из настроек (`prefs.tabbar`, по умолчанию Сегодня · Задачи · Финансы · Мозг) + «Ещё». Активная вкладка — плашка акцентом, фон с размытием, `env(safe-area-inset-*)` снизу и по бокам. «Ещё» открывает шторку со всеми остальными разделами и действиями (чат, тема, справка).
- **Сайдбар** остаётся на десктопе (232px, sticky) и полностью скрывается на телефоне.
- **Шапка телефона** (`.gt`) — липкая, с полупрозрачным фоном и размытием, с `safe-area-inset-top`; действия не переполняют строку.
- **Шторки** на телефоне выезжают снизу как bottom sheet: «ручка» `.sheet-grip`, свайп за ручку вниз закрывает, есть кнопка ✕ и `Esc`, `overscroll-behavior: contain`, скролл только внутри. На десктопе — по центру.
- **Зоны нажатия** на тач-экранах: кнопки, иконки, пилюли, сегменты, чекбоксы, строки списка — не меньше `--tap` (44px); заметки 44–48px. На тач-экранах вместо `:hover` работает `:active` с короткой анимацией; hover-эффекты там отключены (`@media (hover: none)`).
- **Поля** — `font-size: 16px` на тач-экранах (иначе iOS зумит страницу), `min-height: 44px`; у денежных полей `inputMode="decimal"`, у телефонных — `type="tel"`.
- **Высота** — `100dvh` (`min-height` на `html`/`body`/`#root`/`.app`), а не `100vh`: адресная строка не срезает низ.
- **Широкие строки** на телефоне складываются (`.wide-row`), канбан листается по колонкам с снапом (`.kanban-scroll`) — горизонтальной прокрутки «всей страницы» нет.
- **PWA**: `viewport-fit=cover`, `<html data-pwa="standalone|browser">` (ставит `App`), отступы и safe-area в оболочке.

## Главная — настраивается
«настроить главную» внизу страницы: блоки вкл/выкл и порядок (стрелки или перетаскивание мышью), приветствие/строка контекста/быстрые слова, плотность «спокойно/подробно». Хранится в `localStorage` (`today.prefs.v1`, `today.order.v2`). По умолчанию показаны только задачи, календарь и свёрнутые деньги.

## Клавиатура
`⌘K` палитра · `⌘J` чат · `Esc` закрыть · `Enter` отправить, `Shift+Enter` новая строка · `Alt+1…9` разделы · в календаре `←/→` день, `T` сегодня · в палитре `↑↓ / Tab / Ctrl+J/K`. Подписи — через `kb()/kbAlt()/kbShiftEnter`, символ ⌘ не хардкодится.

## События между частями интерфейса
- `assistant:chat` `{text, send?}` — открыть чат с текстом (send — отправить сразу).
- `assistant:busy` `true|false` — ассистент думает (статус в сайдбаре).
- `assistant:event` — событие SSE от ядра (reminder, chat, recurring, pc_state…).

## Настройки вида (`src/lib/prefs.js`)
Один стор для всего, что пользователь может подкрутить: применяется CSS-переменными на `<html>` (`apply()`), поэтому работает без перезагрузки и без бэкаенда. Ключи: `accent`, `tint`, `font` (`--ui-zoom`), `radius` (`--r-k`), `motion` (класс `.no-motion`), `hiddenNav`, `tabbar` (4 раздела нижней панели), `compactNav`, `address`, `showGreeting/showContext/showQuick`, `density`, `hiddenBlocks` + порядок (`useOrder`), `tasksSort`, `pageAccents`. Кнопка «сбросить вид» → `prefs.reset()`.

## Платформа и клавиши
Подписи горячих клавиш берутся из `kb()/kbAlt()/kbShiftEnter` (`src/lib/api.js`): на macOS ⌘/⌥/⇧, на Windows и Linux — `Ctrl+`/`Alt+`/`Shift+`. Обработчики слушают `metaKey || ctrlKey`; менять нужно только подписи.

## Приоритет задач
`PriorityDot` (`ui.jsx`) — точка + всплывающее меню через портал в `body` (строки лежат внутри `.swipe` с `overflow:hidden`, обычный absolute-попап там обрезался). Сортировка внутри групп задач — `prefs.tasksSort` (`priority | due | new`), переключатель над списком.

## Тексты и i18n
Интерфейс переведён RU/EN через `src/lib/i18n.js` (`t('ключ')`, `useI18n()`, словарь ~2050 ключей, язык по умолчанию — русский). **Новая видимая строка — только через `t()`**: ключ добавляется в словарь сразу в двух формах (`ru` + `en`) и проверяется:
- `node web/src/lib/i18n.test.mjs` — словарь заполнен, плейсхолдеры `{…}` совпадают в ru/en, плюрализация корректна;
- `node web/src/lib/i18n_check.mjs` — 0 висящих русских строк. Сканер понимает JSX-текст, строковые литералы и тела шаблонных литералов; «сырые» данные помечаются комментарием `i18n-raw` (фразы, которые уходят в ядро, HTML-файл для печати, ключи из лога).

## Доступность
- Один фокус на всё приложение: `:focus-visible { outline: var(--focus-ring) solid var(--accent) }`.
- У каждой кнопки есть подпись, `aria-label` **и** тултип/title (проверяется e2e).
- Кликабельные `<span onClick>` заменены на `<button type="button">` (табы-сегменты, кнопки-подписи, переключатели).
- Шторка: `role="dialog"`, `aria-modal`, ловушка фокуса, `Esc` закрывает, фокус возвращается на вызвавший элемент.
- Текст не обрезается молча: `.trunc`, `.clamp-2/3`, `title` на длинных подписях; длинные пояснения — в тултип или подпись (`Section tip/hint`), а не простыня в карточке.
- `prefers-reduced-motion` и настройка «меньше движения» (`.no-motion`) гасят анимации и переходы.

## Reference page pass · 2026
Визуальная цель — приложение, а не свёрстанный сайт:
- светлая `#e9ecf3` / тёмная `#0f1530`, карточки `#151c3d` / `#1c2550`, рамка 1px, тонкие тени;
- 232px тёмно-синий сайдбар, радиус 30px, внешний отступ 16px; активный пункт — цветом акцента;
- 12-колоночная сетка `.bento` с шагом `--bento-gap` (на телефоне одна колонка, шаг `--bento-gap-m`);
- hero — лаймовый градиент `--lime`; акцент — `--accent`;
- Inter Tight-подобная типографическая иерархия и табличные цифры для чисел (`.num`, `.num-r`);
- easing `cubic-bezier(.16,1,.3,1)`; пустые состояния — через `Empty`, виджет без данных компактен.

Routes and components use the same primitives from `src/index.css` and `components/ui.jsx`; page logic, API calls, hooks, storage and tests remain separate from the visual layer.
