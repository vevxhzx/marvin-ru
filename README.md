# J.A.R.V.I.S. — личный ассистент на своём ПК

**Деньги, календарь, задачи и «второй мозг» — обычной речью.** Пишешь в Telegram, на сайте или говоришь «Джарвис, …» в микрофон; всё ложится в одну базу на твоём диске, он напоминает, считает, отвечает — с характером Джарвиса из «Железного человека».

Для одного человека, без аккаунтов и подписок: один процесс на Windows, база — обычный файл, личное не покидает компьютер.

## Шесть главных вещей

| | Пример | Что происходит |
|---|---|---|
| 💸 **Деньги** | `700 такси` · `зп 150 тыс` · `долг Сберу 120к плачу 8к 25-го` · `хватит ли до зарплаты` | категории сами, Т-Банк как основной счёт, касса на 30 дней, долги с прогнозом, выписка Т-Банка файлом, фото чека → трата |
| 📅 **Календарь и задачи** | `встреча в среду в 15 с Димой` · `напомни через 20 минут достать стирку` · `сдать отчёт до пятницы` | напоминания в Telegram и вслух, повторы («каждый пн ср пт»), перенос словами, push в Google Календарь |
| 💼 **Заказы (фриланс)** | `заказ: ролик для Пятёрочки, 25к, до пятницы` · `пришёл аванс 10к за ролик` · `таймер на ролик` · `цель: подушка 300к к марту` | дедлайн в календаре, ожидаемая оплата в прогнозе кассы, помодоро на сайте/в Telegram/голосом → ставка в час, конверты-цели, 50/30/20, «на сколько хватит» |
| 🧠 **Второй мозг** | `мозг: идея для ролика…` · `запомни …` · ссылка · фото с подписью | заголовок, обложка, теги, выжимка, смысловой поиск («та статья про сон») |
| 🎙 **Голос и ПК** | «Джарвис, открой ютуб» · «найди файл договор» · «что на экране» · «разбери рабочий стол» · «статус костюма» | wake word офлайн, Whisper, Silero; медиа-клавиши, игровой режим сам; файлы **никогда не удаляются** |
| 🔒 **Приватность** | режимы `local` / `hybrid` / `cloud` | личное — на твоей видеокарте; в облако (Groq) только общие вопросы, обезличенно; каждый ответ помечен ⚡ правило · 🧠 локально · ☁️ облако |

Около 40 бытовых фраз работают **без нейросети** — мгновенно, офлайн, даже во время игры. Плюс утренний доклад, вечерний «что с задачами?», недельный отчёт-открытка, откат любого действия («отмена»), ночные бэкапы. [Все команды →](docs/features.md)

## Быстрый старт (Windows, 10–15 минут)

1. [Python 3.12](https://www.python.org/downloads/windows/) → при установке галочка **«Add python.exe to PATH»**.
2. Папку `jarvis` — например, в `C:\Jarvis`. Двойной клик **`install.bat`** — поставит библиотеки и откроет `config.yaml`.
3. В `config.yaml` две строки: `token` (от @BotFather) и `owner_id` (свой ID от @userinfobot). Сохранить.
4. **`start.bat`** — в Telegram придёт «Система онлайн, сэр». Сайт: http://localhost:8765.

Дальше по желанию, всё кнопками: локальный мозг — [Ollama](https://ollama.com/download) + `ollama pull qwen3.5:4b`; облако для общих вопросов — ключ Groq в ⚙ Настройки → облако; голос — `voice.bat`; с телефона — `phone.bat` + QR в настройках, а прямо внутри Telegram без VPN — `funnel.bat` ([инструкция](docs/telegram-miniapp.md)); автозагрузка — `autostart.bat`.

Пошагово, со всеми вариантами — [docs/install.md](docs/install.md).

## Железо и границы приватности

| Режим | Что нужно | Куда уходят данные |
|---|---|---|
| 🔒 **local** | видеокарта от 4–6 ГБ + Ollama | никуда, работает без интернета |
| ⚖️ **hybrid** *(текущий)* | то же + бесплатный ключ Groq | деньги, календарь, задачи, заметки, файлы — **локально**; разговор и общие вопросы — в облако с вырезанными именами/суммами/телефонами |
| ☁️ **cloud** | любой ноутбук | всё у провайдера, включая заметки и траты |

Твоя GTX 1660 Super (6 ГБ) — `qwen3.5:4b`; таблица под другие карты — [docs/brain.md](docs/brain.md). Фото из Telegram (в том числе чеки) сейчас разбираются в облаке Groq — это твой осознанный выбор, переключается в `brain.vision.where`.

В любом режиме:

- бот отвечает **только** твоему Telegram ID;
- база — файл `data/jarvis.db`; бэкап = копия файла (ночью сам, 30 дней, вторая копия на другой диск по желанию);
- с других устройств API открыт только по ключу доступа из QR;
- Джарвис **никогда не удаляет** файлы на ПК; суммы от 100 000 ₽ и выключение компьютера — только после «да»;
- экранное время (сколько и где сидишь за ПК) — **выключено по умолчанию**; включается в настройках → голос и ПК, пишет только имя программы и сайт, хранит 90 дней в твоей базе, в облако — никогда;
- Google Календарь — только в одну сторону (Джарвис → Google), обратно ничего не читается.

> Бесплатные лимиты Groq (~1000 запросов/день) и набор его моделей — по состоянию на 10.09.2026, провайдер меняет их без предупреждения. Если облако «посыпалось» — [docs/troubleshooting.md](docs/troubleshooting.md), это чинится за минуту.
