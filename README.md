# Личный ассистент — Telegram + сайт + голос, на вашем компьютере

Один процесс на Windows (или Docker), который ведёт **деньги, календарь, задачи и «второй мозг»** — и понимает обычную речь:

> «потратил 700 на такси» · «встреча в среду в 15 с Димой» · «надо купить молоко» · «долг банку 120к плачу 8к 25-го» · «что сегодня» · «мозг: идея для ролика»

Пишете в **Telegram**, на **сайте** (телефон/ПК, ставится как приложение) или говорите **голосом в микрофон ПК** — всё падает в одну базу на вашем диске.
Имя ассистенту даёте вы сами — оно и в чате, и как слово-активация для голоса.

**Программировать не нужно.** Установка — два клика, дальше мастер в браузере: имя → мозг под ваше железо → Telegram.

## Что умеет

| Область | Примеры фраз | Что происходит |
|---|---|---|
| 💸 Деньги | `700 такси`, `зп 120 тыс`, `перевёл 5000 на наличные`, `сколько потратил на еду за неделю`, `куда ушли деньги` | Категории сами, балансы, лимиты, графики cashflow |
| 📉 Долги и подписки | `долг банку 120к плачу 8к 25-го`, `подписка яндекс 399 25-го`, `закрой долг Диме` | Автоплатежи в срок, прогноз «закроется через N мес.» |
| 📅 Календарь | `встреча завтра в 15 с Димой`, `напомни через 20 минут достать стирку`, `перенеси встречу на пятницу` | Напоминания в Telegram (и голосом), повторы, push в Google Календарь |
| ✅ Задачи | `надо сдать отчёт через 3 дня`, `сделал молоко` | Дедлайны, повторные напоминания, свайпы на телефоне |
| 🧠 Второй мозг | `мозг: …`, `запомни …`, любая ссылка, фото с подписью | Заголовок, обложка, авто-теги, смысловой поиск |
| 🧾 Чеки | фото чека в Telegram | Сумма и категория распознаются, трата записывается |
| 🖥 Компьютер | `открой браузер`, `найди файл договор`, `что на экране` | Открывает, ищет, показывает. **Никогда ничего не удаляет** |
| 🎙 Голос | «Марвин, …» в микрофон ПК; голосовые в Telegram | Wake word офлайн (Vosk), распознавание Whisper, озвучка Silero/Edge |
| ↩️ Откат | `отмени последнюю`, `сотри финансы за 2 дня` | Любое действие откатывается; массовые — с подтверждением |

Плюс: утренний дайджест, недельный отчёт, ночные бэкапы базы, экспорт в JSON/CSV, импорт банковских выписок, тёмная тема, ⌘K-палитра.

## Установка на Windows (10 минут)

**1. Python.** Скачайте [Python 3.12](https://www.python.org/downloads/release/python-3120/) → при установке поставьте галочку **«Add python.exe to PATH»**.

**2. Проект.** Скачайте архив (кнопка **Code → Download ZIP** или [Releases](../../releases)), распакуйте, например, в `C:\Assistant`.

**3. `install.bat`** — двойной клик. Создаст окружение и поставит библиотеки (2–5 минут).

**4. `start.bat`** — двойной клик. Откроется браузер с **мастером настройки**:

- **Имя** — как звать ассистента и как ему обращаться к вам.
- **Мозг** — мастер сам определит видеокарту и предложит один из трёх режимов (см. ниже) и модель. Если выбрали локальную — кнопка «скачать модель» прямо в мастере.
- **Облако** — ключ провайдера (бесплатный, карта не нужна) с проверкой в один клик.
- **Telegram** — токен от [@BotFather](https://t.me/BotFather), затем «напишите боту» — ваш ID подставится сам.

После «готово» ассистент перезапустится и напишет вам в Telegram. Окно `start.bat` держите открытым (или добавьте в автозагрузку: `autostart.bat`).

> Все настройки потом меняются на сайте: ⚙ **Настройки**. Файл `config.yaml` править руками не нужно.

**С телефона:** `phone.bat` покажет адрес сайта в домашней сети; для доступа откуда угодно — [Tailscale](https://tailscale.com) (бесплатно). На телефоне «Добавить на экран Домой» — будет как приложение.

## Три режима мозга — выбираете в мастере

| Режим | Где думает | Кому подходит |
|---|---|---|
| 🔒 **local** — только Ollama | Всё на вашем ПК. В интернет не уходит ничего. | Видеокарта от 4–6 ГБ. Максимальная приватность |
| ⚖️ **hybrid** — Ollama + облако *(рекомендуем)* | Личное (деньги, календарь, заметки, файлы) — **локально**. Общие вопросы и разговор — в облако, **обезличенно** (имена, суммы, телефоны вырезаются) | Видеокарта есть, хочется и быстро, и умно |
| ☁️ **cloud** — только облако | Всё у провайдера API | Видеокарты нет / слабый ноутбук. Помните: заметки и траты будут обрабатываться на чужих серверах |

Каждый ответ помечен источником: ⚡ правило (без нейросети, мгновенно) · 🧠 локально · ☁️ облако. Около 40 бытовых команд (траты, задачи, встречи, «что сегодня») работают **вообще без модели**.

### Какая модель под какую видеокарту

Мастер выберет сам, но если интересно (все модели — [Ollama](https://ollama.com/download), скачиваются один раз):

| Видеопамять | Модель | Размер | Видит фото | Комментарий |
|---|---|---|---|---|
| 18 ГБ+ | `qwen3.5:27b` | 17 ГБ | да | максимум качества для домашней карты (RTX 3090/4090) |
| 10 ГБ+ | `gemma4:12b` | 8.1 ГБ | да | очень хорошо по-русски, видит картинки |
| 7.5 ГБ+ | `qwen3.5:9b` | 6.0 ГБ | да | золотая середина для 8 ГБ (RTX 3060/4060) |
| 4.5 ГБ+ | `qwen3.5:4b` | 2.8 ГБ | да | быстрая, видит картинки, тянет 6 ГБ (GTX 1660, RTX 2060) |
| 4.5 ГБ+ | `gemma4:e4b` | 3.2 ГБ | да | альтернатива для 6 ГБ, чуть лучше в разговоре |
| 2.5 ГБ+ | `qwen3.5:2b` | 1.6 ГБ | да | для 4 ГБ видеопамяти или процессора с 16 ГБ ОЗУ |
| 1 ГБ+ | `qwen3.5:0.8b` | 0.7 ГБ | нет | совсем слабое железо; понимает команды, разговор так себе |

Нет дискретной видеокарты, но 16+ ГБ ОЗУ — `qwen3.5:2b` пойдёт на процессоре (10–30 с на ответ), общие вопросы лучше отдать облаку (hybrid). Mac с Apple Silicon — вся память общая, смотрите на объём ОЗУ.
Смысловой поиск по заметкам: `nomic-embed-text` (270 МБ), мастер подтянет её сам.

## Docker (Linux / Mac / VPS)

Скачайте архив (кнопка **Code → Download ZIP** на этой странице) и распакуйте. В терминале, в папке проекта:

```bash
cp config.example.yaml config.yaml
docker compose up -d
```

Откройте `http://localhost:8765` — появится тот же мастер. Ollama поднимается вторым контейнером (`OLLAMA_URL=http://ollama:11434` уже прописан); для NVIDIA раскомментируйте блок `deploy` в `docker-compose.yml`. Без видеокарты выбирайте режим **cloud** и можете убрать сервис `ollama`.

База и картинки — в `./data`, настройки — `./config.yaml`. Голос на ПК в Docker не работает (микрофон) — это отдельный аддон для Windows.

## Голос на ПК (аддон, Windows)

1. `install_voice.bat` — поставит распознавание (Whisper), слово-активацию (Vosk), микрофон и трей (~700 МБ). По желанию спросит про **Silero** (офлайн-озвучка, ~2 ГБ) и **GPU для Whisper** (CUDA, ~1 ГБ; распознавание 0.3 с вместо 2–3 с).
2. Запущен `start.bat` → двойной клик **`voice.bat`**. Кружок в трее: серый — жду имя, синий — слушаю, жёлтый — думаю, зелёный — говорю.
3. «**Марвин**, потратил семьсот на такси» (ваше имя из мастера) — или **Ctrl+Shift+J** без обращения.

После ответа ещё 12 секунд можно говорить без имени; «режим беседы» — 2 минуты. Напоминания произносятся вслух. Голосовые в Telegram расшифровываются и выполняются как текст — ответ приходит текстом.
Пауза, после которой команда считается сказанной: ⚙ Настройки → голос → `silence_sec`.

Без аддона распознавание голосовых сообщений Telegram недоступно (можно включить Groq Whisper в настройках — тогда голос уйдёт в облако).

## Google Календарь (в одну сторону: ассистент → Google)

⚙ Настройки → google календарь → инструкция на 5 шагов (создать OAuth-клиент в Google Cloud, вставить Client ID/Secret, «подключить»). Всё, что попадает в календарь ассистента, появится в Google — на телефоне, часах, где угодно. Обратно ничего не читается.

## Приватность

- Бот отвечает **только** вашему Telegram ID, остальных молча игнорирует.
- База — файл `data/assistant.db` на вашем диске. Скопировали файл — сделали бэкап (ночью это делается само, 30 дней хранения, вторая копия — на другой диск/в облачную папку по желанию).
- В режимах local/hybrid личные данные в облако **не уходят**; в hybrid обезличиваются даже общие вопросы (`brain.gemini.anonymize`). Фото — по умолчанию локально, если модель видит картинки; иначе в облако с вашего разрешения (`brain.vision.where`).
- Файлы на ПК ассистент **никогда не удаляет** — собирает в отдельную папку, решение за вами.
- Токен и ключи — в `config.yaml`, который в `.gitignore`.

## Где что лежит

```
├─ install.bat / start.bat / update.bat     ← установка, запуск (держать открытым), обновление пакетов
├─ install_voice.bat / voice.bat            ← голосовой аддон и его запуск
├─ autostart.bat / phone.bat / build_web.bat
├─ config.example.yaml → config.yaml        ← настройки (мастер и сайт пишут сюда сами)
├─ data/assistant.db                        ← ВСЯ база; data/backups/, data/media/
├─ run.py                                   ← ядро: API + сайт + Telegram + планировщик
├─ voice_client.py                          ← голосовой клиент ПК
├─ core/                                    ← мозг (brain/), инструменты (tools/), сервисы, API, Telegram, голос, setup_wizard.py
├─ web/                                     ← сайт (React + Vite); собранный сайт — web/site/
├─ tests/                                   ← pytest
└─ Dockerfile, docker-compose.yml
```

`web/site` (собранный сайт) лежит в репозитории — Node.js для запуска не нужен. Если меняли фронт — `build_web.bat` (нужен [Node.js](https://nodejs.org)) или `cd web && npm ci && npm run build`.

## Если что-то не так

- **Окно `start.bat` пишет `Cannot connect to host api.telegram.org`** — Telegram заблокирован у провайдера. Включите VPN (ассистент переподключится сам) или впишите прокси в ⚙ Настройки → telegram. Сайт и API работают и без Telegram.
- **Бот молчит** — `/diag` в боте покажет, кто отвечает и за сколько. Проверьте `owner_id` (`/id` в боте).
- **«Локальный мозг не запущен»** — Ollama не установлена/не запущена (значок в трее Windows). Команды-шаблоны работают и без неё.
- **Облако отвечает ошибкой 4xx** — провайдер снял модель или ключ протух: ⚙ Настройки → облако → «проверить». Модель можно оставить пустой — возьмётся дефолтная.
- **Хочу пройти мастер заново** — откройте `http://localhost:8765/setup?again`.
- **Обновление** — распакуйте новый архив поверх (папка `data/` и `config.yaml` не трогаются), затем `update.bat` и `start.bat`.
- **Второе окно `start.bat`** — не нужно: порт занят, ассистент уже запущен (возможно, в трее из автозагрузки).

Логи — прямо в окне `start.bat`; голос — `data\voice.log`. Нашли ошибку — [заведите issue](../../issues/new/choose), приложите лог (ключи замажьте).

## Разработка

```bash
python -m venv .venv && . .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt pytest
python -m pytest tests -q                         # 50 тестов, без сети
python run.py --no-tg                             # ядро без Telegram, сайт на :8765
cd web && npm ci && npm run dev                   # фронт с hot reload на :5173 (проксирует /api на :8765)
```
