# История изменений

Формат: что изменилось для пользователя. Инженерные подробности аудитов — в [docs/audit.md](docs/audit.md).

## 0.9.5 — 14.09.2026

- **Режим фрилансера** — «Настройки → фриланс»: один выключатель на все «заказные» штуки (раздел «Заказы» в меню и на
  телефоне, блок на главной, мини-таймер, дедлайны в дайджесте, оплаты в прогнозе кассы, действия в палитре). Под ним —
  каждая ручка отдельно. При обновлении режим включается сам, если заказы уже есть; на чистой установке — выключен.
  Помодоро переехал в эту же вкладку. Данные не трогаются: выключил — просто не показывается.
- **Финансовый пульс** (внутри режима, без нового экрана):
  · *следить за оплатами* — сдал, а денег нет дольше N дней (порог ползунком, по умолчанию 3): строка на главной в блоке
    «заказы», в утреннем дайджесте, тихая строка под цифрами в «Заказах», «обычно платит за N дней» по истории клиента;
    ожидаемая дата в прогнозе кассы — по привычке клиента, а не «завтра». Чат: «кто задерживает» / «кто тянет с оплатой».
  · *ставка по факту* — если гоняли таймер и была оценка часов: «12 ч из 8 · 2 000 ₽/ч · план 3 000» и мягкое
    предупреждение при перерасходе больше порога (ползунок, по умолчанию 30 %). Без таймера — ничего не показывается.
  · *налог с дохода по заказам* — 0 / 4 / 6 / 13 %: вычитается из ожидаемых оплат в прогнозе и «свободных деньгах»,
    в «Заказах» и в сводке «заказы» — сколько уйдёт за месяц с полученного и с ожидаемого.
  · *фриланс в недельном отчёте* — заработано · часов · ставка · кто задерживает, три строки в конце «Недели в мыслях».
  API `GET/PUT /api/orders/freelance`, `GET /api/orders/pulse`; в `/api/dashboard` — `freelance`, `orders.late`. Тесты `tests/test_pulse.py` (10).
- **Вид** — 13 акцентов вместо 6 (индиго, слива, красный, янтарь, олива, бирюза, небо…), образец показывает светлый и
  тёмный вариант цвета; **оттенок поверхностей** — нейтральный / тёплый / холодный / чернильный / в тон акценту (фон и
  карточки едва заметно подкрашиваются в обеих темах). Смена акцента и оттенка перетекает, как смена темы.
- **Движение** — карточки-ссылки приподнимаются под курсором, пилюли и сегменты «перетекают», переключатель с пружиной,
  числа при смене «вдыхают», шторка появляется без мигания подложки, глиф пустого состояния проявляется после текста,
  иконки в навигации чуть отзываются на наведение. Всё выключается прежним тумблером «анимации».

## 0.9.4 — 14.09.2026

- **Люди и клиенты** — карточка человека собирается сама из всего, где он упомянут (заказы и деньги по ним, долги, встречи,
  задачи, мысли, ссылки, последний контакт). Имена ловятся в падежах и по «он же»-именам («Ваня» = «Иван Петров»), похожие
  слова («Иванов», «ванну») — нет. Чат: «человек: Лена, сестра», «клиент: Пятёрочка», «что по Ване», «кто такая Лена» — без
  модели (⚡); для модели — инструменты `person_card`, `add_person`. Когда имя всплывает в обычной фразе, ассистент добавляет
  одну строку важного (неоплата, долг, ближайшая встреча) — не повторяя только что созданное и не чаще раза в 3 часа.
  Утренний дайджест: «кто сегодня».
- **Сайт → Люди** (Alt+9) — плитки, поиск, карточка с правкой, ссылки в разделы, «спросить ассистента». Главная: блок
  «кто сегодня» (только когда есть кого показать). API `/api/people*`.
- **Мозг → граф** — граф связей: люди · заказы · мысли · ссылки · теги · долги; рёбра по именам, `#тегам`, `[[ссылкам]]`
  и смысловой близости. Свой force-layout на canvas, без новых зависимостей. `GET /api/graph`, `GET /api/graph/backlinks/{kind}/{id}`.
  Тесты: `tests/test_people.py`.

## 0.9.3 — 14.09.2026

- **Помодоро: настройки** — «Настройки → общее → помодоро»: длина фокуса, короткого и длинного перерыва, длинный каждый
  N-й помидор, авто-перерыв (после фокуса перерыв стартует сам, после перерыва — ждёт), звук (колокол / динь / щелчки /
  без звука) и громкость, «сказать голосом». Хранится в базе (`setting pomodoro`), общее для сайта, Telegram и голоса,
  без перезапуска. API `GET/PUT /api/orders/pomodoro`; «таймер»/«перерыв» без числа, `/pomo` и кнопки в Telegram берут
  длину из настроек. Помидором считается сессия, отработанная хотя бы на 80 % — таймер, остановленный через минуту,
  в счёт и в «длинный перерыв каждый N-й» не идёт.
- **Уборка рабочего стола и «Загрузок»** — «разбери рабочий стол» / «прибери в загрузках» / «разгреби бардак» (голосом, в
  Telegram, на сайте). Работает на ПК через voice.bat по тому же каналу, что «открой»/«найди» (`core/pc/tidy.py`): сначала
  план — по каждой папке категории (Документы, Картинки, Скриншоты, Видео, Проекты, Архивы, Установщики…), примеры имён, что
  не трогает (папки, ярлыки, скрытые, недокачанное, изменённое за 10 минут, открытое в программе); после «да» — перенос в
  `<папка>/Разобрано/<Категория>` с журналом, одноимённые файлы не затираются. «отмени уборку» возвращает всё на место.
  Ничего не удаляется. Ночная уборка только «Загрузок» (файлы старше N дней, 3–6 утра, отчёт в Telegram) —
  `voice.pc.tidy_downloads_days`, по умолчанию выключена. Результаты команд ПК для запросов из Telegram теперь приходят
  в Telegram (раньше — только в чат сайта).
- **Мини-таймер в боковой панели** — кольцо, `мм:сс`, заказ; клик по времени → «Заказы», квадрат — стоп. Без таймера —
  кнопка «▶ 25:00» (длина из настроек). В свёрнутой панели — только кольцо с подсказкой. На телефоне таймер по-прежнему в шапке.
- **Звук по завершении** — в браузере (WebAudio, без файлов; на телефоне ещё и вибрация) по SSE-событию `timer`,
  и на колонках ПК через voice.bat (`_pomo_chime`) — слышно, даже если озвучка выключена. Кнопка «послушать» в настройках.

## 0.9.2 — 14.09.2026

- **Заказы (фриланс)** — `core/services/orders.py`, страница «Заказы», тулы `add_order / list_orders / update_order /
  order_payment`, `/orders` в Telegram. Заказ = клиент + сумма + дедлайн + статус (новый → в работе → на правках → сдан →
  оплачен). Аванс/оплата — доход «Фриланс» с привязкой (`Transaction.order_id`), полная оплата закрывает заказ.
  Дедлайны — в календаре (`kind: order`), в утреннем дайджесте («горит», «сдан, но не оплачен»), остаток по незакрытым
  заказам — как ожидаемый доход в прогнозе кассы. Статистика: доход по месяцам, ставка в час по таймеру, средний чек,
  клиенты (кто сколько принёс, кто должен). Правила без модели: «заказ: ролик для Пятёрочки, 25к, до пятницы»,
  «пришёл аванс 10000 за ролик», «заказы».
- **Помодоро** — один таймер на сайт, Telegram и голос (`WorkSession`). «таймер на ролик», «стоп», «перерыв», «сколько
  я сегодня работал», `/pomo`. По истечении: тост + таймер в шапке, Telegram с кнопками «ещё 25 / перерыв 5 / хватит»,
  голосом на ПК (и ночью — вы сами его ставили). Минуты идут в заказ → ставка в час.
- **Конверты / цели** — `core/services/goals.py`, «цель: подушка 300к к марту», «отложил 10к в подушку». Отложенное —
  расход «Накопления» с `goal_id`: уходит из «свободных» и прогноза; цель закрывается сама. Финансы → «конверты».
- **Техники**: 50/30/20 по корзине категории (`Category.bucket`, правится в редакторе категории), месяц к месяцу на тот
  же день, «на сколько хватит» (runway), «хватит ли на платежи» (+ предупреждение в 10:30, раз в день), годовые платежи →
  сколько откладывать в месяц. Всё в одном блоке «техники» и голосом. `finance_report` для модели.
- «Сегодня»: блок «заказы» (горящие дедлайны, идущий таймер, ждут оплаты), бейджи «хватит на N дней» и «на платежи не
  хватает». Палитра: заказ, таймер, цель, 50/30/20, сравнение. Alt+1…8 (заказы — Alt+5).
- Исправлено в этой сборке: `/api/ui-prefs` и `/api/events?tasks_too=true` падали с `NameError` (не были импортированы
  `get_setting` / `select`) — синхронизация оформления между устройствами и задачи в календаре не работали. Добавлен тест.
- Отмена («отмени») понимает заказы и цели. API: `/api/orders*`, `/api/finance/goals*`, `/api/finance/techniques`,
  `/api/orders/timer`.

## 0.9.1 — 11.09.2026

- **Сортировщик списков** (`core/brain/sorter.py`): сообщение с несколькими делами («задачи на день: …, …, в 15:00 врач,
  мысль — …») сначала проходит через нейронку в строгом JSON — каждый пункт получает тип (задача / событие / заметка /
  трата / доход), дату и сумму, — потом каждая запись создаётся своим сервисом. Ответ — разбор по группам; «отмени»
  откатывает всю пачку. Раньше такое улетало одной заметкой в память или первое время из списка становилось одним событием.
- Groq: модель для инструментов берётся из живого `/models` (Groq вывел `llama-4-scout`; при 404 — перечитать и повторить).
- **Сайт внутри Telegram (Mini App)** без VPN на телефоне: `funnel.bat` включает Tailscale Funnel, записывает публичный
  адрес в `telegram.webapp_url`; бот ставит кнопку-приложение и понимает `/app`. Вход — по подписанным данным Telegram
  (HMAC от токена бота, свежесть 10 мин, только `owner_id`) → отдельная сессия `assistant_tg` на 30 дней. Инструкция и
  разбор безопасности: `docs/telegram-miniapp.md`.
- Безопасность: запросы через обратный прокси (`X-Forwarded-*`) больше не считаются «своим компьютером»; `/api/phone` и
  ротация ключа — только физически с ПК; защита от перебора входа; cookie `Secure` по https; ротация ключа сбрасывает и
  Telegram-сессии. Экран «Нет доступа» вместо вечной загрузки для чужого устройства.
- Настройки → Интеграции → Telegram: карточка состояния Mini App (туннель, адрес, «использовать этот адрес»).
- Режим `brain.mode: cloud` теперь полноценный: инструменты (траты, задачи, события, заметки, поиск по памяти) выполняет
  облачная модель (OpenAI-совместимые провайдеры), заметки и недельный обзор тоже обрабатываются облаком. Раньше без Ollama
  работали только команды-шаблоны.
- `docs/second-assistant.md` — второй ассистент на том же ПК для близкого человека (отдельный бот, база, память).
- Обращение из `owner.name` подставляется и в готовые реплики («Есть, мам»; пусто — без обращения); `persona.style: neutral`
  получил свои спокойные реплики и мягкий промпт. В настройках появились «ассистент», «характер», «сервер».
- Правила: прошедшее время и показания здоровья («вчера была у врача…», «утром давление 140 на 90») — заметки в память,
  а не события; «завтра в 10 к врачу» — событие в 10:00 («к» больше не путается с «10к»). `search_notes` ищет по основам слов.
- `autostart.bat`: вторая копия в другой папке получает свой ярлык, а не перезаписывает первый.

## 0.9.0 — 10.09.2026

**Интерфейс переработан целиком** (см. [web/DESIGN.md](web/DESIGN.md)):
- единая дизайн-система: токены цвета, типографика, одинаковые кнопки/поля/карточки/диалоги;
- главная стала центром: приветствие → поле ввода → задачи → события → деньги; блоки можно перетаскивать, скрывать, менять плотность («настроить главную»);
- **Настройки → вид**: тема, акцентный цвет, масштаб, скругления, анимации, состав боковой и нижней панелей, обращение;
- чат: карточки «что сделано» под ответом, статус ассистента, одна история с Telegram;
- палитра `Ctrl+K` (страницы, действия, поиск по Мозгу, любая фраза), горячие клавиши подписаны под вашу ОС;
- календарь: линия текущего времени с подсказкой «первое — через 1 ч 36 мин», события «дальше на неделе» отделены;
- задачи: выбор важности из строки, сортировка по важности / сроку / новизне;
- телефон: свайпы как в iOS, настраиваемая нижняя панель, иконка приложения в стиле логотипа.

**Понимание фраз**
- «др 12 числа», «12-е число» → дата; разовое «иду на др» не считается днём рождения (только ежегодные события);
- «поставь событие что …» — служебные слова не попадают в заголовок.

**Безопасность и надёжность** (аудит, [подробности](docs/audit.md))
- API с других устройств — только по ключу доступа (QR в настройках); CSRF-защита multipart-запросов;
- крупные суммы от нейросети (≥100 000 ₽) и выключение ПК — только после подтверждения;
- вечерний обзор незакрытых задач, тихие часы 23–8, кэш проверки Ollama.
